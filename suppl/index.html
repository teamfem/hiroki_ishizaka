This page is not another list of research topics. It organises the prerequisites, theorem dependencies, exercises, implementation routes and exit problems needed to reach the main Research Visions.

Stage 0Foundation: weak forms, Sobolev spaces, Céa, implementation.
Stage 1Geometry: maximum angle, semi-regularity, anisotropy.
Stage 2Structure: CR, RT, conservation, DMP, maximum norm.
Stage 3Complexes & dynamics: Nédélec, de Rham, memory and delay.
Stage 4Certification: curved geometry, DWR, verified output, formal reasoning.
Recommended routes

Choose a path by research goal.

The curriculum is modular. A student or researcher does not need to follow every branch before reaching a specific research programme.

CR-DMP & \(L^\infty\)

FEM → PDE viewpoint → anisotropic interpolation → CR–RT → DMP / maximum norm.

Nédélec & de Rham

FEM → vector analysis → RT → \(H(\mathrm{curl})\) → commuting projections → Maxwell.

Memory & delay

Evolution equations → Volterra operators / measures → kernel stability → BDF / CQ → certification.

Exact-curved FEM

Anisotropic interpolation → mappings / Jacobians → Piola → shape calculus → ALE / FSI.
