Core programme

The work to build first.

Vision 10, 11, 17, 18, 20 and 21 form the present Core, with geometry, unresolved dynamics, exact-curved analysis and certification developed in parallel but with explicit dependencies.

Core G1 · Geometry / CR–RT

Anisotropic CR–RT, discrete maximum principles and maximum-norm analysis

Separate element geometry, metric-angle monotonicity, patch connectivity and discrete Green-function effects rather than forcing them into one mesh condition.

3D Nédélec interpolation to anisotropic de Rham, Hodge and Maxwell theory

Build quantitative Nédélec stability together with existing RT estimates, then move to commuting projections, discrete Poincaré inequalities, Hodge decomposition and Maxwell certification.

Core M · Unresolved dynamics

Stable reduction theory and structure-preserving memory computation

Three lanes, not one queue.

continuous foundations→BDF–CQ→anisotropic CR–RT→stable reduction→identification + certification
