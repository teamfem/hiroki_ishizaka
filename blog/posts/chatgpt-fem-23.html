第23回：有限要素解の誤差を保証する — equilibrated fluxとhypercircle

ChatGPTで作る有限要素プログラム入門 Season 2 第11回（通算第23回）
30th August 2026

はじめに――「小さそう」ではなく「この値以下」と言いたい

mesh refinementで誤差が減っている． residual estimatorも小さくなっている． それだけでは，exact solutionが本当にどこにいるかは分かりません．

この回では，finite-element solution \(\widetilde u_h\) に対して

\[ \boxed{ \|u-\widetilde u_h\|_V \le \eta_h } \tag{1} \]

というguaranteed upper boundを作ります． 中心になるのが

\[ \boxed{ H(\operatorname{div})\text{-conforming equilibrated flux} + \text{hypercircle identity} } \tag{2} \]

です．

さらに後半では，このlinear error certificationを semilinear problemのNewton–Kantorovich verificationへ接続します．

1．まずPoisson型問題で符号を固定する

bounded Lipschitz domain \(\Omega\subset\mathbb R^d\) で

\[ -\nabla\cdot(A\nabla u)=f, \qquad u=0 \quad\text{on }\partial\Omega \tag{3} \]

を考えます． \(A(x)\) はsymmetric uniformly positive definiteとします．

本記事ではphysical fluxを

\[ \boxed{ \boldsymbol q = A\nabla u } \tag{4} \]

と定義します． 従って

\[ \boxed{ \nabla\cdot\boldsymbol q=-f. } \tag{5} \]

文献によっては \(-A\nabla u\) をfluxと呼ぶので， 最初に符号を固定することが重要です．

2．energy normとdual residual norm

\(V=H_0^1(\Omega)\) に

\[ \boxed{ \|v\|_V = \left( \int_\Omega A\nabla v\cdot\nabla v\,dx \right)^{1/2} } \tag{6} \]

を入れます．

computed conforming state \(\widetilde u_h\in V_h\subset V\) のresidual functionalは

\[ \boxed{ \langle F(\widetilde u_h),v\rangle = \int_\Omega A\nabla\widetilde u_h\cdot\nabla v\,dx - \int_\Omega fv\,dx. } \tag{7} \]

dual normは \[ \|F(\widetilde u_h)\|_{V^\ast} = \sup_{0\ne v\in V} \frac{ |\langle F(\widetilde u_h),v\rangle| }{ \|v\|_V }. \tag{8} \]

3．任意の \(H(\operatorname{div})\) fluxでresidualを書き直す

\(\boldsymbol\sigma_h\in H(\operatorname{div};\Omega)\) を任意に取ります． integration by partsすると

\[ \boxed{ \langle F(\widetilde u_h),v\rangle = \int_\Omega (A\nabla\widetilde u_h-\boldsymbol\sigma_h) \cdot\nabla v\,dx + \int_\Omega (-f-\nabla\cdot\boldsymbol\sigma_h)v\,dx. } \tag{9} \]

ここで重要なのは， \(\boldsymbol\sigma_h\) がelementwise vector polynomialであるだけでなく global \(H(\operatorname{div})\)-conformingであることです．

normal fluxがinterior faceでsingle-valuedだから， element boundary termsがglobalにcancelします．

4．exact equilibrationならresidualはflux mismatchだけになる

もし

\[ \boxed{ \nabla\cdot\boldsymbol\sigma_h=-f } \tag{10} \]

がexactly成立すれば，式 (9) のvolume residualは消えて

\[ \boxed{ \langle F(\widetilde u_h),v\rangle = \int_\Omega (A\nabla\widetilde u_h-\boldsymbol\sigma_h) \cdot\nabla v\,dx. } \tag{11} \]

従ってweighted Cauchy–Schwarzから

\[ \boxed{ \|F(\widetilde u_h)\|_{V^\ast} \le \| \boldsymbol\sigma_h - A\nabla\widetilde u_h \|_{A^{-1}}. } \tag{12} \]

右辺はexact solutionを含まず，完全にcomputableです．

5．hypercircle identity――保証が等式から出る

\(\widetilde u_h\in H_0^1(\Omega)\) と \(\boldsymbol\sigma_h\in H(\operatorname{div};\Omega)\) が \[ \nabla\cdot\boldsymbol\sigma_h=-f \] を満たすとします． するとPrager–Synge型のhypercircle identity

\[ \boxed{ \begin{aligned} & \|u-\widetilde u_h\|_V^2 + \| \boldsymbol\sigma_h-A\nabla u \|_{A^{-1}}^2 \\ &\qquad= \| \boldsymbol\sigma_h - A\nabla\widetilde u_h \|_{A^{-1}}^2 \end{aligned} } \tag{13} \]

が成立します．

これは単なるinequalityではなくexact identityです．

6．hypercircle identityの証明スケッチ

右辺を \[ \boldsymbol\sigma_h-A\nabla\widetilde u_h = (\boldsymbol\sigma_h-A\nabla u) + A\nabla(u-\widetilde u_h) \] と分けます．

cross termは

\[ \int_\Omega (\boldsymbol\sigma_h-A\nabla u) \cdot \nabla(u-\widetilde u_h)\,dx. \tag{14} \]

ここで \[ \nabla\cdot\boldsymbol\sigma_h = \nabla\cdot(A\nabla u) = -f \] なので

\[ \nabla\cdot (\boldsymbol\sigma_h-A\nabla u) = 0. \tag{15} \]

さらに \[ u-\widetilde u_h\in H_0^1(\Omega) \] だからintegration by partsによりcross termは0です． Pythagorasがそのまま式 (13) を与えます．

7．guaranteed energy error bound

式 (13) の第二項はnonnegativeなので

\[ \boxed{ \|u-\widetilde u_h\|_V \le \| \boldsymbol\sigma_h - A\nabla\widetilde u_h \|_{A^{-1}}. } \tag{16} \]

これがequilibrated-flux error certificationの最も透明な形です．

hypercircleの原則
approximate solutionとequilibrated fluxを 同じphysical flux \(A\nabla u\) へ近づければ， その二つのmismatchがexact energy errorを上から囲む．

8．しかし \(f\) がRT divergence spaceに入らないことがある

lowest-order \(RT_0\) では \[ \nabla\cdot RT_0(T)=P_0(T). \] 従って一般の \[ f\in L^2(\Omega) \] に対して \[ \nabla\cdot\boldsymbol\sigma_h=-f \] をcellwise exactly満たすことはできません．

そこで \[ f_h=\Pi_h^0f \] を使い，

\[ \boxed{ \nabla\cdot\boldsymbol\sigma_h = -f_h } \tag{17} \]

とします． このときhypercircleのpure identityにはdata oscillationが追加されます．

9．必要なのはelementwise mean equilibration

より一般にelement residual

\[ R_T(\boldsymbol\sigma_h) = -f-\nabla\cdot\boldsymbol\sigma_h \tag{18} \]

が

\[ \boxed{ \int_T R_T(\boldsymbol\sigma_h)\,dx = 0 \qquad \forall T\in\mathcal T_h } \tag{19} \]

を満たせば十分です．

element average \[ \overline v_T = \frac1{|T|} \int_Tv\,dx \] を引けば \[ \int_T R_Tv\,dx = \int_T R_T(v-\overline v_T)\,dx. \tag{20} \]

10．simplexのPoincaré boundはangle conditionを使わない

convex simplex \(T\) ではPayne–Weinberger型のboundとして

\[ \boxed{ \|v-\overline v_T\|_{L^2(T)} \le \frac{h_T}{\pi} \|\nabla v\|_{L^2(T)}. } \tag{21} \]

ここで \[ h_T=\operatorname{diam}(T). \]

このconstantはtriangleのminimum angleを直接要求しません． 従ってresidual certificationのこの部分は， 強いanisotropyに対しても形状正則性を前提にしない構造を持ちます．

11．flux mismatchとoscillation

\(A(x)\xi\cdot\xi\ge\alpha_0|\xi|^2\) とします．

flux mismatchを \[ \boxed{ \eta_{\mathrm{mis}} = \| \boldsymbol\sigma_h - A\nabla\widetilde u_h \|_{A^{-1}}, } \tag{22} \] oscillation termを \[ \boxed{ \eta_{\mathrm{osc}} = \left[ \sum_{T\in\mathcal T_h} \left( \frac{h_T}{\pi} \right)^2 \| R_T(\boldsymbol\sigma_h) \|_{L^2(T)}^2 \right]^{1/2} } \tag{23} \] とします．

すると

\[ \boxed{ \|F(\widetilde u_h)\|_{V^\ast} \le \eta_{\mathrm{mis}} + \alpha_0^{-1/2} \eta_{\mathrm{osc}}. } \tag{24} \]

exact equilibrationなら \(\eta_{\mathrm{osc}}=0\) で， hypercircle型のmismatch boundへ戻ります．

12．なぜRT fluxが必要なのか

elementwise gradient \[ A\nabla\widetilde u_h \] は通常interior faceでnormal componentがjumpするので \[ H(\operatorname{div};\Omega) \] には入りません．

一方，RT spaceは

\[ \boxed{ \text{single-valued normal flux} } \tag{25} \]

をfinite-element conformityとして持っています．

従って

\[ \boxed{ \text{equilibration} + \text{normal continuity} } \]

を有限次元で実現する自然なcertificate spaceがRTです．

13．CR–RT route――certificate fluxをscalar problemから作る

低次では，patchwise mixed reconstructionを毎回解く代わりに， auxiliary CR problemとMarini型relationから \(RT_0\) certificate fluxを作れます．

semilinear diffusion–reaction residualに合わせて

\[ s_h = c(\cdot,\widetilde u_h)-f, \qquad r_h|_T = \Pi_T^0s_h \tag{26} \]

と置きます． Poissonなら \[ c=0, \qquad r_h=-f_h. \]

14．auxiliary CR problem

\(A_{0,T}\) をelementwise constant tensorとします． \(\widetilde u_h^{CR}\in V_{h,0}^{CR}\) を

\[ \boxed{ \sum_{T\in\mathcal T_h} \int_T A_{0,T} \nabla_h\widetilde u_h^{CR} \cdot \nabla_hv_h\,dx = -\int_\Omega r_hv_h\,dx } \tag{27} \]

for all \(v_h\in V_{h,0}^{CR}\) から求めます．

このsolveはprimal solutionを置き換えるためではありません． certificate fluxを作るためだけのauxiliary scalar solveです．

15．Marini型のcellwise field

element barycentreを \(x_T\) とし，

\[ \boxed{ \boldsymbol\sigma_T^\ast(x) = A_{0,T} \nabla_h\widetilde u_h^{CR}|_T + \frac{r_h|_T}{d} (x-x_T). } \tag{28} \]

これは \(RT_0(T)\) に属し，

\[ \boxed{ \nabla\cdot\boldsymbol\sigma_T^\ast = r_h|_T. } \tag{29} \]

Poissonでは \[ \boldsymbol\sigma_T^\ast = \nabla_hu_h^{CR} - \frac{f_h|_T}{d}(x-x_T). \tag{30} \]

16．CR equationがRT normal continuityを作る

interior face \(F\) のCR basis function \(\phi_F\) を auxiliary problemのtest functionに選ぶと， 隣接element \(T^+,T^-\) のface flux balanceが得られます．

その結果，式 (28) のface flux DoFsは

\[ \boxed{ \int_F [\![\boldsymbol\sigma_h\cdot\boldsymbol n]\!] \,ds = 0. } \tag{31} \]

lowest-order RTではnormal componentがface上constantなので

\[ \boxed{ [\![\boldsymbol\sigma_h\cdot\boldsymbol n]\!] = 0 \quad\text{a.e. on }F. } \tag{32} \]

従って \[ \boldsymbol\sigma_h\in H(\operatorname{div};\Omega). \]

第15回で見たCR–RTの相性が， ここではerror certificateを作る代数として現れます．

17．実装ではface flux DoFをglobal orientationでassembleする

# T: one simplex
# xT: barycentre
# rh_T: cellwise constant target divergence
# grad_cr: broken CR gradient on T
# A0: cellwise constant diffusion tensor

def sigma_star(x, A0, grad_cr, rh_T, xT, dim):
    return (
        A0 @ grad_cr
        + (rh_T / dim) * (x - xT)
    )

# For each oriented face F:
#   flux_F = integral_F sigma_star · n_global ds
# Store one global value per face.
#
# Local RT coefficients are recovered using
# the local/global face orientation signs.

ここでも第14回と同じく， normal orientationのsign管理が必要です．

18．certificate algorithm

低次CR–RT routeをまとめると，

\[ \boxed{ \begin{aligned} 1.&\quad \widetilde u_h\text{ を通常のconforming FEMで計算},\\ 2.&\quad r_h=\Pi_h^0(c(\widetilde u_h)-f),\\ 3.&\quad \text{auxiliary CR problemを解く},\\ 4.&\quad \text{Marini型式で }RT_0\text{ fluxを再構成},\\ 5.&\quad H(\operatorname{div})\text{ continuityを監査},\\ 6.&\quad \eta_{\mathrm{mis}},\eta_{\mathrm{osc}}\text{ を計算},\\ 7.&\quad \|F(\widetilde u_h)\|_{V^\ast}\text{ を上から保証} \end{aligned} } \tag{33} \]

となります．

19．hypercircleとresidual certificationを混同しない

二つは近いですが，同じstatementではありません．

setting result
exact equilibration \(\nabla\cdot\sigma_h=-f\) Prager–Synge hypercircle identity，energy errorをmismatchだけで保証
mean equilibration only dual residual bound，mismatch + oscillation
semilinear problem residual boundをNK verificationの(C1)として使用

20．guaranteed estimatorとeffectivity

guaranteed upper bound \[ \|u-\widetilde u_h\|_V\le\eta_h \] があっても，\(\eta_h\) が非常に大きければ実用性は低くなります．

exact solutionを知るmanufactured testでは

\[ \boxed{ I_{\mathrm{eff}} = \frac{\eta_h}{ \|u-\widetilde u_h\|_V } \ge1 } \tag{34} \]

を見ればsharpnessを診断できます．

ただし実問題ではtrue errorは未知なので， effectivityは開発時の診断であってcertification条件そのものではありません．

21．anisotropic meshで何が嬉しいのか

式 (21) のlocal mean-zero Poincaré boundは \[ h_T/\pi \] だけで書けるため，residual boundそのものにshape regularity constantを直接入れずに済みます．

しかし，ここから

\[ \boxed{ \text{anisotropic estimator efficiency is automatically uniform} } \]

と結論してはいけません．

本当に重要なのは \[ \eta_{\mathrm{mis}} = \|\boldsymbol\sigma_h-A\nabla\widetilde u_h\|_{A^{-1}} \] がanisotropic mesh familyでどう振る舞うかです．

22．低次Poissonでのanisotropic consistency

\(A=I\) のPoisson problemで \[ f_h=\Pi_h^0f \] とし， \[ \boldsymbol\sigma_h|_T = \nabla_hu_h^{CR}|_T - \frac{f_h|_T}{d}(x-x_T) \] とします． triangle inequalityから

\[ \boxed{ \begin{aligned} \| \boldsymbol\sigma_h-\nabla\widetilde u_h \|_{L^2} \le{}& \| \nabla_hu_h^{CR}-\nabla u \|_{L^2} \\ &+ \| \nabla(u-\widetilde u_h) \|_{L^2} + h\|f_h\|_{L^2}. \end{aligned} } \tag{35} \]

従ってCR approximationとconforming approximationが そのanisotropic mesh family上でenergy-consistentなら

\[ \boxed{ \| \boldsymbol\sigma_h-\nabla\widetilde u_h \|_{L^2} \longrightarrow0. } \tag{36} \]

これは一般のanisotropic efficiency theoremではなくconditional consistency statementです．

23．実際のanisotropic testではaspect ratioを発散させる

一つのtest familyとして

\[ h_x=M^{-1}, \qquad h_y=M^{-2} \tag{37} \]

を使うと

\[ \boxed{ \kappa_h = \frac{h_x}{h_y} = M \longrightarrow\infty. } \tag{38} \]

つまりusual shape-regular regimeから外れていきます．

このfamilyでも，smooth manufactured solutionに対する低次CR–RT certificationでは， mesh refinementとともにresidual boundとverification radiusが減少する挙動を確認できます． ただしこれはnumerical evidenceであり，uniform anisotropic efficiencyの証明ではありません．

24．semilinear problemではerror boundをsolution existenceへ使う

semilinear diffusion–reaction problemを

\[ F(u)=0 \quad\text{in }V^\ast \tag{39} \]

と書きます． computed state \(\widetilde u_h\) の近くにexact solutionが存在することを示すには， equilibrated residualだけでは足りません．

Newton–Kantorovich verificationでは三つの量を用意します．

\[ \boxed{ \begin{aligned} \text{(C1)}&\quad \|F(\widetilde u_h)\|_{V^\ast}\le r, \\ \text{(C2)}&\quad \|DF(\widetilde u_h)^{-1}\| \le \alpha^{-1}, \\ \text{(C3)}&\quad \|DF(w)-DF(z)\| \le L(\rho)\|w-z\|_V. \end{aligned} } \tag{40} \]

equilibrated fluxが担当するのは(C1)です．

25．verification radiusはscalar inequalitiesへ落ちる

\[ \eta=\frac r\alpha \] とし，

\[ \boxed{ p(\rho) = \eta + \frac{L(\rho)}{2\alpha}\rho^2 - \rho, } \tag{41} \] \[ \boxed{ q(\rho) = \frac{L(\rho)}{\alpha}\rho. } \tag{42} \]

もし

\[ \boxed{ p(\rho)\le0, \qquad q(\rho)<1 } \tag{43} \]

なら， \[ B(\widetilde u_h,\rho) = \{w\in V:\|w-\widetilde u_h\|_V\le\rho\} \] の中にexact solutionが存在し，そのball内でlocal uniquenessも得られます．

つまりfinite-element post-processingが最後には 数個のscalar inequalityのverificationへ落ちます．

26．monotone reactionならstability constantが簡単になる

semilinear operator \[ -\nabla\cdot(A\nabla u)+c(x,u)=f \] に対し \[ \partial_sc(x,\widetilde u_h)\ge0 \] ならlinearizationはenergy normでcoerciveです．

特に \[ \|v\|_V^2 = \int_\Omega A\nabla v\cdot\nabla v \] と正規化すれば

\[ \boxed{ \alpha\ge1 } \tag{44} \]

と取れる設定があります．

一方，strongly non-monotone reactionやnearly singular linearizationでは， この安価なcoercivity routeだけでは不十分です．

27．例：\(-\Delta u+u^3=f\)

unit squareで

\[ -\Delta u+u^3=f, \qquad u=0 \tag{45} \]

を考え， \[ u^\ast(x,y) = \sin(\pi x)\sin(\pi y) \] から \(f\) を作ります．

この場合 \[ \partial_sc(u)=3u^2\ge0 \] なので \[ \alpha=1 \] を使えます．

また \(H_0^1(\Omega)\hookrightarrow L^4(\Omega)\) のverified embedding constantを使えば， \(DF\) のLipschitz boundもcomputableになります．

30．solution ballが得られるとQoIも囲める

もし \[ u\in B(\widetilde u_h,\rho) \] がcertifiedなら， quantity of interest \(J(u)\) も derivative boundから囲めます．

\[ \|DJ(w)\|_{L(V,\mathbb R)} \le L_J(\rho) \] がball上で成立すれば

\[ \boxed{ J(u) \in [ J(\widetilde u_h)-L_J(\rho)\rho,\ J(\widetilde u_h)+L_J(\rho)\rho ]. } \tag{46} \]

これはadjointを解かないbaseline enclosureです．

31．adjointを使うとoutput boundを鋭くできる

linearized adjoint \[ B_{\widetilde u_h}(v,z) = DJ(\widetilde u_h)v \tag{47} \] を解き， approximation \(z_h\) のadjoint residualも equilibrated fluxでcertifyすると， worst-case derivative boundより鋭いgoal-oriented enclosureを作れます．

つまり

\[ \boxed{ \text{equilibrated flux} \longrightarrow \text{state residual certification} \longrightarrow \text{adjoint residual certification} \longrightarrow \text{verified QoI} } \tag{48} \]

という二重利用ができます．

32．「guaranteed estimator」と「computer-assisted proof」は区別する

数学的に導いたupper bound formulaがrigorousでも， それをstandard double precisionで評価した数値を そのままinterval enclosureと呼ぶことはできません．

strict computer-assisted proofにするなら， 最終的なscalar quantities

\[ \boxed{ r,\quad \alpha,\quad L(\rho),\quad p(\rho),\quad q(\rho) } \tag{49} \]

をoutward rounding / interval arithmeticで評価する必要があります．

一方，finite-element assembly全体をinterval化しなくても， 最後のscalar post-processingだけでrigorを閉じられる設計は大きな利点です．

33．variable coefficientでは何に注意するか

Marini型explicit formulaで \[ A_{0,T}=\Pi_T^0A \] のようなelementwise constant tensorを使う場合， genuinely variable \(A(x)\) に対しては

\[ \boxed{ (A-A_{0,T})\nabla\widetilde u_h } \tag{50} \]

に由来するcoefficient-approximation contributionを residual budgetへ追加する必要があります．

従ってlow-order formulaを general higher-order variable-coefficient equilibrated reconstruction と同一視してはいけません．

34．higher orderでは別のreconstructionが必要

高次conforming stateに対して lowest-order \(RT_0\) certificateを固定したままでは， flux mismatchがapproximation orderを制限する可能性があります．

その場合は

\[ \boxed{ RT_k, \quad BDM_k, \quad \text{local mixed equilibrated reconstruction} } \tag{51} \]

などへ進むのが自然です．

CR–RT routeの価値は 「全てのequilibrated estimatorより優れる」ことではなく， low-orderでalgebraic structureが透明なことにあります．

35．AIがguaranteed error estimationで間違えやすい点

mistake何が壊れるか
flux signを途中で反転divergence targetとhypercircle identityが不整合
elementwise fluxを \(H(\operatorname{div})\) とみなすinterior face termsが消えない

36．equilibrated-flux implementation audit prompt

Audit prompt
このequilibrated-flux / hypercircle finite-element codeを数学的に監査してください．
(1) physical fluxのsign conventionを最初から最後まで固定しているか，
(2) certificate fluxがglobal \(H(\operatorname{div})\)-conformingか，
(3) interior face normal-flux jumpがzeroか，
(4) exact equilibrationとelementwise mean equilibrationを区別しているか，
(5) exact equilibration時だけPrager–Synge identityをそのまま使っているか，
(6) mean equilibration時にoscillation termを入れているか，
(7) weighted flux mismatchを \(A^{-1}\)-normで評価しているか，
(8) local Poincaré termに \(h_T/\pi\) を使う場合，その前提を確認しているか，
(9) CR auxiliary solveのright-hand side signがdivergence targetと一致しているか，
(10) Marini型fieldのdivergenceが \(r_h\) になることをcellwiseに確認しているか，
(11) global RT face orientationを管理しているか，
(12) nonconforming primalの場合にconforming companion / nonconformity termを忘れていないか，
(13) anisotropic meshでresidual reliabilityとestimator efficiencyを混同していないか，
(14) semilinear certificationではresidual boundをNKの(C1)として使い，(C2)(C3)を別途検証しているか，
(15) \(p(\rho)\le0,\ q(\rho)<1\) をcertification条件として確認しているか，
(16) fully rigorous numerical proofを主張する場合，scalar post-processingをoutward roundedにしているか，
(17) higher-order / variable-coefficient problemへlow-order \(RT_0\) formulaを無条件で拡張していないか
を順に確認してください．

37．第23回の結論

有限要素解のerrorを保証するには， 「exact solutionを推測する」のではなく もう一つのadmissible object――equilibrated flux――を作るという発想が有効です．

\[ \boxed{ \text{conforming primal state} + \text{equilibrated }H(\operatorname{div})\text{ flux} \Longrightarrow \text{guaranteed energy control} } \tag{52} \]

exact equilibrationならhypercircle identityが

\[ \boxed{ \text{error}^2 + \text{flux error}^2 = \text{computable mismatch}^2 } \tag{53} \]

を与えます．

low-orderではCR auxiliary solveとMarini型RT reconstructionによって， このcertificate fluxを明示的に作れます．

さらにsemilinear problemでは

\[ \boxed{ \text{equilibrated residual} + \text{linearized stability} + \text{nonlinear Lipschitz bound} \Longrightarrow \text{verified solution ball} } \tag{54} \]
