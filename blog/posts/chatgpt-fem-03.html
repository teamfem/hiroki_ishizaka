第3回：2次元三角形P1要素 — reference elementとJacobian

ChatGPTで作る有限要素プログラム入門 第3回
29th August 2026

はじめに――2次元では「要素の形」が数式に入ってくる

第2回では，1次元Poisson方程式について，弱形式から局所行列，assemblyまでを追いました． 2次元でも有限要素法の基本構造は同じですが，新しい要素が一つ入ります． reference elementからphysical elementへの座標変換です．

三角形の形，大きさ，向きはJacobian行列に集約されます． そして勾配には \(J^{-\top}\)，積分には \(|\det J|\) が現れます． この二つを間違えると，コードは動いても別の離散問題を解くことになります．

今回の核心
P1三角形要素では， \[ \nabla\phi_i=J^{-\top}\widehat\nabla\widehat\phi_i, \qquad dx=|\det J|\,d\widehat x. \] 2次元有限要素コードの幾何学的な核心は，この二つの変換にある．

1．モデル問題

単位正方形 \[ \Omega=(0,1)^2 \] でPoisson方程式 \[ -\Delta u=f\qquad\text{in }\Omega, \tag{1} \] \[ u=0\qquad\text{on }\partial\Omega \tag{2} \] を考えます．検証用の厳密解を \[ u(x,y)=\sin(\pi x)\sin(\pi y) \tag{3} \] とすると， \[ f(x,y)=2\pi^2\sin(\pi x)\sin(\pi y). \tag{4} \]

弱形式は \[ \text{Find }u\in H_0^1(\Omega) \text{ such that } \int_\Omega\nabla u\cdot\nabla v\,dx = \int_\Omega fv\,dx \quad \forall v\in H_0^1(\Omega). \tag{5} \]

2．reference triangle

標準参照三角形を \[ \widehat T = \operatorname{conv} \{(0,0)^{\top},(1,0)^{\top},(0,1)^{\top}\} \tag{6} \] とします．reference coordinatesを \[ \widehat x=(\xi,\eta)^{\top} \] と書きます．

P1 Lagrange基底は \[ \widehat\phi_0(\xi,\eta)=1-\xi-\eta, \qquad \widehat\phi_1(\xi,\eta)=\xi, \qquad \widehat\phi_2(\xi,\eta)=\eta. \tag{7} \] 従ってreference triangle上の勾配は定数で， \[ \widehat\nabla\widehat\phi_0 = \begin{pmatrix}-1\\-1\end{pmatrix}, \qquad \widehat\nabla\widehat\phi_1 = \begin{pmatrix}1\\0\end{pmatrix}, \qquad \widehat\nabla\widehat\phi_2 = \begin{pmatrix}0\\1\end{pmatrix}. \tag{8} \]

この三つの勾配は全要素で共通です．実要素ごとの差は，次に導入するJacobianを通して現れます．

3．physical triangleへのアフィン写像

実三角形を \[ T=\operatorname{conv}\{p_0,p_1,p_2\}, \qquad p_i\in\mathbb R^2 \tag{9} \] とします．reference triangleから \(T\) へのアフィン写像を \[ F_T(\widehat x) = p_0+J_T\widehat x \tag{10} \] とします．ここでJacobian行列は \[ J_T = \begin{pmatrix} |&|\\ p_1-p_0&p_2-p_0\\ |&| \end{pmatrix}. \tag{11} \]

つまり，Pythonでは 

J = np.column_stack((p1 - p0, p2 - p0))

です．列を辺ベクトルにするという convention を固定しておくことが重要です．

4．determinantは面積と向きを表す

reference triangleの面積は \[ |\widehat T|=\frac12. \] アフィン写像によって面積は \(|\det J_T|\) 倍されるので， \[ |T| = |\det J_T|\,|\widehat T| = \frac{|\det J_T|}{2}. \tag{12} \]

\(\det J_T>0\) なら頂点は反時計回り，\(\det J_T<0\) なら時計回りです． 積分measureには符号ではなく絶対値が必要なので， \[ dx=|\det J_T|\,d\widehat x. \tag{13} \]

監査ポイント
detJ と abs(detJ) を区別する． 向きの検査には符号付き \(\det J_T\) を使い，面積積分には \(|\det J_T|\) を使う．

5．なぜ勾配に \(J^{-\top}\) が現れるのか

実要素上の基底関数を \[ \phi_i(x) = \widehat\phi_i(F_T^{-1}(x)) \tag{14} \] で定めます．chain ruleから \[ \widehat\nabla\widehat\phi_i = J_T^{\top}\nabla\phi_i. \] 従って \[ \boxed{ \nabla\phi_i = J_T^{-\top}\widehat\nabla\widehat\phi_i } \tag{15} \] です．

ここはAI生成コードで非常に間違えやすい部分です． scalar P1要素の勾配変換は \(J_T^{-1}\) ではなく \[ J_T^{-\top} \] です． 

invJT = np.linalg.inv(J).T
grad_phi = (invJT @ grad_hat.T).T

6．局所剛性行列

Poisson問題の局所剛性行列は \[ K^{(T)}_{ij} = \int_T \nabla\phi_j\cdot\nabla\phi_i\,dx. \tag{16} \] 式 (13)，(15) を使うと \[ K^{(T)}_{ij} = |\det J_T| \int_{\widehat T} \left( J_T^{-\top}\widehat\nabla\widehat\phi_j \right) \cdot \left( J_T^{-\top}\widehat\nabla\widehat\phi_i \right) \,d\widehat x. \tag{17} \]

P1要素では勾配もJacobianも要素内で一定なので， \[ K^{(T)}_{ij} = \frac{|\det J_T|}{2} \left( J_T^{-\top}\widehat\nabla\widehat\phi_j \right) \cdot \left( J_T^{-\top}\widehat\nabla\widehat\phi_i \right). \tag{18} \]

physical gradientsを行に並べた行列 \[ G_T= \begin{pmatrix} (\nabla\phi_0)^{\top}\\ (\nabla\phi_1)^{\top}\\ (\nabla\phi_2)^{\top} \end{pmatrix} \] を使えば， \[ \boxed{ K^{(T)} = \frac{|\det J_T|}{2} G_TG_T^{\top} } \tag{19} \] と書けます．

7．具体例で \(J^{-\top}\) を確認する

例えば \[ p_0=(0,0)^{\top}, \qquad p_1=(2,0)^{\top}, \qquad p_2=(0,1)^{\top} \] とします．このとき \[ J_T = \begin{pmatrix} 2&0\\ 0&1 \end{pmatrix}, \qquad J_T^{-\top} = \begin{pmatrix} 1/2&0\\ 0&1 \end{pmatrix}. \] 従って \[ \nabla\phi_0= \begin{pmatrix}-1/2\\-1\end{pmatrix}, \quad \nabla\phi_1= \begin{pmatrix}1/2\\0\end{pmatrix}, \quad \nabla\phi_2= \begin{pmatrix}0\\1\end{pmatrix}. \]

\(|\det J_T|/2=1\) なので， \[ K^{(T)} = \begin{pmatrix} 5/4&-1/4&-1\\ -1/4&1/4&0\\ -1&0&1 \end{pmatrix}. \tag{20} \] 行和が0になることも確認できます．これは \[ \phi_0+\phi_1+\phi_2=1 \] から \[ \nabla\phi_0+\nabla\phi_1+\nabla\phi_2=0 \] となることに対応しています．

8．局所荷重ベクトルと三角形上の数値積分

局所荷重ベクトルは \[ F_i^{(T)} = \int_T f(x)\phi_i(x)\,dx \tag{21} \] です．reference triangleへ戻すと \[ F_i^{(T)} = |\det J_T| \int_{\widehat T} f(F_T(\widehat x)) \widehat\phi_i(\widehat x) \,d\widehat x. \tag{22} \]

ここでも \(|\det J_T|\) が必要です． 1次元で現れた \(h/2\) が，2次元ではJacobian determinantへ置き換わったと考えると分かりやすいです．

9．三角形P1要素をPythonに書く

一つの三角形から局所剛性行列を作る最小コードは次です． 

import numpy as np


grad_hat = np.array([
    [-1.0, -1.0],
    [ 1.0,  0.0],
    [ 0.0,  1.0]
])


def local_stiffness(P):
    # P[0], P[1], P[2] are the triangle vertices
    J = np.column_stack((
        P[1] - P[0],
        P[2] - P[0]
    ))

    detJ = np.linalg.det(J)

    if abs(detJ) < 1.0e-14:
        raise ValueError("Degenerate triangle")

    invJT = np.linalg.inv(J).T

    # physical gradients of the three P1 basis functions
    grads = (invJT @ grad_hat.T).T

    area = 0.5 * abs(detJ)

    Ke = area * (grads @ grads.T)

    return Ke, detJ, grads

このコードでは，detJ の符号を残して向きを検査し， 面積では abs(detJ) を使っています．

10．unit squareを三角形分割する

単位正方形を \(n\times n\) の小正方形に分け，各小正方形を対角線で二つの三角形へ分割します． 

def make_unit_square_mesh(n):
    grid = np.linspace(0.0, 1.0, n + 1)

    nodes = np.array([
        [x, y]
        for y in grid
        for x in grid
    ])

    triangles = []

    def idx(i, j):
        return j * (n + 1) + i

    for j in range(n):
        for i in range(n):
            v00 = idx(i,     j)
            v10 = idx(i + 1, j)
            v01 = idx(i,     j + 1)
            v11 = idx(i + 1, j + 1)

            # counter-clockwise ordering
            triangles.append([v00, v10, v11])
            triangles.append([v00, v11, v01])

    return nodes, np.array(triangles, dtype=int)

ここでは三角形を反時計回りに並べています． 面積積分には \(|\det J|\) を使うため，頂点順序を反転してもscalar P1要素の積分は正しく評価できます． ただし，局所自由度の番号を入れ替えれば，局所行列の表示も同じ行・列の置換を受けます．connectivityとの対応を一貫させることが必要です． また，RT要素やNédélec要素のようにorientationが自由度の符号やPiola変換に関わる場合には，頂点・辺・面の向きをより慎重に管理しなければなりません．

11．2次元のassembly

1次元では一要素あたり2自由度でしたが，三角形P1では3自由度です． それ以外のassemblyの考え方は同じです．

\[ A_{\operatorname{dof}_T(a),\operatorname{dof}_T(b)} \mathrel{+}=K^{(T)}_{ab}, \qquad a,b=0,1,2. \tag{23} \]

Pythonでは 

for a in range(3):
    b[tri[a]] += Fe[a]

    for c in range(3):
        A[tri[a], tri[c]] += Ke[a, c]

となります． local-to-global mapが tri = [i0, i1, i2] そのものになっている点が重要です．

大域行列についての注意
Dirichlet境界条件をまだ課していないPoisson stiffness matrixは，定数関数に対応する零固有値を持つため正定値ではなく半正定値です． 実際，各局所行列の行和が0なので，大域行列についても (A_{ m full}{f 1}=0) です． 同次Dirichlet境界自由度を除去した内部行列 (A_{II}) が対称正定値になります．

12．Poisson問題を解く完全な最小コード

以下では7点三角形quadratureを使って荷重ベクトルを計算します． dense matrixを使うのは構造を見やすくするためであり，大規模計算ではsparse matrixへ置き換える必要があります． 

def triangle_quadrature_7():
    points = [
        [1/3, 1/3],

        [0.059715871789770, 0.470142064105115],
        [0.470142064105115, 0.059715871789770],
        [0.470142064105115, 0.470142064105115],

        [0.797426985353087, 0.101286507323456],
        [0.101286507323456, 0.797426985353087],
        [0.101286507323456, 0.101286507323456]
    ]

    weights = [
        0.112500000000000,

        0.066197076394253,
        0.066197076394253,
        0.066197076394253,

        0.062969590272414,
        0.062969590272414,
        0.062969590272414
    ]

    return np.array(points), np.array(weights)


def solve_poisson_2d(n):
    nodes, triangles = make_unit_square_mesh(n)

    N = len(nodes)

    A = np.zeros((N, N))
    b = np.zeros(N)

    qpts, qw = triangle_quadrature_7()

    grad_hat = np.array([
        [-1.0, -1.0],
        [ 1.0,  0.0],
        [ 0.0,  1.0]
    ])

    for tri in triangles:
        P = nodes[tri]

        J = np.column_stack((
            P[1] - P[0],
            P[2] - P[0]
        ))

        detJ = np.linalg.det(J)
        invJT = np.linalg.inv(J).T

        grads = (invJT @ grad_hat.T).T

        Ke = 0.5 * abs(detJ) * (grads @ grads.T)

        Fe = np.zeros(3)

        for (xi, eta), w in zip(qpts, qw):
            phi = np.array([
                1.0 - xi - eta,
                xi,
                eta
            ])

            x = phi @ P

            f = (
                2.0 * np.pi**2
                * np.sin(np.pi * x[0])
                * np.sin(np.pi * x[1])
            )

            Fe += w * abs(detJ) * f * phi

        for a in range(3):
            b[tri[a]] += Fe[a]

            for c in range(3):
                A[tri[a], tri[c]] += Ke[a, c]

    on_boundary = (
        np.isclose(nodes[:, 0], 0.0)
        | np.isclose(nodes[:, 0], 1.0)
        | np.isclose(nodes[:, 1], 0.0)
        | np.isclose(nodes[:, 1], 1.0)
    )

    boundary = np.where(on_boundary)[0]
    interior = np.where(~on_boundary)[0]

    uh = np.zeros(N)

    uh[interior] = np.linalg.solve(
        A[np.ix_(interior, interior)],
        b[interior]
    )

    return nodes, triangles, uh

13．相対誤差と収束次数

相対誤差を \[ E_{L^2}^{\mathrm{rel}} = \frac{\|u-u_h\|_{L^2(\Omega)}}{\|u\|_{L^2(\Omega)}}, \qquad E_{H^1}^{\mathrm{rel}} = \frac{|u-u_h|_{H^1(\Omega)}}{|u|_{H^1(\Omega)}} \tag{24} \] とします．shape-regularな三角形メッシュ上のP1要素では，滑らかな解に対し \[ E_{L^2}^{\mathrm{rel}}=O(h^2), \qquad E_{H^1}^{\mathrm{rel}}=O(h) \tag{25} \] が期待されます．

14．2次元でも一次式は厳密に再現される

第1回で確認したlinear patch testは2次元でも成立します． 厳密解を \[ u(x,y)=a+bx+cy \tag{26} \] とします．これは各三角形上でP1多項式なので，境界値を厳密に与えれば \[ u\in V_h^g. \] さらに \[ -\Delta u=0. \]

任意の \(v_h\in V_h^0\) に対して，Greenの公式より \[ \int_\Omega\nabla u\cdot\nabla v_h\,dx = -\int_\Omega(\Delta u)v_h\,dx + \int_{\partial\Omega} \frac{\partial u}{\partial n}v_h\,ds = 0. \] 従って \(u\) 自身が離散問題を満たし，一意性から \[ \boxed{u_h=u}. \tag{27} \]

例えば \[ u(x,y)=1+2x-3y \] を使った数値テストでは，最大節点誤差は次の程度になります．

理論的な有限要素誤差は0であり，表に現れているのは丸め誤差です． このテストは \(J^{-\top}\)，assembly，Dirichlet境界条件を同時に検査できます．

15．ChatGPTが間違えやすい場所

  1. \(J^{-1}\) と \(J^{-\top}\) を取り違える：scalar P1の勾配は \(J^{-\top}\widehat\nabla\widehat\phi\)．
  2. \(|\det J|\) を落とす：荷重積分も剛性積分もphysical measureへの変換が必要．
  3. 面積を \(|\det J|\) とする：reference triangleの面積は \(1/2\) なので \(|T|=|\det J|/2\)．
  4. 頂点を行に並べるか列に並べるかを混同する：Jacobian conventionを固定する．
  5. reference gradientをphysical gradientとして使う：非標準三角形では誤り．
  6. determinantの符号を無視する：向きの検査と積分measureでは用途が違う．

まとめ

2次元三角形P1要素では，reference triangle上で固定された基底関数を， 各physical triangleへアフィン写像で移します．そのとき \[ \nabla\phi_i = J_T^{-\top}\widehat\nabla\widehat\phi_i, \qquad dx = |\det J_T|\,d\widehat x \] が有限要素コードの中心になります．

つまり，Jacobianは単なる座標変換の補助量ではありません． 要素の形状を，微分と積分の双方を通して離散作用素へ伝える量です． ここから先で異方性三角形を扱うと，\(J_T\) と \(J_T^{-1}\) の大きさが誤差解析や安定性に直接関わってきます．
