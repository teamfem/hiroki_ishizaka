第17回：Stokes方程式を有限要素法で解く — velocity・pressure・inf-sup条件

ChatGPTで作る有限要素プログラム入門 Season 2 第5回（通算第17回）
29th August 2026

はじめに――Poissonにはなかった「組合せの安定性」

第16回のmixed Poissonでは，RT0–P0というstable pairを使い， fluxとscalarを同時に求めました． Stokes方程式でも未知量は二種類です．

\[ \boxed{ \text{velocity} + \text{pressure} } \]

しかしStokes FEMでは， velocity spaceとpressure spaceを別々に選べばよいわけではありません． 二つのspaceの組合せがinf-sup stableであることが必要です．

Stokes要素を選ぶ基準
polynomial degreeだけを見るのではなく， \[ \boxed{ \text{velocity space} \times \text{pressure space} \quad\text{がinf-sup conditionを満たすか} } \] を確認する．

1．Stokes problem

\(\Omega\subset\mathbb R^d\)，\(d\in\{2,3\}\) で \[ -\nu\Delta\boldsymbol u+\nabla p = \boldsymbol f \qquad\text{in }\Omega, \tag{1} \] \[ \nabla\cdot\boldsymbol u=0 \qquad\text{in }\Omega, \tag{2} \] \[ \boldsymbol u=\boldsymbol 0 \qquad\text{on }\partial\Omega \tag{3} \] を考えます．

pressureは定数だけ不定なので \[ \boxed{ \int_\Omega p\,dx=0 } \tag{4} \] で正規化します．

2．continuous variational formulation

\[ V:=H_0^1(\Omega)^d, \qquad Q:=L_0^2(\Omega) \tag{5} \] とします．

bilinear formsを \[ a(\boldsymbol v,\boldsymbol w) = \nu \int_\Omega \nabla\boldsymbol v:\nabla\boldsymbol w\,dx, \tag{6} \] \[ b(\boldsymbol v,q) = - \int_\Omega (\nabla\cdot\boldsymbol v)q\,dx \tag{7} \] と置けば，

\[ \boxed{ a(\boldsymbol u,\boldsymbol v) + b(\boldsymbol v,p) = (\boldsymbol f,\boldsymbol v) } \tag{8} \]

for all \(\boldsymbol v\in V\)，および

\[ \boxed{ b(\boldsymbol u,q)=0 } \tag{9} \]

for all \(q\in Q\) です．

3．pressureはLagrange multiplier

式 (9) は \[ \nabla\cdot\boldsymbol u=0 \] というincompressibility constraintです． pressure \(p\) はこのconstraintを課すLagrange multiplierとして現れます．

従ってStokes systemはPoissonのような単純なSPD problemではなく，

\[ \boxed{ \text{saddle-point problem} } \]

です．

この時点で，linear solverやpreconditionerの選び方もPoissonとは変わります．

4．continuous inf-sup condition

Stokes problemのwell-posednessには \[ \boxed{ \inf_{0\neq q\in Q} \sup_{0\neq\boldsymbol v\in V} \frac{ |b(\boldsymbol v,q)| }{ |\boldsymbol v|_{H^1(\Omega)^d} \|q\|_{L^2(\Omega)} } \ge \beta > 0 } \tag{10} \] が重要です．

これはpressure modeをvelocity divergenceが十分に検出できる， という意味に読めます．

5．finite-element pairはCR–P0を使う

今回は \[ \boxed{ V_h = (V_{h0}^{CR})^d, \qquad Q_h = P_0(\mathcal T_h)\cap L_0^2(\Omega) } \tag{11} \] を使います．

velocityはcomponentwise CR function， pressureはelementwise constantです．

velocityは \[ V_h\not\subset H_0^1(\Omega)^d \] なのでnonconformingですが， このCR–P0 pairはStokes approximationの代表的なstable pairです．

6．なぜ単純なP1–P1ではだめなのか

velocityもpressureもcontinuous P1にすれば実装は簡単そうに見えます． しかし \[ P_1^d\times P_1 \] というequal-order pairは，stabilisationなしでは一般にdiscrete inf-sup conditionを満たしません．

その結果，spurious pressure modeや不安定なpressure fieldが現れ得ます．

ChatGPTにStokes codeを書かせるときの最初の質問
「何次の要素か」ではなく， そのvelocity–pressure pairはinf-sup stableか を聞く．

7．discrete Stokes problem

broken gradientとbroken divergenceを使い， \[ a_h(\boldsymbol u_h,\boldsymbol v_h) = \nu \sum_{T\in\mathcal T_h} \int_T \nabla\boldsymbol u_h: \nabla\boldsymbol v_h\,dx, \tag{12} \] \[ b_h(\boldsymbol v_h,q_h) = - \sum_{T\in\mathcal T_h} \int_T (\nabla\cdot\boldsymbol v_h)q_h\,dx. \tag{13} \]

求めるのは \[ (\boldsymbol u_h,p_h)\in V_h\times Q_h \] で， \[ \boxed{ a_h(\boldsymbol u_h,\boldsymbol v_h) + b_h(\boldsymbol v_h,p_h) = (\boldsymbol f,\boldsymbol v_h) } \tag{14} \] for all \(\boldsymbol v_h\in V_h\)， \[ \boxed{ b_h(\boldsymbol u_h,q_h)=0 } \tag{15} \] for all \(q_h\in Q_h\) です．

8．vector CR DoF

scalar CRのglobal DoFは各edge meanでした． Stokes velocityでは各componentについて \[ \frac1{|E|} \int_E u_{h,k}\,ds, \qquad k=1,\ldots,d \tag{16} \] を持ちます．

2次元なら一つのinterior edgeにつき \[ \boxed{ 2\ \text{velocity DoFs} } \] です．

boundary edge meanはcomponentwiseに0とします．

9．P0 pressureとmean-zero constraint

pressureは各elementでconstantです． \[ p_h|_T=P_T. \tag{17} \]

ただしconstant pressure modeを除くため， \[ \boxed{ \sum_{T\in\mathcal T_h} |T|P_T=0 } \tag{18} \] を課します．

実装では

\[ \text{one pressure DoF elimination} \]

でもよいですし， mean-zero constraint用のLagrange multiplierを一つ追加しても構いません．

10．block matrix

velocity stiffness matrixを \(A\)，divergence matrixを \(B\) とすると \[ \boxed{ \begin{pmatrix} \nu A&B^{\top}\\ B&0 \end{pmatrix} \begin{pmatrix} U\\ P \end{pmatrix} = \begin{pmatrix} F\\ 0 \end{pmatrix}. } \tag{19} \]

pressure mean-zero constraintをLagrange multiplier \(\lambda\) で入れるなら \[ \boxed{ \begin{pmatrix} \nu A&B^{\top}&0\\ B&0&m\\ 0&m^{\top}&0 \end{pmatrix} \begin{pmatrix} U\\ P\\ \lambda \end{pmatrix} = \begin{pmatrix} F\\ 0\\ 0 \end{pmatrix}, } \tag{20} \] ここで \[ m_T=|T|. \]

これはstabilisationではなくpressure normalisationのための補助変数です．

11．CR–P0 divergence matrix

scalar CR basisを \(\psi_{T,i}\) とします． velocity basis \[ \psi_{T,i}\boldsymbol e_k \] に対し， \[ \nabla\cdot ( \psi_{T,i}\boldsymbol e_k ) = \frac{\partial\psi_{T,i}}{\partial x_k}. \]

従ってlocal divergence matrixは \[ \boxed{ B^{(T)}_{1,(i,k)} = - |T| \frac{\partial\psi_{T,i}}{\partial x_k}. } \tag{21} \]

CR basisのgradientはelementwise constantなので， ここにquadratureは不要です．

13．discrete inf-sup condition

CR–P0 pairでは \[ \boxed{ \inf_{0\neq q_h\in Q_h} \sup_{0\neq\boldsymbol v_h\in V_h} \frac{ |b_h(\boldsymbol v_h,q_h)| }{ |\boldsymbol v_h|_{1,h} \|q_h\|_{L^2} } \ge \beta_0 > 0 } \tag{22} \] というmesh-independentなboundが必要です．

一つのmeshでmatrix rankがfullだったことと， family of meshesで \(\beta_0\) がuniformに正であることは別です．

14．CR interpolationがFortin mapになる

十分regularな \[ \boldsymbol v\in H_0^1(\Omega)^d \] にcomponentwise CR interpolation \(I_h^{CR}\boldsymbol v\) を適用すると， \(q_h\in Q_h\) がelementwise constantであることから \[ \boxed{ b_h( I_h^{CR}\boldsymbol v, q_h ) = b( \boldsymbol v, q_h ). } \tag{23} \]

つまりdivergence–pressure pairingを保存します．

さらに \[ |I_h^{CR}\boldsymbol v|_{1,h} \le C |\boldsymbol v|_{H^1(\Omega)^d} \tag{24} \] というstabilityがあれば， continuous inf-sup conditionをdiscrete spaceへ移せます．

semi-regularなanisotropic meshを扱う場合にも， このinterpolation stabilityをgeometryに一様に制御できるかが重要です．

15．CR–P0 velocityはelementwise divergence-free

CR velocityは各elementでaffineなので \[ \nabla\cdot\boldsymbol u_h \in P_0(T). \]

さらにCR0のedge-mean continuityとboundary conditionから \[ \int_\Omega \nabla_h\cdot\boldsymbol u_h\,dx = 0. \tag{25} \] したがって \[ \nabla_h\cdot\boldsymbol u_h \in Q_h. \]

式 (15) で \[ q_h= \nabla_h\cdot\boldsymbol u_h \] を選べば \[ \boxed{ \nabla_h\cdot\boldsymbol u_h = 0 \qquad \text{on every element}. } \tag{26} \]

CR–P0の重要な構造
incompressibilityはglobal averageだけではなく， elementwise constant divergenceがexactly zeroになる．

16．ただし「elementwise divergence-free = pressure robust」ではない

式 (26) は非常に強い性質ですが， standard CR methodが自動的にpressure robustになるという意味ではありません．

CR velocity spaceは \[ V_h\not\subset H_0^1(\Omega)^d \] なので，discrete divergence-free test functionにgradient forceを作用させたとき， nonconforming face termが残り得ます．

従ってstandard CR velocity errorはpressure approximationや \(\boldsymbol f\) のgradient componentの影響を受けることがあります．

pressure-robust modificationは後の回で改めて扱います．

17．Stokesの誤差解析は「nonconforming + mixed」

Poisson CRでは \[ \text{approximation} + \text{consistency} \] に分けました． Stokes CR–P0ではさらにpressureとinf-sup stabilityが加わります．

fixed \(\nu>0\) の下でschematically， \[ \begin{aligned} |\boldsymbol u-\boldsymbol u_h|_{1,h} + \|p-p_h\|_{L^2} \le C_\nu \Bigg[ & \inf_{\boldsymbol v_h\in V_h} |\boldsymbol u-\boldsymbol v_h|_{1,h} \\ &+ \inf_{q_h\in Q_h} \|p-q_h\|_{L^2} \\ &+ \sup_{0\neq\boldsymbol w_h\in V_h} \frac{ |\mathcal R_h(\boldsymbol w_h)| }{ |\boldsymbol w_h|_{1,h} } \Bigg], \end{aligned} \tag{27} \]

ここで \[ \mathcal R_h(\boldsymbol w_h) = a_h(\boldsymbol u,\boldsymbol w_h) + b_h(\boldsymbol w_h,p) - (\boldsymbol f,\boldsymbol w_h) \tag{28} \] がnonconforming consistency residualです．

18．manufactured solution

unit square \[ \Omega=(0,1)^2 \] で \[ \varphi(x,y) = x^2(x-1)^2y^2(y-1)^2 \tag{29} \] とし， \[ \boxed{ \boldsymbol u = \operatorname{rot}\varphi = \begin{pmatrix} \partial_y\varphi\\ -\partial_x\varphi \end{pmatrix}, \qquad p=x^2-y^2. } \tag{30} \]

このvelocityは \[ \nabla\cdot\boldsymbol u=0, \qquad \boldsymbol u|_{\partial\Omega}=0, \] pressureは \[ \int_\Omega p\,dx=0 \] を満たします．

\(\nu=1\) とし， \[ \boldsymbol f = -\Delta\boldsymbol u+\nabla p \tag{31} \] をexact sourceとして使います．

21．pressure meanを必ず監査する

pressureは定数分だけ不定なので， comparisonの前に \[ \int_\Omega p_h\,dx=0 \tag{34} \] を確認します．

pressure errorが大きいとき， 最初に疑うべきなのは

\[ \text{sign}, \quad \text{pressure normalisation}, \quad \text{inf-sup pair} \]

です． 単にmeshを細かくする前にここを監査します．

22．matrix rankだけではinf-sup testにならない

pressure constant modeを除いたsaddle matrixがnonsingularなら， そのmesh上ではdiscrete problemを解けます．

しかしfinite-element methodとして必要なのは， mesh familyに対して \[ \beta_h\ge\beta_0>0 \] が一様に成立することです．

従ってdebuggingでは

\[ \boxed{ \text{algebraic nonsingularity} \neq \text{uniform inf-sup stability} } \]

を明確に区別します．

23．anisotropic meshでは何を追加監査するか

強いanisotropyを許す場合は， CR interpolationのstabilityとdiscrete inf-sup constantが mesh geometryに対して一様かを確認する必要があります．

semi-regularity condition \[ \frac{H_T}{h_T}\le C \tag{35} \] の下では，shape regularityを要求せずに扱えるanisotropic mesh familyがあります．

このときも

\[ \boxed{ \text{mesh geometry} + \text{CR interpolation stability} + \text{discrete inf-sup} } \]

を一組として見ることが重要です．

24．ChatGPTへのStokes implementation audit prompt

Audit prompt
このCR–P0 Stokes codeを数学的に監査してください．
(1) velocity spaceがvector-valued CR0，pressure spaceがmean-zero \(P_0\) か，
(2) bilinear formが \(a_h(u_h,v_h)=\nu(\nabla_hu_h,\nabla_hv_h)\) か，
(3) \(b_h(v_h,q_h)=-(\operatorname{div}_hv_h,q_h)\) のsignが一貫しているか，
(4) pressure constant null modeを正しく除いているか，
(5) saddle matrixをSPDと誤認していないか，
(6) unstabilised P1–P1などinf-sup unstable pairを使っていないか，
(7) CR interpolationがpressure pairingを保存するFortin propertyを持つか，
(8) discrete inf-supを一つのmatrix rankだけで判断していないか，
(9) \(\operatorname{div}_hu_h=0\) がelementwiseに成立するか，
(10) elementwise divergence-free性とpressure robustnessを混同していないか，
(11) broken \(H^1\) velocity errorとpressure \(L^2\) errorが期待orderで収束するか
を順に確認してください．

25．第17回の結論

Stokes FEMでは， velocity spaceとpressure spaceを別々に実装するだけでは不十分です．

\[ \boxed{ \text{velocity approximation} + \text{pressure approximation} + \text{inf-sup stability} + \text{incompressibility} } \tag{36} \]

を一つのmethodとして設計する必要があります．

CR–P0では \[ \nabla_h\cdot\boldsymbol u_h=0 \] がelementwiseに成立し， 同時にstable velocity–pressure couplingを得られます．

Stokes elementを選ぶときは， polynomial degreeではなくinf-sup structureを見る．
