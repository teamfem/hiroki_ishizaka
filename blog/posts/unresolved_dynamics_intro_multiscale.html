はじめに――微細な動きを消してもよいのか？

入門シリーズ第1〜6回では，見えない変数の影響，安定性，近似縮約，記憶項と誤差を学びました．今回は，速く変わる微細な成分とゆっくり変わる大きな成分が共存するマルチスケール問題につなぎます．

微細な動きを消したとき，その影響はどこへ行くのでしょうか．

正確に消去すると記憶が現れることがあります．さらに時間尺度が十分に分離すると，その記憶を局所的な項に置き換えて近似できる場合があります．今回は，その条件と限界を一つの微分方程式から調べます．

1．遅い変数と速い変数

大きな物体の平均温度と，内部にある微細な温度差を想像してみましょう．前者はゆっくり変わり，後者は短い時間で緩和することがあります．

次の二変数モデルを考えます．

\[ \boxed{\begin{aligned} x'(t)&=-\alpha x(t)+\beta y(t),\\ \varepsilon y'(t)&=\gamma x(t)-y(t), \end{aligned}\qquad\varepsilon>0} \tag{1} \]

\(\alpha,\beta,\gamma\) は時間に依存しない実数とし，\(x(0)=x_0,\ y(0)=y_0\) です．\(0<\varepsilon\ll1\) は速い緩和の時間尺度を表します．ただし，\(y\) は \(\beta y\) を通じて \(x\) に影響するため，速いからといって無視してよいとは限りません．

2．速い変数を正確に消すと，記憶が残る

第二式を \(y'+\varepsilon^{-1}y=\gamma\varepsilon^{-1}x\) と書き，積分因子 \(e^{t/\varepsilon}\) を掛けます．積の微分を時刻0から積分して，

\[ \boxed{ y(t)=e^{-t/\varepsilon}y_0+ \frac{\gamma}{\varepsilon} \int_0^t e^{-(t-s)/\varepsilon}x(s)\,ds } \tag{2} \]

を得ます．これを第一式に代入すると，

\[ \boxed{\begin{aligned} x'(t)={}&-\alpha x(t)+\beta e^{-t/\varepsilon}y_0\\ &+\frac{\beta\gamma}{\varepsilon} \int_0^t e^{-(t-s)/\varepsilon}x(s)\,ds. \end{aligned}} \tag{3} \]

です．これは近似ではなく正確な変形です．見えない初期値の影響も残っています．このときの記憶核は

\[ \boxed{ K_\varepsilon(\tau)= \frac{\beta\gamma}{\varepsilon}e^{-\tau/\varepsilon}, \qquad \tau\geq0. } \tag{4} \]

です．

3．速い緩和があると，記憶は短くなる

重み \(g_\varepsilon(\tau)=\varepsilon^{-1}e^{-\tau/\varepsilon}\) は，常に正で，

\[ \boxed{\int_0^\infty g_\varepsilon(\tau)\,d\tau=1} \tag{5} \]

を満たします．\(\varepsilon\) が小さくなると，時間差 \(\tau=0\) の近くに強く集中します．

まず \(\varepsilon\) に依存しない一つの連続関数 \(x\) に対して，固定した \(t>0\) では，

\[ \boxed{ \frac1\varepsilon\int_0^t e^{-(t-s)/\varepsilon}x(s)\,ds \longrightarrow x(t)\quad(\varepsilon\to0) } \tag{6} \]

となります．記憶積分が，いまの値に近づくのです．しかし \(t=0\) では左辺は常に0なので，時刻0を含めて同じ収束を主張してはいけません．

重要な注意：実際の方程式(1)の解は \(\varepsilon\) によって変わるので，単に「各 \(\varepsilon\) の解が連続」と言うだけでは式(6)の極限を適用できません．後の第5節で示すように，固定時間区間で \(|x'(t)|\leq M_T\) を \(\varepsilon\) と無関係に確認することが必要です．このとき，

\[ \begin{aligned} &\left|\frac1\varepsilon\int_0^t e^{-(t-s)/\varepsilon}x(s)\,ds-x(t)\right|\\ &\qquad\leq e^{-t/\varepsilon}|x_0|+\varepsilon M_T \end{aligned} \]

が成り立ち，固定した \(t>0\) について極限を正当化できます．ここで積分の部分積分を使いました．

4．記憶を持たない有効方程式へ

十分小さな \(\varepsilon\) に対して，式(2)から \(y(t)\approx\gamma x(t)\) を期待できます．第一式へ代入すると，

\[ \boxed{ X'(t)=\lambda X(t),\qquad \lambda=-\alpha+\beta\gamma,\qquad X(0)=x_0, } \tag{7} \]

という一変数の有効方程式になります．その解は \(X(t)=x_0e^{\lambda t}\) です．

式(3)は正確な状態消去ですが，式(7)は近似的な縮約です．だからこそ，どの程度近いかを別に証明する必要があります．

5．近似誤差は本当に小さくなるのか？

速い変数とその近似の差を \(w(t)=y(t)-\gamma x(t)\)，\(w_0=y_0-\gamma x_0\) と置きます．元の方程式から，

\[ \varepsilon w'(t)=-w(t)-\varepsilon\gamma x'(t) \]

です．これを解けば，

\[ \boxed{ w(t)=e^{-t/\varepsilon}w_0 -\gamma\int_0^t e^{-(t-s)/\varepsilon}x'(s)\,ds. } \tag{8} \]

一方，\(x'=\lambda x+\beta w\) なので，\(X\) との差を積分で表すと，

\[ \boxed{x(t)-X(t)= \beta\int_0^t e^{\lambda(t-s)}w(s)\,ds.} \tag{9} \]

です．固定した有限時間区間 \(0\leq t\leq T\) で \(|x'(t)|\leq M_T\) とすると，

\[ \int_0^T |w(t)|\,dt\leq \varepsilon|w_0|+\varepsilon|\gamma|T M_T \]

となります．したがって，

\[ \boxed{\begin{aligned} |x(t)-X(t)|\leq{}& \varepsilon|\beta|e^{\max\{\lambda,0\}T}\\ &\times\bigl(|y_0-\gamma x_0|+|\gamma|TM_T\bigr), \quad0\leq t\leq T. \end{aligned}} \tag{10} \]

です．\(M_T\) を \(\varepsilon\) に依存しない値に選べれば，固定時間区間での誤差は \(O(\varepsilon)\)，つまり定数倍の \(\varepsilon\) 以下です．

発展：\(M_T\) を独立に選べることの証明

式(2)から \(m(t)=\sup_{0\leq s\leq t}|x(s)|\) と置くと，\(|y(t)|\leq|y_0|+|\gamma|m(t)\) です．第一式を積分して，

\[ m(t)\leq |x_0|+|\beta|T|y_0| +(|\alpha|+|\beta\gamma|)\int_0^t m(s)\,ds \]

を得ます．この不等式を用いると，

\[ m(t)\leq X_T:=(|x_0|+|\beta|T|y_0|) e^{(|\alpha|+|\beta\gamma|)T}. \]

したがって \(M_T=(|\alpha|+|\beta\gamma|)X_T+|\beta||y_0|\) と選べます．これは固定した \(x_0,y_0,\alpha,\beta,\gamma,T\) に対して \(\varepsilon\) に依存しません．

この証明は有限時間の結果です．長時間の一様な近似を主張するには，さらに安定性などの仮定が必要です．

6．時刻0に残る「初期層」

式(8)の \(e^{-t/\varepsilon}w_0\) は，初期状態 \(y_0\neq\gamma x_0\) のずれを短時間で減衰させます．この速い変化を初期層と呼びます．

保持した \(x\) の近似誤差は小さくなりますが，\(y\) を \(\gamma X\) で近似する場合，

\[ |y(0)-\gamma X(0)|=|y_0-\gamma x_0| \tag{11} \]

です．初期値が釣り合っていなければ，\(y\) の誤差まで時刻0から一様に小さくなるとは限りません．

7．具体例――安定性はどう変わる？

\(\alpha=2,\ \beta=\gamma=1\) なら，有効方程式は \(X'=-X\) で，\(X(t)=x_0e^{-t}\) です．元の二変数系の \(x\) は，

\[ \boxed{ \varepsilon x''+(1+2\varepsilon)x'+x=0, \quad x'(0)=-2x_0+y_0 } \tag{12} \]

を満たします．\(\varepsilon\) が小さいほど，適切に固定した初期値での \(x\) の解は \(X\) に近づきます．

ただし，すべての係数で安定性が保たれるわけではありません．元の二変数系の固有値を決める式は，

\[ \boxed{ \varepsilon r^2+(1+\alpha\varepsilon)r+ (\alpha-\beta\gamma)=0. } \tag{13} \]

です．\(\alpha>0,\ \beta,\gamma\geq0\) の場合，\(\alpha>\beta\gamma\) なら元の系も有効モデルも指数安定，等号なら安定だが漸近安定ではなく，\(\alpha<\beta\gamma\) なら不安定です．

例えば \(\alpha=1,\ \beta=1,\ \gamma=2\) なら実際には不安定です．しかし \(y=0\) と単純に置いた近似 \(x'=-x\) は安定と予測します．速い変数をただ0と置くのは危険です．

8．均質化法，MsFEM，HMMとは何が違う？

今回の \(\varepsilon\) は時間尺度でした．一方，微細な材料構造の空間尺度を \(\delta\) とする問題もあります．例として，

\[ \frac{\partial u_\delta}{\partial t} -\nabla\cdot(a(\xi/\delta)\nabla u_\delta)=0 \tag{14} \]

があります．

考え方主な目的
均質化法微細係数から有効係数を導く
MsFEM微細構造を粗い計算基底に反映する
HMM巨視的計算に必要な情報を微視的計算から得る
未解像ダイナミクスの安定縮約省いた成分の影響や安定性，近似誤差を調べる

これらは組み合わせられる可能性があります．ただし，空間の微細構造から必ず時間的な記憶が現れるわけではありません．例えば通常の周期係数の熱方程式では，局所的な有効熱方程式が得られる典型例があります．

9．練習問題

  1. 問題1：\(\varepsilon y'=-y,\ y(0)=2\) を解いてください．
  2. 問題2：\(\alpha=3,\ \beta=1,\ \gamma=2\) なら有効方程式は何ですか．
  3. 問題3：\(\alpha=1,\ \beta=\gamma=1,\ \varepsilon=0.2\) で元の系の安定性を判定してください．
  4. 問題4（発展）：\(x(t)\equiv1\) の場合に式(6)の左辺を計算してください．
練習問題の解答と計算過程を見る

問題1：\(y(t)=2e^{-t/\varepsilon}\) です．

問題2：\(\lambda=-3+2=-1\) より \(X'=-X\) です．

問題3：式(13)は \(0.2r^2+1.2r=0\) なので，固有値は0と \(-6\) です．安定ですが漸近安定ではありません．

問題4：\(\varepsilon^{-1}\int_0^t e^{-(t-s)/\varepsilon}\,ds=1-e^{-t/\varepsilon}\) で，固定した \(t>0\) では1に近づきます．

おわりに――微細構造を消すと何が残るのか

今回の模型から，正確な消去は記憶と初期値項を残すこと，時間尺度の分離が局所的な有効方程式を生む場合があること，有限時間の近似誤差と長時間の安定性を区別することを学びました．

二変数の例の数学は既知の基本事項です．研究として重要なのは，より複雑な偏微分方程式や異方性を含む問題で，どの縮約が安定性を保ち，どの条件で誤差を評価できるかを明確にすることです．

微細な動きを計算しないことと，その影響を無視してよいことは違います．
