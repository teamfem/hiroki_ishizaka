第8回：良い異方性要素と悪い異方性要素 — shape regularity・maximum angle・semi-regularity

ChatGPTで作る有限要素プログラム入門 第8回
29th August 2026

はじめに――「良い要素」の意味を先に決める

第7回では，強いaspect ratioを持っていても最大角が悪化しないmeshと， 最大角が \(\pi\) へ近づくmeshを実際に比較しました． 前者では標準的なP1収束次数が保たれ，後者では観測次数が悪化しました．

しかし，「良い要素」「悪い要素」という言葉は，目的を指定しないと曖昧です． 補間誤差にとって良い要素，linear solverにとって良い要素， 離散最大値原理にとって良い要素は，同じとは限りません．

第8回でいう「良い」
主としてP1補間・Galerkin誤差解析に必要な要素幾何という意味で使う．
DMP，maximum-norm estimate，linear-system conditioningには， これとは別の条件が必要になる場合がある．

この回では，既存の 「有限要素法ではなぜメッシュの幾何条件が必要なのか」， 「正則性と準正則性を角度を使わずに表す」， 「長方形の三角形分割を \(Q_T\) と \(H_T/h_T\) で調べる」 で整理した幾何条件を，ChatGPT生成FEMコードのmesh certificateとして使える形にまとめ直します．

1．条件は一個の三角形ではなくmesh familyに課す

一つの非退化三角形を固定すれば，以下で使う幾何量はすべて有限です． 問題になるのは，細分化して \[ \{\mathcal T_h\}_{h\downarrow0} \] というmesh familyを作ったときに，最悪の要素がどのように変化するかです．

したがって，コードでも一回のmeshだけを見て good mesh と判定するのではなく，各levelで \[ \max_{T\in\mathcal T_h}Q_T, \qquad \max_{T\in\mathcal T_h}\frac{H_T}{h_T}, \qquad \max_{T\in\mathcal T_h}\theta_{\max,T} \tag{1} \] を保存し，refinementに対するtrendを見る必要があります．

2．shape regularityを測る \(Q_T\)

三角形 \(T\) の直径を \[ h_T:=\operatorname{diam}(T) \] とし，面積を \(|T|\) とします． 本サイトの幾何シリーズと同じく \[ \boxed{ Q_T:=\frac{h_T^2}{|T|} } \tag{2} \] と置きます．

2次元では，mesh familyがshape-regularであることは \[ \boxed{ \sup_h\max_{T\in\mathcal T_h}Q_T<\infty } \tag{3} \] と同値です． これは古典的な \[ \frac{h_T}{\rho_T}\le C \] というinscribed-ball conditionや，minimum angleを0から一様に離す条件と同じ種類の制御です．

従ってshape regularityは，極端に細長い三角形を基本的に排除します． 異方性meshを積極的に使いたい場合には，この条件は強すぎることがあります．

3．semi-regularityを測る \(H_T/h_T\)

第6回と同じstandard labellingを使います． 最長辺を \(p_2p_3\)，反対頂点を \(p_1\) とし， \[ h_1=|p_1-p_2|, \qquad h_2=|p_1-p_3|, \qquad h_2\le h_1. \tag{4} \]

幾何パラメータを \[ H_T := \frac{h_1h_2}{|T|}h_T \tag{5} \] と定めると， \[ \boxed{ A_T := \frac{H_T}{h_T} = \frac{h_1h_2}{|T|} } \tag{6} \] です．

mesh familyがsemi-regularであるとは \[ \boxed{ \sup_h\max_{T\in\mathcal T_h}A_T<\infty } \tag{7} \] という意味です．

4．maximum-angle conditionとsemi-regularityは2次元で同じ幾何を測る

最長辺 \(p_2p_3\) の対角，すなわち \(p_1\) の角を \[ \theta_{\max,T} \] とします． これは三角形の最大角です．

面積は \[ |T| = \frac12 h_1h_2\sin\theta_{\max,T} \] なので， \[ \boxed{ A_T = \frac{2}{\sin\theta_{\max,T}} } \tag{8} \] です．

したがって \[ A_T\le C \] という条件は， ある \(\gamma_0<\pi\) が存在して \[ \theta_{\max,T}\le\gamma_0 \tag{9} \] とするmaximum-angle conditionと同値です．

minimum angleは0へ近づいても構いません． つまりsemi-regularityは，強いaspect ratioを許しつつ， 最大角が \(\pi\) へ近づく種類の扁平化だけを排除する条件です．

5．shape regularityはsemi-regularityより強い

standard edge lengthsは \[ h_1\le h_T, \qquad h_2\le h_T \] なので \[ A_T = \frac{h_1h_2}{|T|} \le \frac{h_T^2}{|T|} = Q_T. \tag{10} \]

従って \[ \boxed{ \text{shape regular} \Longrightarrow \text{semi-regular} } \tag{11} \] です． 逆は成立しません． その最も分かりやすい例が，細長い直角三角形です．

6．三つの典型例を分類する

6.1 等方的な良い要素

正三角形 \[ T_{\mathrm{eq}} = \operatorname{conv} \left\{ (0,0)^{\top}, (1,0)^{\top}, \left(\frac12,\frac{\sqrt3}{2}\right)^{\top} \right\} \] では \[ Q_T = A_T = \frac{4}{\sqrt3} \approx2.3094. \tag{12} \] 最大角は60°です． shape-regularでもsemi-regularでもあります．

6.2 細長いが「良い」異方性要素

\[ T_\varepsilon^{\mathrm{ani}} = \operatorname{conv} \{(0,0)^{\top},(1,0)^{\top},(0,\varepsilon)^{\top}\}, \qquad \varepsilon\downarrow0 \tag{13} \] を考えます．

面積は \[ |T_\varepsilon^{\mathrm{ani}}| = \frac{\varepsilon}{2}, \] 直径は \[ h_T=\sqrt{1+\varepsilon^2} \] なので， \[ Q_T = \frac{2(1+\varepsilon^2)}{\varepsilon} \longrightarrow\infty. \tag{14} \] 従ってshape regularityは失われます．

一方，standard lengthsは \[ h_1=1, \qquad h_2=\varepsilon \] なので \[ A_T = \frac{h_1h_2}{|T|} = 2. \tag{15} \] maximum angleは常に90°です． 従ってこのfamilyは \[ \boxed{ \text{not shape-regular} \quad\text{but}\quad \text{semi-regular} } \] です．

6.3 最大角が退化する悪い要素

\[ T_\delta^{\mathrm{flat}} = \operatorname{conv} \{(0,\delta)^{\top},(-1,0)^{\top},(1,0)^{\top}\}, \qquad \delta\downarrow0 \tag{16} \] を考えます．

このとき \[ h_T=2, \qquad |T|=\delta, \] なので \[ Q_T = \frac{4}{\delta} \longrightarrow\infty. \tag{17} \] また \[ h_1=h_2=\sqrt{1+\delta^2} \] なので \[ A_T = \frac{1+\delta^2}{\delta} \longrightarrow\infty. \tag{18} \] 最大角も \[ \theta_{\max,T}\longrightarrow\pi. \] 従ってshape regularityもsemi-regularityも失われます．

7．数値で比べると違いがはっきりする

thin right triangleとflat triangleは，どちらも \(Q_T\) が非常に大きいので， shape regularityだけでは同じ「悪い要素」に見えます．

しかし \(A_T\) を見ると， \[ 2 \quad\text{と}\quad 10^3 \] で明確に分かれます． これが異方性解析でsemi-regularityを導入する意味です．

8．aspect ratioだけでも判定できない

第6・7回でも見たように，aspect ratioや \[ \kappa_2(J_T) \] が大きいこと自体は，maximum-angle deteriorationを意味しません．

thin right triangleでは \[ \kappa_2(J_T)\sim\varepsilon^{-1} \] ですが \[ A_T=2. \] 一方，flat triangleでもJacobian condition numberは大きくなりますが， 同時に \[ A_T\to\infty. \]

従ってmesh geometryの監査では

\[ \text{aspect ratio} \quad\text{or}\quad \kappa(J_T) \]

だけを使ってgood / badを決めるべきではありません．

9．semi-regularityと \(H(h)\to0\) も同じではない

mesh全体について \[ H(h) := \max_{T\in\mathcal T_h}H_T \tag{19} \] とします．

もし \[ h:=\max_{T\in\mathcal T_h}h_T\to0 \] かつsemi-regularity \[ H_T/h_T\le C \] が成立すれば， \[ H(h) \le Ch \longrightarrow0. \tag{20} \] 従って \[ \boxed{ \text{semi-regularity}+h\to0 \Longrightarrow H(h)\to0. } \tag{21} \]

しかし逆は一般には成立しません． 最大角条件を破って \[ H_T/h_T\to\infty \] となっても， \(H_T\) 自身は0へ向かうmesh familyがあり得ます．

この区別は 「最大角条件とBabuška–Aziz反例」 で詳しく扱っています． maximum-angle conditionは非常に有用な安全側の十分条件ですが， それを破ったという事実だけから，特定の有限要素計算が必ず非収束になるとは言えません．

10．「良い異方性要素」は解の方向性と組み合わせて初めて有効になる

semi-regularな細長い要素だから，自動的に高精度になるわけではありません． 異方性補間評価は方向別に \[ |u-I_Tu|_{H^1(T)} \le C \sum_{i=1}^{2} h_i \left\| \frac{\partial u}{\partial r_i} \right\|_{H^1(T)} \tag{22} \] という形を持ちます．

従って短い方向を \[ r_2 \] としたなら，その方向に解が強く変化しているときにmesh anisotropyが有効です． 解の変化が弱い方向を過剰に細分化しても，自由度を増やすだけで効率的とは限りません．

幾何条件が保証すること
semi-regularityは，異方的な方向情報を保持した補間評価を aspect ratioに対してrobustに扱うための幾何学的基盤である．
mesh adaptationそのものの最適性は，解の方向微分との対応まで見なければ決まらない．

11．「良い」の意味はDMPでは変わる

ここまでのgood / badは主として補間・energy errorの観点でした． しかし 「幾何条件から補間・DMP・\(L^\infty\)解析へ何が引き継げるか」 で整理したように，DMPには別の角度条件が現れます．

2次元Poisson P1要素では，異なる二頂点に対応する局所剛性行列成分は \[ \int_T \nabla\phi_i\cdot\nabla\phi_j\,dx = -\frac12\cot\theta_k \tag{23} \] と書けます．

例えば最大角120°の固定形状三角形はshape-regularかつsemi-regularです． それでも \[ -\frac12\cot120^\circ = \frac{1}{2\sqrt3} >0. \tag{24} \] したがって，標準的なM-matrix型DMP条件には適しません．

つまり \[ \boxed{ \text{good for interpolation} \not\Longrightarrow \text{good for DMP}. } \tag{25} \]

13．Pythonでmesh geometry certificateを作る

一つの三角形に対し，\(Q_T\)，\(A_T\)，最小角，最大角を返す関数を作ります． 

import numpy as np


def triangle_geometry_certificate(P):
    P = np.asarray(P, dtype=float)

    pairs = [(0, 1), (1, 2), (2, 0)]

    edge_lengths = np.array([
        np.linalg.norm(P[i] - P[j])
        for i, j in pairs
    ])

    hT = np.max(edge_lengths)

    J = np.column_stack((
        P[1] - P[0],
        P[2] - P[0]
    ))

    area = 0.5 * abs(np.linalg.det(J))

    if area <= 0.0:
        raise ValueError("Degenerate triangle")

    QT = hT**2 / area

    # standard labelling:
    # p2-p3 is the longest edge
    m = np.argmax(edge_lengths)
    i2, i3 = pairs[m]
    i1 = list(
        {0, 1, 2} - {i2, i3}
    )[0]

    d12 = np.linalg.norm(P[i2] - P[i1])
    d13 = np.linalg.norm(P[i3] - P[i1])

    h1 = max(d12, d13)
    h2 = min(d12, d13)

    AT = h1 * h2 / area

    angles = []

    for i in range(3):
        j = (i + 1) % 3
        k = (i + 2) % 3

        a = P[j] - P[i]
        b = P[k] - P[i]

        cos_theta = (
            np.dot(a, b)
            / (
                np.linalg.norm(a)
                * np.linalg.norm(b)
            )
        )

        cos_theta = np.clip(
            cos_theta,
            -1.0,
            1.0
        )

        angles.append(
            np.arccos(cos_theta)
        )

    return {
        "hT": hT,
        "area": area,
        "Q_T": QT,
        "H_over_h": AT,
        "min_angle_deg":
            np.degrees(min(angles)),
        "max_angle_deg":
            np.degrees(max(angles)),
        "cond_J_raw":
            np.linalg.cond(J)
    }

14．mesh familyではmax値の履歴を保存する

def audit_mesh_geometry(nodes, triangles):
    max_Q = 0.0
    max_A = 0.0
    max_angle = 0.0
    min_angle = 180.0

    for tri in triangles:
        data = triangle_geometry_certificate(
            nodes[tri]
        )

        max_Q = max(
            max_Q,
            data["Q_T"]
        )

        max_A = max(
            max_A,
            data["H_over_h"]
        )

        max_angle = max(
            max_angle,
            data["max_angle_deg"]
        )

        min_angle = min(
            min_angle,
            data["min_angle_deg"]
        )

    return {
        "max_Q": max_Q,
        "max_H_over_h": max_A,
        "max_angle_deg": max_angle,
        "min_angle_deg": min_angle
    }

history = []

15．ChatGPTへの質問も「目的」を指定する

Audit prompt
この三角形mesh familyをP1有限要素近似の観点から監査してください．
aspect ratioだけでgood / badを決めず，levelごとに
(1) \(Q_T=h_T^2/|T|\) の最大値，
(2) \(H_T/h_T\) の最大値，
(3) minimum angleとmaximum angle，
(4) \(H(h)=\max_T H_T\)，
を計算してください．
shape regularity，semi-regularity，maximum-angle condition，\(H(h)\to0\)を区別し， どの条件が一様に成り立っているかを説明してください． DMPについて判断する場合は，nonobtuse / metric-angle条件を別に検査してください．

16．第8回の結論

異方性要素を分類するとき，

\[ \text{thin} = \text{bad} \]

ではありません． P1補間・Galerkin誤差の観点では，

\[ \boxed{ Q_T\ \text{large} \quad\text{but}\quad H_T/h_T\ \text{bounded} } \]

という要素は，shape regularityを破りながら semi-regularityを保つ「良い異方性要素」になり得ます．

一方， \[ H_T/h_T\to\infty \] はmaximum angleが \(\pi\) へ近づく種類の退化を表し， 標準的な一様誤差評価を失う警告になります．

ただし，maximum-angle conditionは安全側の十分条件であり， その破綻だけからすべての有限要素計算の非収束を結論してはいけません． また，semi-regularityが成立してもDMPやmaximum-norm解析には追加条件が必要です．

mesh geometryの監査原則
「何にとって良いmeshなのか」を先に決める．
その上でshape regularity，semi-regularity，angle condition， \(H(h)\)，conditioningを混同せずに調べる．
