第7回：異方性P1要素は本当に正しく動くか — patch test・誤差・condition number

ChatGPTで作る有限要素プログラム入門 第7回
29th August 2026

はじめに――「細長い要素」を一括りにしない

第6回では，異方性三角形のJacobianを \[ J_T=A_T\widetilde A\widehat A \] と分け， \[ \widehat A \] に方向別scale， \[ \widetilde A \] に角度・flatness， \[ A_T \] にrotation/reflectionを持たせました．

今回はその考え方を実際のP1有限要素計算へ入れます． 比較するのは，

  1. semi-regularな強異方性メッシュ，
  2. maximum angleが \(\pi\) に近づく扁平メッシュ

です． どちらもJacobianのcondition numberは大きくなりますが， 有限要素近似の幾何として同じ意味ではありません．

今回の問い
大きなaspect ratio，large \(\kappa(J_T)\)，large \(\kappa(A)\)， maximum-angle deteriorationは同じ現象なのか？
答えはnoです．

1．モデル問題

単位正方形 \[ \Omega=(0,1)^2 \] で \[ -\Delta u=f \qquad\text{in }\Omega, \tag{1} \] \[ u=0 \qquad\text{on }\partial\Omega \tag{2} \] を考えます． 厳密解は \[ u(x,y)=\sin(\pi x)\sin(\pi y), \tag{3} \] 従って \[ f(x,y)=2\pi^2\sin(\pi x)\sin(\pi y). \tag{4} \]

有限要素法は第3・4回と同じ連続P1 Galerkin法です． つまり，今回変更するのはmesh geometryだけです．

2．Mesh A：semi-regularな強異方性メッシュ

\(x\) 方向を \(n\) 分割，\(y\) 方向を \(n^2\) 分割します． 従って \[ h_x=\frac1n, \qquad h_y=\frac1{n^2}, \tag{5} \] なのでaspect ratioは \[ \frac{h_x}{h_y}=n \longrightarrow\infty. \tag{6} \]

各長方形を対角線で二分して三角形にします． 各三角形は直角三角形なので最大角は常に \[ \theta_{\max}=\frac{\pi}{2}. \] 第6回のstandard positionを使うと \[ \frac{H_T}{h_T}=2 \tag{7} \] であり，\(n\) に依存しません．

一方，標準化したJacobianはscaleの違いを直接持つため \[ \kappa_2(J_T)=n. \tag{8} \] つまり，

\[ \boxed{ \kappa_2(J_T)\to\infty \quad\text{でも}\quad H_T/h_T=2 } \]

です．

3．Mesh B：最大角が \(\pi\) に近づくメッシュ

今度は単位正方形を \(n\times n\) の正方形に分けます． 各cellの幅を \[ h=\frac1n \] とします．

各cell \[ [ih,(i+1)h]\times[jh,(j+1)h] \] の内部に \[ c_{ij} = \left( \left(i+\frac12\right)h,\, jh+h^2 \right) \tag{9} \] を置き，cellの四隅と \(c_{ij}\) を結んで4個の三角形にします．

bottom edgeを底辺とする三角形は，高さが \[ h^2 \] しかありません． その最大角は細分化とともに \(\pi\) へ近づきます．

このbad triangleでは \[ h_1=h_2 = h\sqrt{\frac14+h^2}, \] \[ |T| = \frac{h^3}{2}, \] したがって \[ \boxed{ \frac{H_T}{h_T} = \frac{1}{2h}+2h = \frac n2+\frac2n } \tag{10} \] です．従って \[ \frac{H_T}{h_T}\to\infty. \]

さらに \[ H_T = \frac12+\frac{2}{n^2} \longrightarrow\frac12, \tag{11} \] なので，このmesh familyでは \[ \max_T H_T\to0 \] というより弱いanisotropic convergence conditionさえ満たしません．

ここで過剰な結論を出さない
semi-regularityや \(H(h)\to0\) は，所定の誤差評価を一様に得るための十分条件です． それを破ったからといって，あらゆる右辺・あらゆる解で有限要素解が必ず発散するわけではありません． 今回のMesh Bとsmooth solutionでは，少なくとも計算した範囲で誤差は減っています．

8．Jacobianのcondition numberは両方で大きくなる

standard positionで見ると， Mesh Aでは \[ \kappa_2(J_T)=n, \tag{15} \] Mesh Bの最も扁平な三角形では \[ \kappa_2(J_T) = \frac{n}{2} \qquad(n\ge4). \tag{16} \]

つまり両方とも \[ \kappa_2(J_T)=O(n) \] です． ところが \[ \frac{H_T}{h_T} = 2 \] と \[ \frac{H_T}{h_T} \sim\frac n2 \] で幾何学的意味は全く違います．

この事実だけでも，

\[ \boxed{ \text{large }\kappa(J_T) \not\Longleftrightarrow \text{bad maximum angle} } \]

であることが分かります．

\[ \boxed{ \text{approximation geometry} \neq \text{algebraic conditioning} } \]

を確認することです．

10．patch testの丸め誤差にもconditioningが見える

Mesh Aのpatch-test errorは \[ 10^{-15},10^{-14},10^{-13} \] と少しずつ大きくなりました． 離散化誤差は0なので，この増加は主に浮動小数点演算とlinear-system conditioningの影響です．

したがって \[ u_h=u \] という数学的exactnessと， computer arithmeticで得られる誤差の大きさは区別する必要があります．

11．二つのmesh familyをPythonで作る

11.1 semi-regularな強異方性mesh

def make_good_anisotropic_mesh(n):
    nx = n
    ny = n * n

    xs = np.linspace(0.0, 1.0, nx + 1)
    ys = np.linspace(0.0, 1.0, ny + 1)

    nodes = np.array([
        [x, y]
        for y in ys
        for x in xs
    ])

    def idx(i, j):
        return j * (nx + 1) + i

    triangles = []

    for j in range(ny):
        for i in range(nx):
            v00 = idx(i,     j)
            v10 = idx(i + 1, j)
            v01 = idx(i,     j + 1)
            v11 = idx(i + 1, j + 1)

            triangles.append(
                [v00, v10, v11]
            )
            triangles.append(
                [v00, v11, v01]
            )

    return nodes, np.array(
        triangles,
        dtype=int
    )

11.2 maximum angleが悪化するmesh

def make_bad_flat_mesh(n):
    h = 1.0 / n

    nodes = [
        [i * h, j * h]
        for j in range(n + 1)
        for i in range(n + 1)
    ]

    def idx(i, j):
        return j * (n + 1) + i

    triangles = []

    for j in range(n):
        for i in range(n):
            v00 = idx(i,     j)
            v10 = idx(i + 1, j)
            v11 = idx(i + 1, j + 1)
            v01 = idx(i,     j + 1)

            center = [
                (i + 0.5) * h,
                j * h + h * h
            ]

            vc = len(nodes)
            nodes.append(center)

            triangles += [
                [v00, v10, vc],
                [v10, v11, vc],
                [v11, v01, vc],
                [v01, v00, vc]
            ]

    return (
        np.array(nodes, dtype=float),
        np.array(triangles, dtype=int)
    )

12．anisotropic geometry auditをsolverと分離する

有限要素solverは第3・4回のstandard Jacobianでそのままassemblyします． 一方，mesh auditでは第6回のstandard-position decompositionを使い， 

max_cond_J = 0.0
max_H_over_h = 0.0
max_angle = 0.0

for tri in triangles:
    data = anisotropic_triangle_decomposition(
        nodes[tri]
    )

    max_cond_J = max(
        max_cond_J,
        np.linalg.cond(
            data["J_direct"]
        )
    )

    max_H_over_h = max(
        max_H_over_h,
        data["H_over_h"]
    )

    theta = np.arcsin(
        min(1.0, 2.0 / data["H_over_h"])
    )

    # for the standard-labelled triangle,
    # theta is the maximum angle only after
    # selecting the correct branch;
    # compute it directly in production code.

といった診断を別に持ちます． angleについては \(\sin\theta\) だけではacute/obtuseのbranchが区別できないため， 実装ではdot productや余弦定理から最大角を直接計算する方が安全です．

14．ChatGPTに「細長いから悪い」と言わせない

Audit prompt
この異方性P1メッシュを評価してください． 単にaspect ratioや \(\kappa(J_T)\) だけで良否を判定せず，
(1) standard-position \(h_1,h_2\)，
(2) \(H_T/h_T\)，
(3) maximum angle，
(4) linear patch test，
(5) \(L^2\)・\(H^1\)相対誤差とobserved rate，
(6) stiffness matrixのcondition number，
を別々に計算し，approximation geometryとalgebraic conditioningを混同しないでください．

このように指定しないと，AIはしばしば 「aspect ratioが大きい → bad mesh」 と短絡します． 異方性有限要素法では，そこを分ける必要があります．

15．第7回の結論

今回の数値実験から，少なくとも次の四つを区別する必要があります．

\[ \text{anisotropic scale}, \qquad \text{angle degeneration}, \qquad \text{polynomial reproduction}, \qquad \text{linear-system conditioning}. \]

特に， \[ \kappa(J_T)\to\infty \] でもsemi-regularなmeshは作れます． また，maximum angleが悪化してもlinear patch testは通ります． 逆に，semi-regularな強異方性meshでも大域剛性行列はかなりill-conditionedになり得ます．

異方性FEMの監査では，一つの数値だけを見てはいけない
geometry，approximation，exactness，conditioningを分離して診断する．

次回はこの結果を受けて， 「良い異方性要素」と「悪い異方性要素」を幾何条件としてどう分類するか を整理します．
