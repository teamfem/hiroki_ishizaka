Bakhvalov–Shishkin meshとS-type mesh：最適性と幾何条件

異方性有限要素法の幾何学的基礎 第9回
1st August 2026 New

はじめに

第7回ではpiecewise-uniformなShishkin meshを，第8回では discrete layerに合わせて幅を徐々に増加させるBakhvalov-type meshを扱いました． 今回は，この二つの考え方を結び付けるBakhvalov–Shishkin meshと， それを含むS-type meshの一般的な枠組みを整理します．

S-type meshでは，遷移点をShishkin型の \(O(\varepsilon\ln N)\) に保ちながら，層領域内部の格子点を 一般のmesh-generating functionで配置します．したがって，Shishkin meshも Bakhvalov–Shishkin meshも，同じS-type meshの構成に含められます [3]–[6]．

一方，本連載で用いている \[ Q_T=\frac{h_T^2}{|T|_2}, \qquad \frac{H_T}{h_T} \] は，要素形状とsemi-regularityを測る指標です [1]，[2]． S-type meshの「最適性」と，この幾何学的な正則性・準正則性は別概念です． 今回は，この違いを明確にします．

今回の結論
  • S-type meshは，一つのメッシュではなく，生成関数によって定義されるlayer-adapted meshのクラスです．
  • mesh-characterizing function \(\psi=e^{-\varphi}\) を使うと，多くの誤差評価に \(\max|\psi'|\) が現れます．
  • Shishkin meshでは \(\max|\psi'|=O(\ln N)\) ですが，Bakhvalov–Shishkin meshでは一様有界です．
  • この意味でBakhvalov–Shishkin meshは「optimal S-type mesh」と呼ばれます．
  • しかし二次元の直角三角形分割では，両者ともparameter-uniformには準正則だが非正則です．

1．Bakhvalov-type meshとの違い

第8回で扱った代表的なBakhvalov-type meshでは，層領域の終端が \[ O\!\left(\varepsilon\ln\frac1\varepsilon\right) \] に置かれます．生成関数は主として \(\varepsilon\) に依存し，境界付近の \(O(\varepsilon/N)\) の幅から外側の幅へgradingします．

これに対してBakhvalov–Shishkin meshでは，Shishkin meshと同様に遷移点を \[ O(\varepsilon\ln N) \] に置きます．ただし，層領域を一様分割する代わりに，Bakhvalov型の対数関数で 格子点を配置します．したがって名称にある

  • Bakhvalov：層領域内部を指数層に合わせてgradingする，
  • Shishkin：遷移点を \(\varepsilon\ln N\) 型にする，

という二つの特徴を併せ持ちます．Bakhvalov–Shishkin meshはBakhvalov-type mesh一般と 同じものではなく，S-type meshの代表例です．

2．一次元S-type meshの定義

区間 \([0,1]\) の左端 \(x=0\) に指数境界層があり，その減衰率を \(\beta>0\) とします．分割数 \(N\) は偶数とし，多項式次数などに応じた定数を \(\sigma>0\) とします．遷移点を \[ \lambda :=\min\left\{ \frac12, \frac{\sigma\varepsilon}{\beta}\ln N \right\} \] と定義します．以下では層が十分薄く， \[ \lambda=\frac{\sigma\varepsilon}{\beta}\ln N \lt\frac12 \] となる場合を中心に考えます．

層領域の生成関数を \[ \varphi:[0,1/2]\longrightarrow[0,\ln N] \] とし，\(\varphi\) は単調増加で \[ \varphi(0)=0, \qquad \varphi(1/2)=\ln N \] を満たすとします．細かい領域の格子点を \[ x_i =\frac{\sigma\varepsilon}{\beta} \varphi\!\left(\frac{i}{N}\right), \qquad 0\le i\le\frac N2 \] で定めます．外側の領域は一様に \[ x_i =1-\frac{2(1-\lambda)}{N}(N-i), \qquad \frac N2\le i\le N \] と分割します．

遷移点の係数

\(\sigma\) は飾りではありません．多項式次数，層の減衰率，対象とするノルムに応じて 選ぶ必要があります．代表的には次数 \(k\) に対して \(\sigma\ge k+1\) が現れます． 一次要素なら基準値は \(\sigma=2\) です．

3．mesh-characterizing function \(\psi\)

S-type meshでは，生成関数 \(\varphi\) そのものに加えて \[ \boxed{ \psi(t):=e^{-\varphi(t)} } \] を導入します．これをmesh-characterizing functionと呼びます．端点では \[ \psi(0)=1, \qquad \psi(1/2)=\frac1N \] です．

S-type mesh上の有限要素法では，多くの場合，誤差評価が模式的に \[ \|u-u_h\| \le C\left( N^{-1} \max_{0\le t\le1/2}|\psi'(t)| \right)^k \] という形になります．ここでノルム，次数，追加因子は問題と数値手法によって異なりますが， \(N^{-1}\max|\psi'|\) がメッシュの精度を特徴付けるという点が重要です [3]，[6]．

この枠組みでは \[ \max_{0\le t\le1/2}|\psi'(t)|\le C \] を \(N\) と \(\varepsilon\) に一様な定数で満たすメッシュを， optimal S-type meshと呼びます．ここでのoptimalは， shape regularityやsemi-regularityの意味ではありません．

4．Shishkin meshをS-type meshとして書く

層領域を一様分割するShishkin meshでは \[ \varphi_{\mathrm S}(t)=2t\ln N \] です．したがって \[ \psi_{\mathrm S}(t) =e^{-2t\ln N} =N^{-2t} \] であり， \[ \psi_{\mathrm S}'(t) =-2\ln N\,N^{-2t}. \] よって \[ \boxed{ \max_{0\le t\le1/2} |\psi_{\mathrm S}'(t)| =2\ln N } \] となります．

このため，Shishkin mesh上の高次法の誤差評価には，しばしば \((\ln N)^k\) 型の因子が現れます．Shishkin meshはS-type meshですが， 上の意味でoptimal S-type meshではありません．

5．Bakhvalov–Shishkin mesh

Bakhvalov–Shishkin meshでは，mesh-characterizing functionを \[ \boxed{ \psi_{\mathrm{BS}}(t) =1-2\left(1-\frac1N\right)t } \qquad \left(0\le t\le\frac12\right) \] とします．したがって生成関数は \[ \varphi_{\mathrm{BS}}(t) =-\ln\!\left[ 1-2\left(1-\frac1N\right)t \right]. \] 端点では \[ \varphi_{\mathrm{BS}}(0)=0, \qquad \varphi_{\mathrm{BS}}(1/2)=\ln N \] となり，S-type meshの条件を満たします．

細かい領域の格子点は \[ \boxed{ x_i =-\frac{\sigma\varepsilon}{\beta} \ln\!\left[ 1-2\left(1-\frac1N\right)\frac{i}{N} \right] } \qquad \left(0\le i\le\frac N2\right) \] です．一方， \[ \psi_{\mathrm{BS}}'(t) =-2\left(1-\frac1N\right) \] なので \[ \boxed{ \max_{0\le t\le1/2} |\psi_{\mathrm{BS}}'(t)| =2\left(1-\frac1N\right) \le2 } \] です．したがってBakhvalov–Shishkin meshはoptimal S-type meshです [4]–[6]．

6．局所メッシュ幅を計算する

細かい領域の幅を \[ h_i:=x_{i+1}-x_i, \qquad 0\le i\le\frac N2-1 \] とします．一般のS-type meshでは \[ h_i =\frac{\sigma\varepsilon}{\beta} \left[ \varphi\!\left(\frac{i+1}{N}\right) -\varphi\!\left(\frac{i}{N}\right) \right] \] です．\(\psi=e^{-\varphi}\) を用いれば \[ h_i =\frac{\sigma\varepsilon}{\beta} \ln\!\left( \frac{\psi(i/N)}{\psi((i+1)/N)} \right) \] とも書けます．

Bakhvalov–Shishkin meshでは \[ h_i =\frac{\sigma\varepsilon}{\beta} \ln\!\left( \frac{ 1-2(1-N^{-1})i/N }{ 1-2(1-N^{-1})(i+1)/N } \right). \] 境界に最も近い幅は \[ h_0\asymp\frac{\varepsilon}{N} \] ですが，遷移点直前では \[ h_{N/2-1} =\frac{\sigma\varepsilon}{\beta} \ln\!\left(3-\frac2N\right) \asymp\varepsilon. \] したがって，層領域内の幅は \(O(\varepsilon/N)\) から \(O(\varepsilon)\) へ増加します．

粗い領域の幅は \[ h_{\mathrm c}=\frac{2(1-\lambda)}{N} \asymp\frac1N \] です．遷移点の隣接幅比を一様に保つには，例えば \(\varepsilon N=O(1)\) のような追加関係が有効です．実際， Bakhvalov–Shishkin mesh上の解析では \(\varepsilon\lesssim N^{-1}\) を仮定する場合があります [5]．

重要

\(\max|\psi'|\) が一様有界であることと，すべての隣接要素幅比が一様有界であることは 同じ条件ではありません．S-typeとしてのoptimalityだけからlocal quasi-uniformityは従いません．

7．二次元tensor-product meshの幾何条件

単位正方形で，\(x\) 方向に上のS-type格子点 \(x_i\) を使い， \(y\) 方向は一様に \[ y_j=\frac{j}{N} \] とします．各長方形セルの幅を \[ h_x=x_{i+1}-x_i, \qquad h_y=\frac1N \] とし，対角線で二つの直角三角形に分割します．例えば頂点は \[ (x_i,y_j)^{\top}, \qquad (x_{i+1},y_j)^{\top}, \qquad (x_i,y_{j+1})^{\top} \] です．

第6回の計算から，すべての要素で \[ \boxed{ Q_T =2\left( \frac{h_x}{h_y} +\frac{h_y}{h_x} \right) } \] および \[ \boxed{ \frac{H_T}{h_T}=2 } \] となります．これは生成関数 \(\varphi\) の選び方に依存しません．

Bakhvalov–Shishkin meshの境界付近では \[ h_x\asymp\frac{\varepsilon}{N}, \qquad h_y=\frac1N \] なので \[ Q_T\asymp\frac1\varepsilon \longrightarrow\infty \qquad(\varepsilon\to0). \] 一方で \(H_T/h_T=2\) は保たれます．したがって \[ \boxed{ \text{parameter-uniformには準正則だが非正則} } \] です．これはShishkin meshと同じ幾何学的分類です．

8．三つの「最適」を混同しない

用語 判定量 意味
shape regular \(\sup Q_T<\infty\) 要素の面積・体積が直径に対して退化しない
semi-regular \(\sup H_T/h_T<\infty\) maximum-angle conditionと同値な形状制御
optimal S-type \(\max|\psi'|\le C\) S-type誤差評価に現れるmesh factorが対数的に増大しない
最適次数の数値法 問題・方法ごとの誤差評価 近似次数に対応するparameter-uniform収束率を達成する

Bakhvalov–Shishkin meshはoptimal S-type meshですが，\(\varepsilon\to0\) に一様な shape regularityは満たしません．逆に，shape-regularなメッシュであっても， 境界層に格子点を適切に配分しなければparameter-uniformな精度は得られません．

したがって \[ \boxed{ \text{S-typeとしてのoptimality} \neq \text{要素形状のregularity} } \] です．

9．Shishkin，Bakhvalov–Shishkin，Bakhvalov-typeの比較

観点 Shishkin Bakhvalov–Shishkin Bakhvalov-type
遷移点 \(O(\varepsilon\ln N)\) \(O(\varepsilon\ln N)\) 代表的に \(O(\varepsilon\ln(1/\varepsilon))\)
層領域 一様分割 対数型grading 対数型grading
S-type meshか はい はい 一般には別クラス
\(\max|\psi'|\) \(O(\ln N)\) \(O(1)\) S-typeの量としては通常評価しない
直角三角形分割の \(H_T/h_T\) 2 2 2
parameter-uniformなshape regularity 一般に満たさない 一般に満たさない 一般に満たさない

この比較から，layer-adapted meshの違いを理解するには，少なくとも

  • 遷移点，
  • 生成関数と局所幅，
  • S-typeのmesh factor，
  • 単体要素の幾何条件，

を別々に確認する必要があることが分かります．

10．幾何条件から分かること・分からないこと

10.1 分かること

  • tensor-product rectangleを直角三角形に分割すれば，S-type生成関数によらず準正則であること，
  • 境界付近の最小幅によってparameter-uniformなshape regularityが失われること，
  • 筆者のsemi-regularityに基づく異方性補間・安定性理論へ接続できること．

10.2 この二指標だけでは分からないこと

  • \(\max|\psi'|\) が有界か，
  • 誤差評価から \(\ln N\) 因子を除けるか，
  • 遷移点でlocal quasi-uniformityが成立するか，
  • DMP，M-matrix性，無振動性，maximum-norm評価が成立するか．

特に，\(H_T/h_T=2\) という結果だけでは，Shishkin meshと Bakhvalov–Shishkin meshの精度差を説明できません．その差は生成関数と mesh-characterizing functionに現れます．

まとめ

S-type meshは，Shishkin型の遷移点 \[ \lambda =\frac{\sigma\varepsilon}{\beta}\ln N \] と，一般のmesh-generating function \(\varphi\) によって定義される layer-adapted meshのクラスです．mesh-characterizing function \(\psi=e^{-\varphi}\) を使うと，Shishkin meshでは \(\max|\psi'|=O(\ln N)\)，Bakhvalov–Shishkin meshでは \(\max|\psi'|=O(1)\) となります．

したがってBakhvalov–Shishkin meshはoptimal S-type meshです．しかし， 二次元tensor-product meshを直角三角形に分割した場合，境界付近のアスペクト比は \(O(1/\varepsilon)\) となります．よってparameter-uniformには非正則ですが， \(H_T/h_T=2\) により準正則です．

次回は，Shishkin，Bakhvalov，Bakhvalov–Shishkin，S-type meshを同じ表にまとめ， 遷移点，局所幅，quasi-uniformity，\(Q_T\)，\(H_T/h_T\)，誤差解析上の特徴を比較します．
