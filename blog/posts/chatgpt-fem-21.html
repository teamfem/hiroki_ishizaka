第21回：Nédélec要素を実装する — edge moment・curl・covariant Piola

ChatGPTで作る有限要素プログラム入門 Season 2 第9回（通算第21回）
30th August 2026

はじめに――今度は「接線成分」をつなぐ

第14回のRaviart–Thomas（RT）要素では， faceを横切る \[ \boldsymbol q\cdot\boldsymbol n \] を自由度にしました． Nédélec要素では逆に，edgeに沿う \[ \boldsymbol v\cdot\boldsymbol t \] を自由度にします．

\[ \boxed{ \text{Nédélec} = \text{edge tangential moment} + H(\operatorname{curl})\text{ conformity} + \text{covariant Piola} } \tag{1} \]

Maxwell方程式だけでなく，de Rham complex，Hodge decomposition， compatible discretisationを理解するための中心的な有限要素です．

なおNédélec elementにもfirst family / second family，さらに各次数があります． 本記事ではlowest-order Nédélec first familyに限定します．

1．\(H(\operatorname{curl})\) とは何か

2次元ではvector field \[ \boldsymbol v=(v_1,v_2)^{\top} \] に対しscalar curlを \[ \boxed{ \operatorname{curl}\boldsymbol v = \partial_xv_2-\partial_yv_1 } \tag{2} \] とします．

そして \[ \boxed{ H(\operatorname{curl};\Omega) = \left\{ \boldsymbol v\in L^2(\Omega)^2: \operatorname{curl}\boldsymbol v\in L^2(\Omega) \right\}. } \tag{3} \]

3次元では通常のvector curl \[ \nabla\times\boldsymbol v \] を使います．

2．\(H(\operatorname{curl})\) conformityが要求するcontinuity

\(H^1\)-conforming elementはfunction valueをつなぎ， RTはnormal componentをつなぎました． Nédélecでは

\[ \boxed{ \text{tangential trace} } \tag{4} \]

をelement間で整合させます．

2次元interior edge \(E\) では， 固定したunit tangent \(\boldsymbol t_E\) に対して \[ [\boldsymbol v_h\cdot\boldsymbol t_E]_E=0 \tag{5} \] という形です． lowest-order first-family elementではedge上のtangential componentがconstantなので， 一つのedge line integralを共有すればこのcontinuityが実現します．

3．local Nédélec space

2次元triangle \(T\) ではlowest-order first-family spaceを \[ \boxed{ \mathcal N_0(T) = P_0(T)^2 \oplus \operatorname{span} \left\{ (-y,x)^{\top} \right\}. } \tag{6} \]

従って \[ \dim\mathcal N_0(T)=3, \] triangleの三つのedgesに一つずつDoFを置きます．

3次元tetrahedronでは六つのedgesに対応して \[ \dim\mathcal N_0(T)=6 \] です．

4．DoFはoriented edge circulation

edge \[ E=[p_i,p_j] \] にorientation \(p_i\to p_j\) を与え， unit tangentを \(\boldsymbol t_E\) とします． 自由度は

\[ \boxed{ m_E(\boldsymbol v) = \int_E \boldsymbol v\cdot\boldsymbol t_E\,ds. } \tag{7} \]

orientationを反転すると \[ m_{-E}(\boldsymbol v) = - m_E(\boldsymbol v). \tag{8} \]

ここがscalar CRと違い， RTと同じくglobal sign管理が必須になる理由です．

5．barycentric coordinateでbasisを書く

triangleのbarycentric coordinatesを \[ \lambda_0,\lambda_1,\lambda_2 \] とします． oriented edge \(i\to j\) に対応するbasisを \[ \boxed{ \boldsymbol\theta_{ij} = \lambda_i\nabla\lambda_j - \lambda_j\nabla\lambda_i. } \tag{9} \]

この式は2次元だけでなくsimplex上のlowest-order Whitney 1-form / Nédélec basisとして使えます．

6．edge momentのKronecker property

edge \(E_{ij}\) を \(p_i\to p_j\) に向けると \[ \boxed{ \int_{E_{kl}} \boldsymbol\theta_{ij} \cdot \boldsymbol t_{kl}\,ds = \delta_{(ij),(kl)}. } \tag{10} \]

実装の最初のunit testは，basisの値そのものではなく このline-integral Kronecker propertyです．

7．reference triangleではbasisを手で書ける

reference triangle \[ \widehat T = \operatorname{conv} \left\{ (0,0)^{\top}, (1,0)^{\top}, (0,1)^{\top} \right\} \] で \[ \widehat\lambda_0=1-\xi-\eta, \qquad \widehat\lambda_1=\xi, \qquad \widehat\lambda_2=\eta. \] edgesを \[ 0\to1,\qquad1\to2,\qquad2\to0 \] と向けると

\[ \boxed{ \begin{aligned} \widehat{\boldsymbol\theta}_{01} &= (1-\eta,\xi)^{\top}, \\ \widehat{\boldsymbol\theta}_{12} &= (-\eta,\xi)^{\top}, \\ \widehat{\boldsymbol\theta}_{20} &= (-\eta,\xi-1)^{\top}. \end{aligned} } \tag{11} \]

三つともscalar curlは \[ \boxed{ \widehat{\operatorname{curl}} \widehat{\boldsymbol\theta}_{e} = 2. } \tag{12} \]

8．なぜusual compositionではだめなのか

affine map \[ F_T(\widehat x) = J_T\widehat x+b_T \tag{13} \] を考えます． scalar P1なら \[ v=\widehat v\circ F_T^{-1} \] でよいのですが， vector fieldを同じようにcompositionするだけではedge circulationが保存されません．

Nédélec elementでは covariant Piola transformを使います．

9．covariant Piola transform

\(\det J_T>0\) とし，

\[ \boxed{ \boldsymbol v(x) = J_T^{-\top} \widehat{\boldsymbol v}(\widehat x), \qquad x=F_T(\widehat x). } \tag{14} \]

これがNédélecのcovariant Piola transformです．

RTのcontravariant Piola \[ \boldsymbol q = \frac1{\det J_T} J_T\widehat{\boldsymbol q} \tag{15} \] とは全く違うtransformです．

10．covariant Piolaはedge line integralを保存する

reference edge tangent vectorを \(d\widehat x\) とすると \[ dx = J_T\,d\widehat x. \] 従って

\[ \begin{aligned} \boldsymbol v\cdot dx &= \left( J_T^{-\top} \widehat{\boldsymbol v} \right) \cdot \left( J_T\,d\widehat x \right) \\ &= \widehat{\boldsymbol v} \cdot d\widehat x. \end{aligned} \tag{16} \]

したがって

\[ \boxed{ \int_E \boldsymbol v\cdot\boldsymbol t_E\,ds = \int_{\widehat E} \widehat{\boldsymbol v} \cdot \widehat{\boldsymbol t}_{\widehat E} \,d\widehat s. } \tag{17} \]

これがcovariant Piolaを選ぶ本質です．

11．curlはどう変換されるか――2次元

2次元では式 (14) の下で \[ \boxed{ \operatorname{curl}\boldsymbol v = \frac1{\det J_T} \widehat{\operatorname{curl}} \widehat{\boldsymbol v}. } \tag{18} \]

従ってreference elementでconstantだったcurlはphysical triangleでもconstantです．

12．curlはどう変換されるか――3次元

3次元ではcurlはvectorで，

\[ \boxed{ \nabla\times\boldsymbol v = \frac1{\det J_T} J_T \left( \widehat\nabla\times \widehat{\boldsymbol v} \right). } \tag{19} \]

ここで現れる \[ \frac1{\det J_T}J_T \] はRTのcontravariant Piolaと同じ形です．

つまり

\[ \boxed{ \text{Nédélec field} \xrightarrow{\operatorname{curl}} \text{RT-type field} } \tag{20} \]

というde Rham structureがPiola transformの段階ですでに見えています．

13．NédélecとRTを並べる

element DoF space Piola operator
Nédélec edge tangential circulation \(H(\operatorname{curl})\) \(J^{-\top}\) curl
RT face normal flux \(H(\operatorname{div})\) \((\det J)^{-1}J\) div

両者は似ていますが， normalとtangent，contravariantとcovariantを入れ替えてはいけません．

14．global edge orientation

global meshでは各edge \[ E=\{a,b\} \] に一つorientationを決めます． 例えばglobal vertex IDを使って \[ \min(a,b)\to\max(a,b) \] と決めれば再現可能です．

element-local edge orientationとglobal orientationが同じなら \[ s_{T,E}=+1, \] 逆なら \[ s_{T,E}=-1. \]

local basisとglobal unknownの対応には \[ \boxed{ c_{T,E}^{\mathrm{local}} = s_{T,E}\, c_E^{\mathrm{global}} } \tag{21} \] を使います．

15．orientation signをassemblyへ入れる

global_edges = element_edges[t]
signs = element_edge_signs[t]   # +1 or -1

for i, I in enumerate(global_edges):
    for j, J in enumerate(global_edges):
        A[I, J] += (
            signs[i]
            * signs[j]
            * A_local[i, j]
        )

RT assemblyと同じ形ですが， signが表しているのはnormal orientationではなく edge tangent orientationです．

16．canonical edge interpolation

十分regularなvector field \(\boldsymbol v\) に対し， local Nédélec interpolation \(I_T^N\boldsymbol v\) を

\[ \boxed{ \int_E I_T^N\boldsymbol v \cdot\boldsymbol t_E\,ds = \int_E \boldsymbol v \cdot\boldsymbol t_E\,ds \qquad \forall E\subset\partial T } \tag{22} \]

で定義します．

したがって \[ I_T^N\boldsymbol v = \sum_{E\subset\partial T} \left( \int_E \boldsymbol v\cdot\boldsymbol t_E\,ds \right) \boldsymbol\theta_E. \tag{23} \]

17．重要：\(H(\operatorname{curl})\) だけではedge momentを古典的に書けない

式 (22) を見て，

\[ \boldsymbol v\in H(\operatorname{curl};T) \quad\Longrightarrow\quad \int_E \boldsymbol v\cdot\boldsymbol t_E\,ds \text{ が普通の積分として存在する} \]

と考えてはいけません．

generic \(H(\operatorname{curl})\) fieldのtangential traceはnegative-order trace spaceで理解され， 特に3次元ではface traceからさらにedgeへrestrictionする操作は自動的ではありません．

この記事での安全な前提
canonical interpolationを実際に評価するときは， 例えば \[ \boxed{ \boldsymbol v\in H^1(T)^d } \tag{24} \] のようにedge momentsがclassically well-definedなregularityを仮定する．

これは第14回で述べたRT interpolationのtrace regularity問題と同じ種類の注意です．

18．commuting property――2次元ではStokesの定理だけで見える

\(I_T^N\boldsymbol v\in\mathcal N_0(T)\) なので \[ \operatorname{curl}I_T^N\boldsymbol v \] はconstantです． Stokesの定理とedge moment preservationから

\[ \begin{aligned} \int_T \operatorname{curl} I_T^N\boldsymbol v\,dx &= \int_{\partial T} I_T^N\boldsymbol v \cdot\boldsymbol t\,ds \\ &= \int_{\partial T} \boldsymbol v \cdot\boldsymbol t\,ds \\ &= \int_T \operatorname{curl} \boldsymbol v\,dx. \end{aligned} \tag{25} \]

従って

\[ \boxed{ \operatorname{curl} I_T^N\boldsymbol v = \Pi_T^0 \operatorname{curl} \boldsymbol v. } \tag{26} \]

これがlowest-order Nédélec interpolationのcommuting identityです．

19．3次元ではNédélecからRTへcommuteする

十分smoothな3次元fieldでは，lowest-order de Rham projectionの形として

\[ \boxed{ \operatorname{curl} I_T^N\boldsymbol v = I_T^{RT} \left( \operatorname{curl}\boldsymbol v \right) } \tag{27} \]

が現れます．

edge circulationを保存するNédélecと， face fluxを保存するRTが Stokesの定理を通して接続されるわけです．

次回のde Rham complexではこの関係をglobal incidence matrixまで含めて実装します．

20．model variational problem

pure curl–curl operatorにはgradient kernelがあるので， 最初の実装testではreaction termを加えたcoercive problemを使います．

2次元で \[ H_0(\operatorname{curl};\Omega) = \left\{ \boldsymbol v\in H(\operatorname{curl};\Omega): \boldsymbol v\cdot\boldsymbol t=0 \text{ on }\partial\Omega \right\} \] とし，

\[ \boxed{ \text{Find }\boldsymbol u\in H_0(\operatorname{curl};\Omega) } \]

such that

\[ \boxed{ ( \operatorname{curl}\boldsymbol u, \operatorname{curl}\boldsymbol v ) + ( \boldsymbol u,\boldsymbol v ) = ( \boldsymbol f,\boldsymbol v ) \quad \forall \boldsymbol v\in H_0(\operatorname{curl};\Omega). } \tag{28} \]

21．local matrix

local Nédélec basisを \[ \boldsymbol\theta_0, \boldsymbol\theta_1, \boldsymbol\theta_2 \] とすると

\[ \boxed{ A_{ij}^{(T)} = \int_T \boldsymbol\theta_j\cdot\boldsymbol\theta_i\,dx + \int_T \operatorname{curl}\boldsymbol\theta_j \operatorname{curl}\boldsymbol\theta_i\,dx. } \tag{29} \]

curlはconstantなのでcurl–curl termはexactに

\[ |T| \operatorname{curl}\boldsymbol\theta_j \operatorname{curl}\boldsymbol\theta_i \]

で計算できます．

22．tangential boundary conditionはboundary edge DoFをzeroにする

homogeneous condition \[ \boldsymbol u\cdot\boldsymbol t=0 \qquad \text{on }\partial\Omega \tag{30} \] はlowest-order Nédélecでは

\[ \boxed{ \int_E \boldsymbol u_h\cdot\boldsymbol t_E\,ds = 0 \qquad \forall E\subset\partial\Omega } \tag{31} \]

としてboundary edge unknownを消去すれば実現できます．

normal componentをzeroにするのではありません．

23．patch test――Nédélec spaceそのものを再現する

2次元lowest-order spaceにexactに属する

\[ \boxed{ \boldsymbol v(x,y) = (1-y,\ 2+x)^{\top} } \tag{32} \]

を使います．

これは \[ \boldsymbol a+c(-y,x)^{\top} \] の形なので \[ I_h^N\boldsymbol v = \boldsymbol v \] でなければなりません．

25．commuting identityも数値で直接監査する

各element \(T\) で \[ \delta_T = \left| \operatorname{curl} I_T^N\boldsymbol v - \frac1{|T|} \int_T \operatorname{curl}\boldsymbol v\,dx \right| \tag{35} \] を計算すると， \(n=32\) でもmaximum defectは \[ 4.62\times10^{-14} \] 程度でした．

これは式 (26) を実装レベルで直接testしていることになります．

26．shape-regular meshでの基本的な補間スケール

十分smoothなfieldとshape-regular meshでは典型的に

\[ \boxed{ \|\boldsymbol v-I_T^N\boldsymbol v\|_{L^2(T)} \le C h_T |\boldsymbol v|_{H^1(T)} } \tag{36} \]

であり，commuting propertyから

\[ \boxed{ \| \operatorname{curl} (\boldsymbol v-I_T^N\boldsymbol v) \|_{L^2(T)} = \| \operatorname{curl}\boldsymbol v - \Pi_T^0\operatorname{curl}\boldsymbol v \|_{L^2(T)}. } \tag{37} \]

従ってcurlが \(H^1\) なら右辺も \(O(h_T)\) です．

27．anisotropic meshではcovariant Piolaを雑に評価しない

anisotropic elementでは \[ J_T^{-\top} \] のsingular valuesが方向ごとに大きく異なります． そのため

\[ \|J_T^{-\top}\| \] だけで全てをisotropicに潰すと， directional approximation structureを失うことがあります．

さらに3次元curl transformには \[ \frac1{\det J_T}J_T \] も入ります．

anisotropic Nédélecで監査するもの
\[ \boxed{ \text{edge directions} + \text{covariant Piola} + \text{curl transform} + \text{mesh geometry} } \tag{38} \]

RTで得たanisotropic estimateを， Piolaが違うNédélecへそのまま置き換えることはできません．

28．pure curl–curlではgradient kernelを忘れない

Maxwell型の \[ ( \operatorname{curl}\boldsymbol u, \operatorname{curl}\boldsymbol v ) \] だけをmatrixにすると，

\[ \operatorname{curl}\nabla\phi=0 \]

なのでgradient fieldsがkernelに入ります．

これはbugではなくcontinuous operatorの構造です．

\[ \boxed{ \operatorname{grad} \longrightarrow \operatorname{curl} \longrightarrow \operatorname{div} } \tag{39} \]

というcomplexを無視してlinear solverだけを眺めると， 「matrixがsingularだから実装失敗」と誤診します．

29．Nédélec実装でAIが間違えやすい点

mistake何が壊れるか
\(J^{-1}\) や \(J\) を使うedge circulationが保存されない

30．Nédélec implementation audit prompt

Audit prompt
このlowest-order Nédélec first-family finite-element codeを数学的に監査してください．
(1) local spaceが2Dで \(P_0^2\oplus\operatorname{span}\{(-y,x)^{\top}\}\) になっているか，
(2) DoFがoriented edge tangential line integralsか，
(3) basis \(\lambda_i\nabla\lambda_j-\lambda_j\nabla\lambda_i\) がedge-moment Kronecker propertyを満たすか，
(4) affine transformが \(J^{-\top}\) のcovariant Piolaか，
(5) edge line integral preservationを数値またはsymbolicに確認しているか，
(6) 2D curl transformが \((\det J)^{-1}\widehat{\operatorname{curl}}\) か，
(7) 3D curl transformが \((\det J)^{-1}J\widehat{\operatorname{curl}}\) か，
(8) global edge orientationを一意に固定しlocal/global signを管理しているか，
(9) boundary conditionでnormalではなくtangential edge DoFを処理しているか，
(10) canonical interpolationをgeneric \(H(\operatorname{curl})\) fieldに無条件で適用していないか，
(11) \(\operatorname{curl}I_T^N=\Pi_T^0\operatorname{curl}\) のcommuting testを行っているか，
(12) 3DではNédélec–RT commuting relationを意識しているか，
(13) anisotropic meshでcovariant Piolaのdirectional scalingを潰していないか，
(14) pure curl–curl operatorのgradient kernelを実装bugと誤認していないか
を順に確認してください．

31．第21回の結論

Nédélec elementでは

\[ \boxed{ \begin{aligned} &\text{edge circulation},\\ &\text{tangential continuity},\\ &\text{covariant Piola},\\ &\text{curl commuting} \end{aligned} } \tag{40} \]

が一つの構造になっています．

特に

\[ \boxed{ \int_E \boldsymbol v\cdot\boldsymbol t\,ds \quad\text{を保存したい} \quad\Longrightarrow\quad J^{-\top} } \tag{41} \]

というPiola transformの選択は， 暗記ではなくDoF invarianceから導けます．

そして3次元では

\[ \boxed{ P_1 \xrightarrow{\nabla} \mathcal N_0 \xrightarrow{\operatorname{curl}} RT_0 \xrightarrow{\operatorname{div}} P_0 } \tag{42} \]

というde Rham complexが見え始めます．

Season 2 第9回の原則
Nédélec要素では 「vector basisの形」を覚えるより，「どのoriented integralを保存するか」からPiola・orientation・commutingを導く．

次回はこの構造をまとめて， de Rham complexをコードで見る — Lagrange・Nédélec・RT・P0 へ進みます．
