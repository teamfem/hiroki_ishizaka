Codexで大学数学教材を作る — 数式から実装・検証まで

線形代数 · 数学教育とAI31st October 2026

Introduction：数学を動かすだけで十分だろうか

AIにプログラムを書かせれば、数学の可視化教材を作ることは以前より容易になりました。しかし、図形が滑らかに動くことと、表示される数学が正しいことは別です。さらに、学生が画面を眺めているだけでは、定義を理解したことにも、命題を証明できるようになったことにもなりません。

この連載では、Codexを使って大学数学の教材を実際に作り、その制作過程を記録します。線形代数、微分積分、位相空間論、関数解析へと対象を広げる予定です。最初に、行列の固有値と対角化可能性を区別する小さな教材を作ってみます。

本連載の基本方針

「予想する → 操作する → 反例を調べる → 証明する」の順序を大切にします。数学的な主張と、数値実験で観察された現象を混同しません。

1．数学的な問いを先に決める

パラメータ \(t\in\mathbb R\) に依存する行列

\[A(t)=\begin{pmatrix}1&t\\0&1\end{pmatrix}\tag{1}\]

を考えます。特性多項式は

\[\det(\lambda I-A(t))=(\lambda-1)^2\tag{2}\]

であり、\(t\) に関係なく固有値は \(1\) だけです。しかし、対角化可能性は \(t\) に依存します。

\[A(t)-I=\begin{pmatrix}0&t\\0&0\end{pmatrix}.\tag{3}\]

したがって、\(t\ne0\) では固有空間は \(\operatorname{span}\{(1,0)^{\top}\}\) に一致し、その次元は1です。一方、\(t=0\) では \(A(0)=I\) なので固有空間の次元は2です。従って

\[A(t)\text{ が対角化可能}\quad\Longleftrightarrow\quad t=0.\tag{4}\]

この性質を、単位正方形と格子の変形によって観察できるようにします。ただし、図による観察が式(4)の証明に置き換わるわけではありません。

2．完成した最小教材を触ってみる

線形代数の実験室を開く

スライダーで \(t\) を変更すると、行列の作用によって格子がせん断変形します。同時に、固有値、固有空間の次元、対角化可能性を表示します。\(t=0\) で何が変わるか、操作する前に予想してみてください。

上記は初版・ver2の操作の説明です。現在のver3では、予想を確定してから観察図と正解を表示します。変更の設計と検証は、後半のver3追記で説明します。

3．作業用フォルダを用意する

このホームページはGitHub Pagesで公開され、ブログ記事は blog/posts/ にあるHTMLファイルで管理されています。既存のサイト構成を大きく変更しないために、実験教材は blog/demos/ に置きます。

blog/
  posts/
    codex-math-01.html
  demos/
    AGENTS.md
    linear-algebra-shear.html
    linear-algebra-shear.js
tests/
  shear-math.test.js

静的HTML、CSS、JavaScriptだけで構成すれば、サーバー側にPythonなどを用意する必要はありません。GitHub Pagesの静的ファイル公開の仕組みに合わせるため、初回は外部JavaScriptライブラリにも依存させません。

4．Codexを起動する

Codex CLIの導入は、OpenAIの公式手順に従います［1］。インストール後、作業用リポジトリに移動して codex を実行し、必要に応じてChatGPTでサインインします。既存のホームページを誤って変更しないよう、Gitで作業ブランチを用意し、最初は新しい教材ファイルだけを扱わせます。

git clone https://github.com/teamfem/hiroki_ishizaka.git
cd hiroki_ishizaka
git switch -c codex-math-education
codex

既にローカルにリポジトリがある場合は、その作業コピーを利用できます。上記は説明用のコマンドであり、既存の変更がある場合はブランチの状態を先に確認してください。

5．最初の指示文を書く

Codexに「線形代数の教材を作ってください」とだけ伝えると、どこまで実装するか、何を正しいと判定するかが曖昧になります。そこで、数学的な要件を先に指定します。

A(t)=[[1,t],[0,1]] の線形代数教材を作ってください。
1. t は -2 から 2 まで 0.1 刻みで操作する。
2. 単位正方形とその線形写像による像を表示する。
3. 固有値は常に 1（代数的重複度2）とする。
4. 固有空間の次元は t=0 なら2、t≠0なら1とする。
5. その結果から対角化可能性を表示する。
6. HTML/CSS/JavaScriptだけで動くようにする。
7. 数学的性質の独立テストを作る。
8. ブログ本体の既存ファイルは変更しない。
9. 実装後にテスト結果と残る制限を報告する。

これは使用できる指示文の一例です。ここに掲載した教材がこの指示文だけから自動生成された、という意味ではありません。どの数式に依拠し、どの機能を実装したかを再現可能な形で示すことが目的です。

6．プログラムのどの部分が数学に対応するか

行列を扱う計算部分を独立した linear-algebra-shear.js に分離します。例えば、線形写像を次のように実装します。

function apply(t, point) {
  const [x, y] = point;
  return [x + t * y, y];
}

この部分は式(1)の \(A(t)(x,y)^{\top}=(x+ty,y)^{\top}\) と直接対応します。図の描画は別の処理にし、数学的計算と見た目の処理を混ぜないようにします。

数学プログラムでの確認
\(A(t)e_1=e_1\)apply(t,[1,0]) が [1,0] を返す
\(A(t)e_2=(t,1)^{\top}\)apply(t,[0,1]) が [t,1] を返す
\(\det A(t)=1\)行列式がすべてのテスト値で1になる
\(\dim\ker(A(t)-I)=1,2\)\(t=0\) と \(t\ne0\) の分岐を調べる

7．テストを実行して、数学的に監査する

スライダーが動くことだけをテストしても、数学的正しさは分かりません。別ファイル tests/shear-math.test.js に、標準基底の像、行列式、固有空間の次元、逆せん断との合成などを確認するテストを用意します。

node --test tests/shear-math.test.js

ver2の配布用コードについては、既存の6件に入力検証と全41値の数学的性質を確認する回帰テスト5件を追加し、計11件が通過することを確認しました。もっとも、これらは指定した行列族に関する有限個の実装テストであり、任意の行列について数学的証明を自動的に与えるものではありません。

実装後はブラウザ上で \(t=-2,-1,0,1,2\) の表示を確認します。ver2では、スライダーで選べる全41値で図形の余白と判定を確認し、幅320・375・768・1440pxで記事と教材の表示を確認しました。数値演算では近似誤差が生じ得るため、任意の実数に対して \(t=0\) かどうかを判定する一般的方法と混同しないことにも注意が必要です。この教材では、スライダーが取り得る有限個の値について定義された問題を扱います。

8．ローカルで確認し、ブログへ配置する

ローカルではPythonの簡易HTTPサーバーを利用できます。リポジトリのルートで次のコマンドを実行します。

python3 -m http.server 8000

ブラウザで http://localhost:8000/blog/demos/linear-algebra-shear.html を開き、図が表示されることを確認します。記事の方は http://localhost:8000/blog/posts/codex-math-01.html です。

確認が終わったら、記事と教材へのリンクを blog/index.html に追加します。サイトの公開操作は、数学的・文章上の確認が終わってから行います。GitHub Pagesの公開設定は既存リポジトリの設定に依存するため、公開元ブランチやActionsの状態は実際の設定を確かめてください［3］。

9．授業では何を学生に問うか

教材を最初から自由に操作させるのではなく、以下の順序を考えています。

  1. 全ての \(t\) で固有値が同じことを先に計算する。
  2. 対角化可能性も同じだろうか、と予想する。
  3. 教材で \(t\) を動かし、固有空間の次元を観察する。
  4. 式(3)から固有空間を求め、観察を証明する。
  5. さらに「固有値が全て実数なら対角化できるか」という命題を検討する。

ここでは答えを速く得ることより、誤った予想を自分で修正できることを重視します。講義中に数分間の個人予想とペア討論を入れる使い方も考えられますが、教育効果は実際の授業で確かめる必要があります。

10．次に考えたいこと

第2回以降は、対角化可能性から直交射影、最小二乗法、特異値分解へ進みたいと思います。その後、微分積分では各点収束と一様収束、位相空間論では分離公理と連続写像、関数解析では強作用素収束と作用素ノルム収束を扱う予定です。

共通する問いは、数学的な定義を実際に操作できるようにすると、何が見え、何が逆に見えなくなるか、ということです。有限次元の実験だけでは無限次元の定理を証明できません。この限界も含めて教材にしたいと思います。

ver3追記1．「予想する → 観察する → 証明する」を画面に組み込む

ver2では、図の欠け、小さい画面での数式表示、不正な入力の扱いを改善しました。ver3では、その数学モデルと改善点を保ち、学生が答えを読む前に自分の予想を表明できる教材へ発展させます。行列族と式(1)〜(4)の結論は変えません。

  1. 予想する：学生はパラメータを選び、固有空間の次元と対角化可能性をそれぞれ選択します。未選択の項目があれば確定できません。
  2. 観察する：予想を確定すると、二つの図、数学モデルから求めた結果、予想との照合を表示します。間違った予想も、その理由を考える出発点として扱います。
  3. 証明する：「次の段階へ」で、固有空間を求める計算、場合分け、対角化の判定を一段ずつ読みます。

予想前には結果の数値だけでなく、固有空間の強調、図の説明、証明も教材画面から隠します。パラメータを変更したら、前の予想と結果、開いた証明をすべて初期化します。「t = 0 に戻す」操作でも新たに予想を求め、前の正解を残しません。

この記事は制作と数学の解説を兼ねているため、前半にも答えが書かれています。授業で事前の予想を大切にする場合は、学生にはまず教材画面を直接開いてもらい、この記事はその後の振り返りに使うことを想定しています。

ver3追記2．Codexには画面の順序と初期化の条件も伝える

数学的に正しい値を表示するだけでは、学生がどの順序で考えるかは決まりません。ver3では、数学的な仕様に加え、正解を表示する条件と、パラメータ変更時に何を消すかを具体的に指示します。

既存の A(t)=[[1,t],[0,1]] の教材をver3へ発展させる。
数学モデル、既存の11テスト、ver2の表示上の修正は維持する。

1. 学生がtを選び、固有空間の次元と対角化可能性を予想する。
2. 予想確定前には結果、観察図、固有空間の説明、証明を表示しない。
3. t変更・リセット時は予想、結果、観察図、証明段階を初期化する。
4. e1/e2とその像を、左右の図・線種・色・文字で区別する。
5. t=0は全平面、t≠0は第1座標軸全体を固有空間として示す。
6. (A(t)-I)(x,y)^T=(ty,0)^Tからの証明を3段階で示す。
7. 色だけに頼らず、ラベルと説明文を付ける。
8. 予想・結果・リセット・キーボード操作の回帰テストを追加する。
9. 全41値と320/375/768/1440pxで図形とページのはみ出しを検査する。
10. 変更は指定4ファイルに限定し、コミットや公開は行わない。

この指示文も要件を共有するための例です。数学的な事実は人が定義から確かめ、操作上の条件は実際の画面とテストで確かめます。指示文が詳しいこと自体を、実装の正しさの保証とは考えません。

ver3追記3．状態、幾何学、証明を対応づける

学習の状態と描画を分ける

行列の計算は引き続き matrix、apply、eigenspaceDimensionAtOne が担当します。学習の進行は ShearMath.createLesson() で作る状態として別に管理し、パラメータ、予想、結果、証明段階を保存します。画面側はその状態を読み、必要な領域だけを開きます。

学生の操作状態の操作画面への反映
パラメータを変更するsetParameter(t)予想、結果、証明段階を初期化する
予想を確定するpredict(dimension, diagonalizable)観察図、結果、予想との照合を表示する
証明を進めるnextProofStep()次の段階を表示する
最初から考え直すreset()パラメータを0に戻して全段階を初期化する

選択肢は fieldset と legend でまとめた標準のラジオボタンとし、キーボードでも選択できるようにします。結果や初期化の通知には読み上げ用の領域を設けます。正解を含む領域は見た目だけでなく hidden 属性で隠し、予想前の読み上げからも除きます。

同じ場所に重なることも観察する

左の図では元の基底ベクトルを、右の図ではその像を示し、実線と破線、ラベルによって区別します。色を見分けにくい場合でも、文字と左右の図で対応を追えるようにします。固定されるベクトルや重なるベクトルの位置を、見やすさのためにずらすことはしません。

固有空間の表示には特に注意が必要です。パラメータが0なら固有空間は二つの軸の集合ではなく全平面なので、面を塗って「表示窓は全平面の一部」と説明します。0以外なら第1座標軸の正負両方向を示します。固有空間は零ベクトルを含みますが、固有ベクトルと呼ぶのはそのうち零でないベクトルです。

証明の3段階

  1. 固有値1に対する条件を \((A(t)-I)(x,y)^{\top}=0\) と書きます。計算すると \[(A(t)-I)(x,y)^{\top}=(ty,0)^{\top}.\] したがって、求める条件は \(ty=0\) です。
  2. \(t\ne0\) なら \(y=0\) となり、\(x\) は自由です。\(t=0\) なら \(x,y\) のどちらにも制約がありません。
  3. 前者では固有空間が1次元、後者では2次元です。2次元空間の基底をなす一次独立な固有ベクトルを選べるのは後者だけなので、式(4)が得られます。
観察と証明の役割

図はベクトルの動きや不変な方向に気付くためのものです。有限個のパラメータ値で表示が一致しても、すべてのパラメータについての証明にはなりません。上の計算と場合分けが、結論を支える数学的な理由です。

ver3追記4．数学と学習の操作を別々に検証する

ver2までの11件のテストを残し、予想前には結果がないこと、予想後の照合、パラメータ変更とリセットによる初期化、予想前には証明を進められないことを回帰テストに加えます。数学モデルのテストが通っても、学生の画面に前の答えが残る不具合は別に起こり得るためです。

node --test tests/shear-math.test.js

# PlaywrightとChromiumを用意した検証環境でブラウザテストも実行する
SHEAR_BROWSER_TESTS=1 node --test --test-isolation=none tests/shear-math.test.js

ブラウザの検証では、未選択のままの送信、予想の確定、結果の表示、変更後の初期化、リセット、ラジオボタンやスライダーのキーボード操作を調べます。全41値では数学モデルとの一致と図形の余白を、幅320・375・768・1440pxではページ全体のはみ出しと数式部分のスクロールを確認します。これらの自動テストは実装の回帰を検出するものであり、実際の学生にとっての分かりやすさまで保証するものではありません。

ver3では、既存11件、学習状態の8件、実ブラウザの4件、計23件がすべて通過しました。通常実行では数学・状態管理の19件を実行し、ブラウザの4件は上記の環境変数を指定したときに追加します。記事の数式33件は描画エラーがなく、指定の4画面幅で記事と教材に横はみ出しがないこと、予想前・結果表示後・証明表示後の操作を確認しました。

PlaywrightとChromiumは開発時の検証に使います。教材自体は引き続き静的HTML・CSS・JavaScriptで動き、学生のブラウザに検証用のライブラリを読み込ませる必要はありません。

ver3追記5．正解数だけでは学習を評価しない

ver3の設計では、予想を先に確定し、観察と証明を分けることで、「どこで自分の考えが変わったか」を学生が振り返りやすくなることを期待しています。ただし、これは教育上の仮説であり、この画面を使うだけで理解が深まるという効果を実証したわけではありません。

授業では、最初の選択の理由、図から分かったこと、図だけでは分からないこと、証明のどの式が予想を修正する根拠になったかを、短い文章やペア討論で説明してもらう方法が考えられます。正解した学生にも、なぜ他の場合と違うのかを説明してもらいます。

本教材は予想や解答を保存・送信する学習管理システムではありません。学生の操作履歴や理解度を収集せず、パラメータ変更時に前の予想を消します。授業で振り返りを残す場合は、学生自身がノートなどに理由を記録する使い方を想定しています。
