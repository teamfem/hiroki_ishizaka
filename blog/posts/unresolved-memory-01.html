第1回：未解像ダイナミクスと履歴依存型発展方程式 — 記憶をどう安定にモデル化・同定・離散化するか

25th July 2026
Revised on 2nd August 2026

Introduction：計算から消した状態は，本当に消えるのか

大規模な物理現象を計算するとき，すべての自由度を同じ精度で追跡することはできません． 細かな渦，材料内部の緩和モード，微視的な熱輸送，複数の反応経路など， 観測や計算の対象から外れる状態は必ず存在します．

しかし，未解像状態を変数から取り除いても，その影響まで消えるとは限りません． 未解像状態は，解像された状態から過去に受け取った情報を内部に蓄え， 少し遅れて解像状態へ返します． 解像変数だけで方程式を書き直すと，この往復が履歴積分，分布遅延，離散遅延， あるいは追加の内部変数として現れます．

この連載の中心問題
未解像ダイナミクスが残す記憶を，どのように導出し，観測から同定し， 安定性を壊さずに近似し，構造保存的に完全離散化するか．

したがって，本連載で扱うのは「memory項を一つ追加して解く」だけの問題ではありません． modelling，well-posedness，kernel stability，model reduction，space-time discretisation， そしてcertificationを一つの誤差予算の中で結び付けることが目標です． 確率性は必須ではありません．まずは決定論的な線形問題において， memoryがどのような構造をもち，何を制御し，どの極限で構造が変わるかを明らかにします．

1．履歴依存型発展方程式の三つの表し方

「memory equation」という言葉の下には，少なくとも三つの異なる表現があります． これらは関係していますが，無条件に同一ではありません．

1.1 measure-valued delay

有限の最大遅延をもつモデルは，Gelfand triple \(V\hookrightarrow H\cong H^*\hookrightarrow V^*\) 上で，例えば \[ \partial_t u(t)+A_0u(t) +\int_{[0,\tau]}A_1\widetilde u(t-s)\,d\mu(s)=f(t) \] と書けます．ここで，\(\widetilde u\) は未知の軌道と与えられた過去履歴を接続した関数， \(\mu\) は遅延時間の分布を表す有限Borel測度です．

  • \(\mu=m\delta_{\tau_d}\)：一つの離散遅延．
  • \(\mu=\sum_{j=1}^{N}m_j\delta_{\tau_j}\)：複数の離散遅延．
  • \(d\mu(s)=k(s)\,ds\)：分布遅延．
  • 原子部分と密度部分の和：離散遅延と分布遅延の混合．

原点の原子 \(m_0\delta_0\) は遅延ではなく瞬時作用です．したがって， \(m_0A_1\) を瞬時作用素へ吸収し，残りのretarded kernelと分けて考える必要があります．

1.2 Volterra memory

過去全体の影響が時間とともに減衰する場合には， \[ \partial_tu(t)+A_0u(t)+A_1(k*u)(t)=f(t), \qquad (k*u)(t):=\int_0^t k(t-s)u(s)\,ds \] というVolterra型memoryが自然です． 有限遅延とVolterra memoryは時間区間も極限構造も異なりますが， 現在の状態だけではなく，過去の軌道を通じて作用する点は共通しています．

1.3 internal-variable formulation

completely monotone kernelが \[ k(t)=\int_{[0,\infty)}e^{-\lambda t}\,d\nu(\lambda) \] と表されるとき，各緩和率 \(\lambda\) に対して \[ \zeta(\lambda,t) :=\int_0^t e^{-\lambda(t-s)}u(s)\,ds, \qquad \partial_t\zeta+\lambda\zeta=u \] を導入できます．すると， \[ (k*u)(t)=\int_{[0,\infty)}\zeta(\lambda,t)\,d\nu(\lambda) \] となり，時間非局所な方程式は，物理変数と連続個の内部変数からなる時間局所系へ移ります． これは単なる計算テクニックではなく，memoryが蓄えるエネルギーを可視化する表現です．

2．memory kernelは「与えられた係数」ではない

通常の偏微分方程式では，拡散係数や反応係数を既知として解析を始めることが多いでしょう． しかし，縮約モデルに現れるkernelは，未解像状態の時間スケール，結合の強さ， 初期分布，観測帯域に依存します．したがって，kernel自体が次の四つの操作の対象になります．

  1. 導出：拡張状態から未解像変数を消去し，kernelの形を求める．
  2. 同定：観測された解からkernelまたはそのパラメータを回収する．
  3. 近似：連続スペクトルや分布kernelを有限個の原子・指数関数へ置き換える．
  4. 検証：kernelの近似誤差が解の誤差へどう伝播するかを評価する．

この視点では，kernel quadratureやsum-of-exponentials approximationは， 積分公式だけではありません．未解像ダイナミクスのモデル簡約そのものです．

3．何が数学的ボトルネックになるのか

3.1 delayed operatorがpivot space上で有界とは限らない

遅延項が反応項ではなくprincipal spatial derivativeを含む場合， \(A_1:V\to V^*\) は自然でも，\(H\to V^*\) の有界作用素ではないことがあります． このとき，過去履歴を単に連続な \(H\)-値関数として扱う理論だけでは不十分です． 平方可積分な \(V\)-値履歴に対して，原子遅延を代表元の点評価なしに定義する必要があります．

3.2 dissipativeであることとcoerciveであることは違う

positive-type memoryは非負のmemory dissipationを与えます．しかし， それが瞬時の \(L^2(0,T;V)\) エネルギーを一様に支配するとは限りません． completely monotone kernelでは，高周波に対するmemory symbolが零へ減衰するため， memoryはゆっくり変化する成分を強く見る一方，急速に振動する成分には弱くなります．

重要な区別
positive type \(\Rightarrow\) memory dissipationは非負．
positive type \(\nRightarrow\) memoryだけで瞬時エネルギーを周波数一様に支配できる．

3.3 瞬時coercivityが消えると，自然な状態空間が変わる

瞬時拡散 \(A_0\) がcoerciveなら，通常のparabolic energy spaceが基礎になります． 一方，そのcoercivityが退化すると，物理変数 \(u\) だけのノルムではなく， 内部変数 \(\zeta\) が蓄えるmemory energyを含む拡張状態を使う必要があります． この拡張状態のzero-prehistory軌道がmemory graph spaceを形成します．

4．連続理論からすでに分かる四つの境界

  1. coercive regimeの有限時間適切性： 瞬時作用がcoerciveで，遅延測度が有限かつ原点に原子をもたない場合， exponential weightによってcausal history operatorを縮小写像にできます． kernelのtotal variationが小さいという仮定や，遅延形式の符号条件は不要です．
  2. kernel stability： signed kernelにはtotal-variation型の定量評価があり， non-negative kernelにはnarrow convergenceによる強収束が得られます． ただし，連続密度をDirac原子へ集中させる極限はtotal variationでは近づかないため， topologyの選択自体が問題の一部です．
  3. positive-lag concentrationとzero-delay boundary： 正の遅延位置へのdistributed-to-discrete concentrationは安定に扱えますが， 原点では原子が瞬時作用素を変えるため，同じ一様評価をそのまま延長できません．
  4. degenerate instantaneous diffusion： 瞬時coercivityが消えても適切性そのものが必ず失われるわけではありません． ただし，安定性を測るべき量はinstantaneous energyではなく， physical stateとinternal variablesを合わせたgraph energyです．

5．誤差は一つではない

完全離散解 \(U_{h,k,N}\) をfull modelの観測量 \(y_{\mathrm{full}}\) と比較するなら， 誤差は少なくとも次のように分ける必要があります． \[ \begin{aligned} y_{\mathrm{full}}-U_{h,k,N} ={}&\underbrace{(y_{\mathrm{full}}-u_{\mu})}_{\text{model reduction}}\\ &+\underbrace{(u_{\mu}-u_{\mu_N})}_{\text{kernel approximation}}\\ &+\underbrace{(u_{\mu_N}-u_{h,\mu_N})}_{\text{space discretisation}}\\ &+\underbrace{(u_{h,\mu_N}-U_{h,k,N})}_{\text{time/history discretisation}}. \end{aligned} \]

第一項は，未解像状態をmemory modelへ置き換えたことによるモデル誤差です． 第二項はkernelを有限原子や有限緩和モードへ近似した誤差， 第三項と第四項が通常の空間・時間離散化誤差です． これらを混ぜると，メッシュを細かくしても減らない誤差をFEMの失敗と誤認することになります．

目標は概念的に \[ \|y_{\mathrm{full}}-U_{h,k,N}\| \le C\bigl( E_{\mathrm{model}}+E_{\mathrm{kernel}} +E_{\mathrm{space}}+E_{\mathrm{time}} \bigr) \] という評価です．さらに，\(C\) が瞬時coercivity parameter，空間メッシュ幅， 時間刻み，原子数，緩和スペクトルのquadratureへ不必要に依存しないことが重要です．

6．なぜ「構造保存」完全離散化が必要なのか

安定な連続問題を離散化しても，連続レベルの打消しを壊せば， 離散安定性定数が急激に悪化する可能性があります．本連載で保存すべき構造は，主に次の三つです．

  • causality：未来値を用いず，履歴作用素の向きを保つこと．
  • memory energy：内部変数の散逸と終端エネルギーを非負の形で再現すること．
  • cross-term cancellation：物理方程式と内部変数方程式の結合項が離散レベルでも正確に打ち消し合うこと．

空間離散には，異方性メッシュ上のCrouzeix–Raviart／Raviart–Thomas構造を利用できます． 時間離散にはBDFとconvolution quadrature，あるいは有限原子kernelに対する内部変数更新が候補になります． 重要なのは，既存手法を並べるだけでなく，連続graph energyに対応する離散エネルギーを先に定め， そのエネルギーを保存・散逸するように空間と時間の離散化を組み合わせることです．

  1. 第1回：研究全体の誤差構造と，delay・Volterra memory・internal variablesの位置付け．
  2. 第2回：未解像状態の厳密消去からmemory kernelが現れる仕組み．
  3. 第3回：measure-valued delayによる分布遅延・原子遅延・混合遅延の統一．

Conclusion

未解像状態を削除した後に残るmemoryは，経験的な補正項とは限りません． 拡張状態から厳密に導出できる場合があり，そのkernelは同定・近似・検証の対象になります． 一方，memoryがdissipativeであっても，通常の瞬時エネルギーを一様に制御するとは限りません． したがって，モデル，状態空間，安定性，離散エネルギーを同時に設計する必要があります．

\[ \text{unresolved dynamics} \longrightarrow \text{memory representation} \longrightarrow \text{kernel stability} \longrightarrow \text{structure-preserving computation} \]
