第15回：CRとRTはなぜ相性がよいのか — 離散部分積分とcommuting property

ChatGPTで作る有限要素プログラム入門 Season 2 第3回（通算第15回）
29th August 2026

はじめに――「どちらもedge-basedだから」では足りない

第13回ではCrouzeix–Raviart（CR）要素のedge-mean DoFを， 第14回ではRaviart–Thomas（RT）要素のnormal-flux DoFを実装しました．

両者はどちらもface / edgeに自由度を持つので， 見た目にも相性がよさそうです． しかし本質はそこではありません．

CR–RT compatibilityの核心
CRの \[ \int_F[\psi_h]\,ds=0 \] と，RTの \[ [[\boldsymbol v_h\cdot\boldsymbol n_F]]=0 \] が組み合わさると，face termがexactに消える離散部分積分が成立する．

この恒等式が，CRのconsistency errorをRT interpolation errorへ移す鍵になります．

1．二つのglobal continuityをもう一度確認する

homogeneous CR spaceでは，内部face \(F\) に対して \[ \boxed{ \int_F[\psi_h]\,ds=0, } \tag{1} \] 境界faceでは \[ \boxed{ \int_F\psi_h\,ds=0. } \tag{2} \]

一方，lowest-order RT spaceでは内部faceに対して \[ \boxed{ [[\boldsymbol v_h\cdot\boldsymbol n_F]]=0. } \tag{3} \] さらに \[ \boldsymbol v_h\cdot\boldsymbol n_F\in P_0(F), \tag{4} \] つまりnormal componentは各face上でconstantです．

式 (1)–(4) の組合せが重要です．

2．要素ごとのGreen公式を全部足す

\[ \boldsymbol v_h\in V_h^{RT0}, \qquad \psi_h\in H_0^1(\Omega)+V_{h0}^{CR} \] とします． 要素 \(T\) ごとには \[ \int_T \boldsymbol v_h\cdot\nabla\psi_h\,dx + \int_T (\nabla\cdot\boldsymbol v_h)\psi_h\,dx = \int_{\partial T} (\boldsymbol v_h\cdot\boldsymbol n_T)\psi_h\,ds. \tag{5} \]

全要素で足すと \[ \sum_{T\in\mathcal T_h} \int_T \boldsymbol v_h\cdot\nabla_h\psi_h\,dx + \sum_{T\in\mathcal T_h} \int_T (\nabla\cdot\boldsymbol v_h)\psi_h\,dx = \sum_{T\in\mathcal T_h} \int_{\partial T} (\boldsymbol v_h\cdot\boldsymbol n_T)\psi_h\,ds. \tag{6} \]

3．interior-face termをjump / averageで見る

内部face \(F\) の寄与は \[ \int_F [[(\boldsymbol v_h\psi_h)\cdot\boldsymbol n_F]] \,ds. \] 積のjumpを分けると \[ [[(\boldsymbol v_h\psi_h)\cdot\boldsymbol n_F]] = [[\boldsymbol v_h\cdot\boldsymbol n_F]] \{\!\{\psi_h\}\!\} + \{\!\{\boldsymbol v_h\}\!\}\cdot\boldsymbol n_F [\psi_h]. \tag{7} \]

第一項はRT conformityから \[ [[\boldsymbol v_h\cdot\boldsymbol n_F]]=0 \] なので消えます．

第二項では \[ \{\!\{\boldsymbol v_h\}\!\}\cdot\boldsymbol n_F \in P_0(F) \] なのでface上でconstantです．したがって \[ \int_F \{\!\{\boldsymbol v_h\}\!\}\cdot\boldsymbol n_F [\psi_h]\,ds = \left( \{\!\{\boldsymbol v_h\}\!\}\cdot\boldsymbol n_F \right) \int_F[\psi_h]\,ds = 0. \tag{8} \]

境界faceでもCR0のface meanが0なので同様に消えます．

4．CR–RT discrete integration by parts

従って \[ \boxed{ \int_\Omega \boldsymbol v_h\cdot\nabla_h\psi_h\,dx + \int_\Omega (\nabla\cdot\boldsymbol v_h)\psi_h\,dx = 0 } \tag{9} \] が成立します．

ここで \[ \boldsymbol v_h\in V_h^{RT0}, \qquad \psi_h\in H_0^1(\Omega)+V_{h0}^{CR}. \]

この式はestimateではなくidentity
mesh sizeが小さいから近似的に0になるのではありません． CRのmean continuityとRTのnormal continuityが正しく実装されていれば， exact arithmeticで0になります．

5．ここで誤解してはいけないこと

式 (9) から \[ \nabla_hV_h^{CR} \subset V_h^{RT0} \] と結論してはいけません．

CR functionのbroken gradientは各elementでconstantなので \[ (\nabla_h\psi_h)|_T\in P_0(T)^d\subset RT_0(T) \] ですが，隣接element間でnormal componentが連続とは限りません． 従って一般には \[ \boxed{ \nabla_h\psi_h\notin V_h^{RT0}. } \tag{10} \]

CR–RT compatibilityとは， 「CR gradientそのものがglobal RT fieldになる」という意味ではなく， RT fieldとCR test functionの間にexactな離散Green公式が成立する という意味です．

6．CR誤差は二つに分ける――第13回との接続

Poisson問題 \[ -\Delta u=f, \qquad u|_{\partial\Omega}=0 \tag{11} \] のCR approximationではSecond Strang lemmaにより \[ |u-u_h^{CR}|_{1,h} \le C \left[ \inf_{v_h\in V_{h0}^{CR}} |u-v_h|_{1,h} + \sup_{0\neq\phi_h\in V_{h0}^{CR}} \frac{ |a_h^{CR}(u,\phi_h)-(f,\phi_h)| }{ |\phi_h|_{1,h} } \right]. \tag{12} \]

ここで

\[ \boxed{ \text{CR error} = \text{interpolation / approximation error} + \text{consistency error} } \]

という二分割が本質です．

第15回で見るのは，第二項のconsistency errorにRTを入れる方法です．

7．任意のRT fieldをconsistency termへ挿入する

式 (9) を使うと，任意の \[ \boldsymbol w_h\in V_h^{RT0} \] に対して \[ \boxed{ a_h^{CR}(u,\phi_h)-(f,\phi_h) = (\nabla u-\boldsymbol w_h,\nabla_h\phi_h) - (\nabla\cdot\boldsymbol w_h+f,\phi_h). } \tag{13} \]

これはCRのnonconforming face residualを，

\[ \text{vector approximation error} + \text{divergence residual} \]

へ変換するidentityです．

どの \(\boldsymbol w_h\) を選ぶかが次のポイントです．

8．\(\boldsymbol w_h=I_h^{RT0}\nabla u\) を選ぶ

exact flux-like field \[ \nabla u \] をlowest-order RT interpolationして \[ \boldsymbol w_h = I_h^{RT0}\nabla u \tag{14} \] とします．

第14回で見たcommuting property \[ \nabla\cdot I_h^{RT0}\boldsymbol v = \Pi_h^0(\nabla\cdot\boldsymbol v) \tag{15} \] を \(\boldsymbol v=\nabla u\) に使えば \[ \nabla\cdot I_h^{RT0}\nabla u = \Pi_h^0\Delta u = -\Pi_h^0f. \tag{16} \]

9．RT interpolationのdomainに再び注意する

ここで \[ I_h^{RT0}\nabla u \] と書くためには，RT face momentsが定義できるregularityが必要です．

第14回で確認したように， standard RT interpolationは \(H(\mathrm{div})\) 全体にそのまま定義できるわけではありません．

今回のPoisson settingでは，例えばconvex polygon / polyhedronで \[ f\in L^2(\Omega), \qquad u\in H^2(\Omega) \tag{17} \] というelliptic regularityを仮定すれば \[ \nabla u\in H^1(\Omega)^d \] なので，classicalなface-moment RT interpolationを使えます．

数学監査上の注意
\[ \nabla u\in H(\mathrm{div}) \] だけを理由に \[ I_h^{RT0}\nabla u \] を無条件に書いてはいけない．

10．consistency errorが二つのbulk errorに変わる

式 (13)–(16) から \[ a_h^{CR}(u,\phi_h)-(f,\phi_h) = (\nabla u-I_h^{RT0}\nabla u,\nabla_h\phi_h) - (f-\Pi_h^0f,\phi_h). \tag{18} \]

さらに \(L^2\)-projectionの直交性から \[ (f-\Pi_h^0f,\Pi_h^0\phi_h)=0 \] なので \[ \boxed{ a_h^{CR}(u,\phi_h)-(f,\phi_h) = (\nabla u-I_h^{RT0}\nabla u,\nabla_h\phi_h) - (f-\Pi_h^0f,\phi_h-\Pi_h^0\phi_h). } \tag{19} \]

ここでface trace termが完全に消えています．

11．Cauchy–Schwarzでconsistency boundへ

式 (19) から \[ \begin{aligned} |a_h^{CR}(u,\phi_h)-(f,\phi_h)| \le{}& \|\nabla u-I_h^{RT0}\nabla u\|_{L^2(\Omega)^d} |\phi_h|_{1,h} \\ &+ \|f-\Pi_h^0f\|_{L^2(\Omega)} \|\phi_h-\Pi_h^0\phi_h\|_{L^2(\Omega)}. \end{aligned} \tag{20} \]

elementwise \(P_0\)-projectionについて \[ \|\phi_h-\Pi_h^0\phi_h\|_{L^2(\Omega)} \le Ch|\phi_h|_{1,h} \tag{21} \] を使えば \[ \boxed{ \frac{ |a_h^{CR}(u,\phi_h)-(f,\phi_h)| }{ |\phi_h|_{1,h} } \le \|\nabla u-I_h^{RT0}\nabla u\|_{L^2(\Omega)^d} + Ch\|f-\Pi_h^0f\|_{L^2(\Omega)}. } \tag{22} \]

粗い評価 \[ \|f-\Pi_h^0f\|_{L^2} \le \|f\|_{L^2} \] を使えば第二項は \(Ch\|f\|_{L^2}\) です．

12．なぜ異方性meshでこの変換が重要なのか

classicalなconsistency analysisでは，element boundaryに残る \[ \int_F (\boldsymbol n_T\cdot\nabla u) (\phi_h-\overline{\phi}_F) \,ds \] をtrace theoremとscalingで直接評価します．

しかし強い異方性meshでは，このtrace scalingにelement heightやdegeneration parameterが入り， 期待するorderを失うことがあります．

式 (19) はそのface termを \[ \boxed{ \|\nabla u-I_h^{RT0}\nabla u\|_{L^2} } \] というRT interpolation errorへ置き換えます．

従ってanisotropic RT interpolation estimateがあれば， CR consistency errorもdirectional geometryを保ったまま評価できます． これがCR–RT relationをanisotropic CR analysisに使う理由です．

13．二つのcommuting propertyを並べて見る

十分regularなscalar function \(u\) についてlocal CR interpolationは \[ \boxed{ \nabla I_T^{CR}u = \Pi_T^0\nabla u. } \tag{23} \]

十分regularなvector field \(\boldsymbol v\) についてRT interpolationは \[ \boxed{ \nabla\cdot I_T^{RT0}\boldsymbol v = \Pi_T^0\nabla\cdot\boldsymbol v. } \tag{24} \]

両者はそれぞれ

\[ \text{CR} \ \xrightarrow{\nabla_h}\ P_0^d, \qquad \text{RT} \ \xrightarrow{\nabla\cdot}\ P_0 \]

という微分作用素との整合性を持っています．

ただし式 (23) はlocal identityであり， \(\nabla_hI_h^{CR}u\) がglobal \(H(\mathrm{div})\)-conforming RT fieldになるという意味ではありません．

14．CR interpolation identityの短い証明

\(\nabla I_T^{CR}u\) はconstantなので \[ |T|\nabla I_T^{CR}u = \int_T\nabla I_T^{CR}u\,dx. \] Gaussの公式とCR face-mean reproductionを使うと \[ \begin{aligned} |T|\nabla I_T^{CR}u &= \sum_{F\subset\partial T} \boldsymbol n_F \int_FI_T^{CR}u\,ds \\ &= \sum_{F\subset\partial T} \boldsymbol n_F \int_Fu\,ds = \int_T\nabla u\,dx. \end{aligned} \tag{25} \]

従って \[ \nabla I_T^{CR}u = \frac1{|T|} \int_T\nabla u\,dx = \Pi_T^0\nabla u. \]

15．二三角形で離散部分積分をexactにtestする

unit squareを対角線で二つの三角形に分けます． boundary CR DoFを0，interior diagonalのCR DoFを1とし， RT側にはglobal edge fluxとして例えば \[ (0.7,-1.2,0.4,0.9,-0.3) \] を与えます．

各elementで \[ R_T = \int_T \boldsymbol v_h\cdot\nabla_h\psi_h\,dx + \int_T (\nabla\cdot\boldsymbol v_h)\psi_h\,dx \tag{26} \] をexact integrationすると， \[ R_{T_1}=1.2, \qquad R_{T_2}=-1.2, \] 従って \[ \boxed{ R_{T_1}+R_{T_2}=0. } \tag{27} \]

element residualはそれぞれ0ではありません． shared faceを通じてexactにcancelすることがポイントです．

16．Pythonでは何をtestすべきか

def discrete_green_residual(
    triangles,
    rt_field,
    cr_field,
    integrate_element
):
    total = 0.0
    element_residuals = []

    for T in triangles:
        rT = integrate_element(
            T,
            rt_field,
            cr_field
        )

        element_residuals.append(rT)
        total += rT

    return (
        np.array(element_residuals),
        total
    )


element_r, total_r = (
    discrete_green_residual(
        triangles,
        rt_field,
        cr_field,
        integrate_element
    )
)

print(element_r)
print(total_r)

test specificationは

\[ \boxed{ |\texttt{total\_r}| \le C\varepsilon_{\mathrm{mach}} \times \text{appropriate scale} } \tag{28} \]

です．

各element residualを0と要求してはいけません． global cancellationをtestします．

17．このtestはorientation bugにも敏感

第14回で扱ったRT edge signを一つ反転すると， shared edgeのnormal continuityが壊れます． すると式 (3) が成立せず， 式 (9) のglobal residualも0ではなくなります．

逆にCR側で同じphysical edgeを別々のglobal DoFとして扱えば， 式 (1) が壊れ，同じtestが失敗します．

つまりdiscrete Green identityは

\[ \boxed{ \text{CR connectivity} + \text{RT orientation} + \text{local integration} } \]

を同時に監査するintegration testになります．

18．「CRとRTが相性よい」には三段階ある

level structure
DoF level CR face mean / RT normal flux
operator level discrete integration by parts + commuting properties
error-analysis level CR consistency errorをRT interpolation errorで制御

第15回で重要なのは第三段階まで見ることです．

19．より強いCR–RT solution relationとは区別する

Poisson問題では，piecewise-constant loadやbubble enrichmentなど追加の条件の下で， CR solutionとRT mixed solutionの間にさらに強い関係式が得られる場合があります．

しかし今回の式 (9) はそれとは別です．

\[ \boxed{ \text{discrete integration by parts} } \] は有限要素空間のcontinuity structureから出るidentityであり， 特定のdiscrete solutionを解いた後に初めて成立する関係ではありません．

solution-levelのCR–RT relationは，後の回で必要になったところで扱います．

20．ChatGPTへのCR–RT structure audit prompt

Audit prompt
このCR–RT finite-element implementationを構造的に監査してください．
(1) CRのinterior face jumpがmean zeroか，
(2) CR0のboundary face meanがzeroか，
(3) RT0のnormal componentが各face上でconstantか，
(4) global RT normal componentがsingle-valuedか，
(5) \((v_h,\nabla_h\psi_h)+(\operatorname{div}v_h,\psi_h)=0\) がglobalに成立するか，
(6) elementwise residualではなくglobal cancellationをtestしているか，
(7) CR gradientを誤ってglobal RT fieldと仮定していないか，
(8) \(I_h^{RT}\nabla u\) を使うときRT interpolationのdomain regularityを確認しているか，
(9) \(\operatorname{div}I_h^{RT}\nabla u=-\Pi_h^0f\) を使っているか，
(10) CR consistency errorをRT interpolation errorと\(P_0\)-projection errorへ正しく変換しているか
を順に確認してください．

21．第15回の結論

CRとRTの相性は，単に両方がface-based elementだからではありません．

CRは \[ \int_F[\psi_h]\,ds=0 \] を，RTは \[ [[\boldsymbol v_h\cdot\boldsymbol n_F]]=0 \] を持ち，RT0 normal componentがface上でconstantであるため，

\[ \boxed{ (\boldsymbol v_h,\nabla_h\psi_h) + (\nabla\cdot\boldsymbol v_h,\psi_h) = 0 } \tag{29} \]

というexactな離散部分積分が成立します．

さらに \[ \boldsymbol v_h=I_h^{RT0}\nabla u \] を選び， \[ \nabla\cdot I_h^{RT0}\nabla u=-\Pi_h^0f \] を使うことで，CRのconsistency errorは \[ \boxed{ \text{RT interpolation error} + P_0\text{-projection error} } \] へ変換されます．

Season 2 第3回の原則
CR–RT relationの本質は， nonconforming face errorを\(H(\mathrm{div})\)-conforming fluxのbulk errorへ移すことにある．
