第6回：graph-space well-posednessとは何か

2nd August 2026

Introduction：no-go theoremはill-posednessを意味しない

前回は，completely monotone kernelがpositive-type dissipationを与えても， memory dissipationだけでは瞬時energy \[ \int_0^T a_1(u(t),u(t))\,dt \] を周波数一様に支配できないことを見ました． 高い時間周波数に対してmemory symbolが0へ減衰するため， 失われた \(L^2(0,T;V)\)-coercivityをmemoryだけで回復することはできません．

しかし，ここから 「瞬時拡散が退化すれば方程式は解けない」 と結論してはいけません． 失敗したのは方程式そのものではなく， 瞬時 \(V\)-energyだけで安定性を測る試みです．

今回の結論
memoryが選ぶ内部変数energyを状態に組み込み， 物理変数と内部変数を一つの拡張状態として扱えば， 瞬時形式 \(a_0\) に正のcoercivity constantがなくても contraction semigroupとHadamard well-posednessを得られる．

この拡張状態のzero-prehistory軌道が作る空間を memory graph spaceと呼びます． ここでいうgraphは，生成作用素のoperator graphではなく， 物理軌道 \(u\) と，そこから因果的に生成される内部変数軌道とのgraphです．

1．coercive regimeとdegenerate regimeの違い

有界Lipschitz領域 \(\Omega\subset\mathbb R^d\)，\(d\in\{1,2,3\}\) 上で \[ H:=L^2(\Omega), \qquad V:=H_0^1(\Omega) \] とし， \[ \partial_tu(t)+A_0u(t)+A_1(k*u)(t)=f(t), \qquad u(0)=u_0 \tag{1} \] を考えます．zero prehistoryを選び， \[ (k*u)(t):=\int_0^t k(t-s)u(s)\,ds. \tag{2} \]

\(A_0,A_1:V\to V^*\) は対称な双線形形式 \(a_0,a_1\) から生成されるとします． 今回の仮定は \[ a_0(v,v)\ge0, \tag{3} \] \[ a_1(v,v)\ge\beta |v|_V^2, \qquad \beta>0 \tag{4} \] です．

第4回のweighted well-posednessでは，瞬時形式に \[ a_0(v,v)\ge\alpha_0\|v\|_V^2, \qquad \alpha_0>0 \] を仮定し，memoryをcoercive parabolic problemへのperturbationとして扱いました． 今回は \(\alpha_0\) を使えません． \(a_0\) は非負ではあるものの，\(V\)-normを下から支配しない可能性があります．

regime 安定性を支えるもの 自然な状態
coercive instantaneous diffusion \(a_0(v,v)\ge\alpha_0\|v\|_V^2\) 物理変数 \(u\)
degenerate instantaneous diffusion 物理energy＋internal-variable energy 拡張状態 \((u,\zeta)\)

2．completely monotone kernelを緩和モードへ分解する

kernel \(k\) は非自明なcompletely monotone kernelとし， Bernstein representation \[ k(t) = \int_{[0,\infty)} e^{-\lambda t}\,d\nu(\lambda) \tag{5} \] をもつとします． \(\nu\) は緩和率 \(\lambda\) の分布です．

今回のsemigroup構成に必要な量は \[ M_0 := \nu([0,\infty)) = k(0+) \tag{6} \] です．基本理論では \[ 0

ここで \(M_0\) と時間kernelの総質量 \[ \|k\|_{L^1(0,\infty)} = \int_{(0,\infty)}\lambda^{-1}\,d\nu(\lambda) \tag{8} \] を混同してはいけません． graph-space theoryを支えるのは，まずBernstein measureの総質量 \(M_0\) です．

例えばProny kernel \[ k(t)=\sum_{j=1}^Jc_je^{-\gamma_jt}, \qquad c_j,\gamma_j>0 \] では \[ \nu=\sum_{j=1}^Jc_j\delta_{\gamma_j}, \qquad M_0=\sum_{j=1}^Jc_j, \qquad \|k\|_{L^1}=\sum_{j=1}^J\frac{c_j}{\gamma_j}. \tag{9} \] 両者は異なる量です．

3．内部変数によって非局所memoryを時間局所系へ戻す

各 \(\lambda\ge0\) に対して \[ \zeta(\lambda,t) := \int_0^t e^{-\lambda(t-s)}u(s)\,ds \tag{10} \] を導入します．固定した \(\lambda\) ごとに \[ \partial_t\zeta(\lambda,t) +\lambda\zeta(\lambda,t) = u(t), \qquad \zeta(\lambda,0)=0. \tag{11} \]

memory potentialを \[ \xi(t) := \int_{[0,\infty)} \zeta(\lambda,t)\,d\nu(\lambda) \tag{12} \] とすると，Fubiniの定理により \[ \xi(t)=(k*u)(t). \tag{13} \] 従って式 (1) は \[ \partial_tu+A_0u+A_1\xi=f, \tag{14} \] \[ \partial_t\zeta(\lambda,\cdot) +\lambda\zeta(\lambda,\cdot) =u \tag{15} \] という拡張系になります．

局所化の意味
\(u\) だけを見ると方程式は過去全体に依存する．
\((u,\zeta)\) を状態とすれば，各時刻の状態だけで次の変化が決まる．

つまり，memory equationを直接扱う代わりに， 連続個の緩和モードを含むMarkov型の拡張系へ戻します．

4．memoryが選ぶ内部変数空間

内部変数familyのenergyを \[ \|\zeta\|_{\mathcal K}^2 := \int_{[0,\infty)} a_1\bigl(\zeta(\lambda),\zeta(\lambda)\bigr) \,d\nu(\lambda) \tag{16} \] と定めます． \(a_1\) が \(V\) 上coerciveなので，これは \[ \int_{[0,\infty)} \|\zeta(\lambda)\|_V^2\,d\nu(\lambda) \] と同値なnormになります．

このHilbert空間を \(\mathcal K\) と書き， 物理変数と組み合わせて \[ \mathcal W:=H\times\mathcal K \tag{17} \] をextended memory state spaceとします．内積は \[ \begin{aligned} \bigl\langle (u,\zeta),(v,\chi)\bigr\rangle_{\mathcal W} &:= (u,v)_H\\ &\quad+ \int_{[0,\infty)} a_1\bigl(\zeta(\lambda),\chi(\lambda)\bigr) \,d\nu(\lambda). \end{aligned} \tag{18} \]

対応するenergyは \[ \|(u,\zeta)\|_{\mathcal W}^2 = \|u\|_H^2 + \int_{[0,\infty)} a_1\bigl(\zeta(\lambda),\zeta(\lambda)\bigr)\,d\nu(\lambda). \tag{19} \]

前回のno-go theoremで不足したのは， まさに第二項でした． 瞬時の \(u\)-energyだけでは見えないmemory storageを， 状態normへ明示的に戻しています．

5．memory graph spaceはtrajectory space内のgraphである

任意の \(u\in C([0,T];H)\) に対して，causal internal-variable map \[ (\mathcal Ru)(t)(\lambda) := \int_0^t e^{-\lambda(t-s)}u(s)\,ds \tag{20} \] を定めます． 有限 \(M_0\) により，\(\mathcal R\) は適切な \(\nu\)-weighted \(H\)-spaceへ連続に写ります．

zero-prehistory memory graph spaceを \[ \begin{aligned} \mathcal G_\nu(0,T) := \bigl\{ &(u,\zeta)\in C([0,T];\mathcal W):\\ &\zeta(t)=(\mathcal Ru)(t) \text{ for every }t\in[0,T] \bigr\} \tag{21} \end{aligned} \] と定めます．等式は，\(\nu\)-ほとんどすべての \(\lambda\) に対する \(H\)-値関数の等式として理解します．

normは \[ \|(u,\zeta)\|_{\mathcal G_\nu(0,T)} := \sup_{0\le t\le T} \|(u(t),\zeta(t))\|_{\mathcal W}. \tag{22} \] \(\mathcal G_\nu(0,T)\) は \(C([0,T];\mathcal W)\) の閉部分空間なのでBanach空間です．

用語上の注意
memory graph spaceは， \(u\mapsto\mathcal Ru\) のtrajectory graphである．
生成作用素 \(\mathcal A\) のoperator graph norm \(\|X\|_{\mathcal W}+\|\mathcal AX\|_{\mathcal W}\) を意味するのではない．

6．aggregationとconstant embedding

二つの作用素がenergy cancellationの中心になります．

aggregation operatorを \[ J:\mathcal K\to V, \qquad J\zeta := \int_{[0,\infty)} \zeta(\lambda)\,d\nu(\lambda), \tag{23} \] constant embeddingを \[ E:V\to\mathcal K, \qquad (Eu)(\lambda):=u \tag{24} \] と定めます．

\(M_0<\infty\) により，両者は有界です．特に \[ \|Eu\|_{\mathcal K}^2 = M_0a_1(u,u), \tag{25} \] また \[ a_1(J\zeta,J\zeta)^{1/2} \le M_0^{1/2}\|\zeta\|_{\mathcal K}. \tag{26} \]

さらに，memory energyに関して \[ a_1(J\zeta,u) = \langle\zeta,Eu\rangle_{\mathcal K} \tag{27} \] が成り立ちます． これは \(J\) と \(E\) のadjoint relationであり， 後のcross-term cancellationを生みます．

7．augmented generatorを作る

緩和作用素を \[ (\Lambda\zeta)(\lambda):=\lambda\zeta(\lambda) \tag{28} \] とします．拡張状態 \[ X=(u,\zeta) \] に対し， \[ \mathcal A(u,\zeta) := \bigl( -A_0u-A_1J\zeta,\, Eu-\Lambda\zeta \bigr) \tag{29} \] と定めます．

domainは概念的に \[ \begin{aligned} D(\mathcal A) := \bigl\{ (u,\zeta)\in V\times\mathcal K:\, &A_0u+A_1J\zeta\in H,\\ &Eu-\Lambda\zeta\in\mathcal K \bigr\}. \end{aligned} \tag{30} \]

すると拡張系は \[ X'(t) = \mathcal AX(t) +(f(t),0), \qquad X(0)=(u_0,0) \tag{31} \] というabstract Cauchy problemになります．

8．cross-term cancellationがenergyを閉じる

\(X=(u,\zeta)\in D(\mathcal A)\) に対して \[ \begin{aligned} \langle\mathcal AX,X\rangle_{\mathcal W} ={}& -a_0(u,u) -a_1(J\zeta,u)\\ &+\langle Eu,\zeta\rangle_{\mathcal K} -\int_{[0,\infty)} \lambda a_1(\zeta(\lambda),\zeta(\lambda)) \,d\nu(\lambda). \end{aligned} \tag{32} \]

式 (27) により \[ -a_1(J\zeta,u) +\langle Eu,\zeta\rangle_{\mathcal K} =0. \tag{33} \] 従って \[ \boxed{ \langle\mathcal AX,X\rangle_{\mathcal W} = -a_0(u,u) - \int_{[0,\infty)} \lambda a_1(\zeta(\lambda),\zeta(\lambda)) \,d\nu(\lambda) \le0 } \tag{34} \] です．

ここが構造保存の核心
物理方程式がmemoryへ渡すenergyと， 内部変数方程式が物理変数から受け取るenergyが， 拡張内積の中で正確に相殺する．

重要なのは，式 (34) が \[ a_0(u,u)\ge0 \] しか使っていないことです． \(a_0\) の正のcoercivity constantは一度も現れません．

9．m-dissipativeとは何を保証するのか

式 (34) は \(\mathcal A\) がdissipativeであることを示します． しかし，dissipativityだけでは任意の初期値から解を生成できません． さらに \[ \operatorname{Ran}(I-\mathcal A) = \mathcal W \tag{35} \] というrange conditionが必要です．

range equation \[ (I-\mathcal A)(u,\zeta)=(g,h) \] では，内部変数の式を \(\lambda\) ごとに解いて \(\zeta\) を消去し， 残る \(u\)-方程式をLax–Milgram型のcoercive problemへ帰着できます． このrange conditionとdissipativityを合わせると， \(\mathcal A\) はm-dissipativeです．

Lumer–Phillips theoremにより， \(\mathcal A\) は \(\mathcal W\) 上の \(C_0\)-contraction semigroup \[ (S(t))_{t\ge0} \] を生成します．

10．mild solutionとcontraction estimate

\(u_0\in H\)，\(f\in L^1(0,T;H)\) に対して， 式 (31) は一意なmild solution \[ X=(u,\zeta)\in C([0,T];\mathcal W) \tag{36} \] をもち， \[ X(t) = S(t)(u_0,0) + \int_0^t S(t-s)(f(s),0)\,ds. \tag{37} \]

semigroupがcontractionなので \[ \|X(t)\|_{\mathcal W} \le \|u_0\|_H + \int_0^t\|f(s)\|_H\,ds. \tag{38} \]

二つのデータ \((u_{0,1},f_1)\)，\((u_{0,2},f_2)\) に対しても \[ \begin{aligned} \|X_1-X_2\|_{C([0,T];\mathcal W)} \le{}& \|u_{0,1}-u_{0,2}\|_H\\ &+ \|f_1-f_2\|_{L^1(0,T;H)}. \end{aligned} \tag{39} \]

このestimateに，\(a_0\) の正のcoercivity constantは含まれません． したがって，瞬時coercivityが0へ近づくfamilyに対しても同じ形のboundが残ります．

11．Hadamard well-posednessはmemory graph spaceで成立する

semigroup solutionの内部変数は， 単に任意の \(\mathcal K\)-値軌道ではありません． zero initial memoryのもとで \[ \zeta(t)=\mathcal Ru(t) \] を満たします．従って \[ (u,\zeta)\in\mathcal G_\nu(0,T). \]

式 (38) はそのまま \[ \|(u,\zeta)\|_{\mathcal G_\nu(0,T)} \le \|u_0\|_H + \|f\|_{L^1(0,T;H)} \tag{40} \] となります．

存在，一意性，データに対するLipschitz連続依存性が 同じBanach空間で成立するため， degenerate memory problemは memory graph spaceにおいてHadamardの意味でwell posedです．

ここで状態空間を変更したことは， 問題を弱くしたことではありません． 消去されていたmemory storageを状態へ戻し， 方程式が実際に制御するenergyで測り直したものです．

12．なぜ通常のweak formulationをそのまま使えないのか

graph-space mild solutionから直接得られるのは \[ u\in C([0,T];H) \] であり，一般には \[ u\in L^2(0,T;V) \tag{41} \] を自動的には得られません． これは前回のno-go theoremと整合しています．

従って，通常のparabolic weak formulationで現れる \[ a_0(u(t),v) \] を直ちに書くことはできません． また，\(V^*\)-\(V\) pairingを使った標準energy calculationも， 追加の \(V\)-regularityなしには正当化できません．

この点が，単に「semigroup solutionを得た」で終わらず， 弱形式との同定に別の工夫が必要になる理由です．

13．finite first momentとencoded weak formulation

追加のmoment \[ M_1 := \int_{[0,\infty)} \lambda\,d\nu(\lambda) = -k'(0+) \tag{42} \] が有限であるとします． first-moment fieldを \[ \eta(t) := \int_{[0,\infty)} \lambda\zeta(\lambda,t)\,d\nu(\lambda) \tag{43} \] と定めると， \[ \partial_t\xi = M_0u-\eta. \tag{44} \] 従って \[ u = \frac1{M_0} \bigl(\partial_t\xi+\eta\bigr). \tag{45} \]

\(\xi\) と \(\eta\) は \(V\)-値fieldとして制御できるため， 式 (45) を使って \(a_0u\) の情報を \(\xi\) と \(\eta\) へ移し，時間積分によって \(\partial_t\xi\) をtest function側へ移せます． これがencoded weak formulationの考え方です．

\(M_0,M_1<\infty\) のもとで，graph-space mild solutionは \[ \xi\in C([0,T];V)\cap H^1(0,T;H), \] \[ \eta\in L^2(0,T;V), \tag{46} \] および式 (44) を満たし， encoded weak solutionと同定できます．

moment条件の役割は明確に分かれます．

条件 得られるもの

さらに \(M_1<\infty\) \(\eta\) のregularity，encoded weak formulation，explicit bounds

14．explicit graph-space stability

\(f\in L^2(0,T;H)\) とし， \[ D_0 := \|u_0\|_H^2 + \|f\|_{L^2(0,T;H)}^2. \tag{47} \] \(M_0,M_1<\infty\) のもとで， ある \(C_T>0\) に対し \[ \begin{aligned} \sup_{t\in[0,T]} \Biggl[ &\|u(t)\|_H^2 + \int_{[0,\infty)} a_1(\zeta(\lambda,t),\zeta(\lambda,t)) \,d\nu(\lambda) \Biggr]\\ &+ 2\int_0^T \int_{[0,\infty)} \lambda a_1(\zeta(\lambda,t),\zeta(\lambda,t)) \,d\nu(\lambda)\,dt \le C_TD_0. \end{aligned} \tag{48} \]

さらに \[ \sup_{t\in[0,T]}|\xi(t)|_V^2 \le C\,M_0D_0, \tag{49} \] \[ \int_0^T|\eta(t)|_V^2\,dt \le C\,M_1D_0. \tag{50} \]

これらのconstantには， \(a_0\) の正のcoercivity constantが含まれません． \(a_0\) が追加の非負dissipationを与えることはありますが， 安定性の基礎としては使用していません．

15．どのkernelが現在のgraph spaceに入るのか

kernel \(M_0\) \(M_1\) 現在の理論
single exponential finite finite 適用可能
finite Prony series finite finite 適用可能
finite \(M_0\)，infinite \(M_1\) finite infinite semigroupは可能，encoded weak theoryは不足
fractional kernel infinite infinite 現在のfinite-mass graph spaceの外

fractional memory equationのsolvability自体が未解決なのではありません． 問題は，今回と同じ形の coercivity-independentで計算可能なgraph-space certificate を \(M_0=M_1=\infty\) の場合にどう構成するかです． そのためには，別のweighted state spaceが必要になります．

16．single exponentialでは一つの内部変数へ縮約される

\[ k(t)=\gamma e^{-\gamma t}, \qquad \gamma>0 \tag{51} \] なら \[ \nu=\gamma\delta_\gamma, \qquad M_0=\gamma, \qquad M_1=\gamma^2. \] 内部変数familyは一つの変数 \(\zeta(t)\) に縮約され， \[ \partial_t\zeta+\gamma\zeta=u, \tag{52} \] \[ \partial_tu+A_0u+\gamma A_1\zeta=f. \tag{53} \]

さらに \(u=\partial_t\zeta+\gamma\zeta\) を代入すると \[ \partial_{tt}\zeta +(\gamma+A_0)\partial_t\zeta +\gamma(A_0+A_1)\zeta = f. \tag{54} \] これはdegenerate Kelvin–Voigt型，またはstrongly damped wave型の方程式です． 一般のcompletely monotone kernelでは， 連続個の内部変数が必要であり，一つの二階方程式には縮約できません．

17．vanishing-coercivity limit

graph-space formulationの強みは， 瞬時coercivityが実際に0へ近づくfamilyを同じ状態空間で比較できることです．

\(a_v\) をcoerciveな形式として \[ a_0^\varepsilon := a_0+\varepsilon a_v, \qquad 0\le\varepsilon\le1 \tag{55} \] を考えます． \(\varepsilon>0\) では瞬時coercivityがありますが， \(\varepsilon=0\) では退化する可能性があります． memory kernel \(k\) とrepresenting measure \(\nu\) は固定します．

対応するgenerator \(\mathcal A_\varepsilon\) は すべて同じextended memory space \(\mathcal W\) 上で作用し， resolventは \[ \bigl\| (I-\mathcal A_\varepsilon)^{-1} - (I-\mathcal A_0)^{-1} \bigr\|_{\mathcal L(\mathcal W)} = O(\varepsilon). \tag{56} \] このnorm-resolvent convergenceから \[ S_\varepsilon(t)X \longrightarrow S_0(t)X \tag{57} \] およびinhomogeneous solutionの \(C([0,T];\mathcal W)\)-収束が得られます．

さらに，極限解の物理成分が追加的に \[ u^0\in L^2(0,T;V) \tag{58} \] を満たすなら， \[ \|X^\varepsilon-X^0\|_{C([0,T];\mathcal W)} \le C\varepsilon^{1/2} \left( \int_0^T a_v(u^0(t),u^0(t))\,dt \right)^{1/2}. \tag{59} \]

この \(O(\varepsilon^{1/2})\) rateには追加regularity (58) が必要です． それはmemory dissipationから自動的に出るものではありません．

18．数値解析で何を保存すべきか

continuous theoryは，structure-preserving discretisationの設計目標を明確にします．

  1. 共通の離散memory state space： 物理変数と離散内部変数を同じenergyで測る．
  2. 離散adjoint relation： aggregationとconstant embeddingの離散版が互いにadjointになる．
  3. cross-term cancellation： 連続式 (33) と同じ相殺を離散energy identityで再現する．
  4. coercivity-independent stability： reliability constantを退化する瞬時coercivityで割らない．
  5. vanishing-coercivity convergence： \(\varepsilon\downarrow0\) で離散解も同じgraph normに収束する．

瞬時 \(L^2(0,T;V)\)-normだけをcertificateに使うと， no-go theoremによりmemory-dominated regimeで一様性を失います． 一方，extended memory energyをcertificateに選べば， continuous stability targetと離散energyを一致させられます．

19．この理論が示すこと，示さないこと

示すこと

  • 瞬時形式が非負であれば，正のcoercivity constantなしに拡張状態のwell-posednessを得られる．
  • zero-prehistory solutionはmemory graph spaceに属する．
  • データから解への写像はgraph normでLipschitz連続である．
  • 有限 \(M_1\) のもとでmild solutionをencoded weak solutionと同定できる．
  • 瞬時coercivityが消える極限でも，同じmemory state spaceでsolution convergenceを扱える．

この理論だけでは示さないこと

  • 一般のgraph-space solutionが必ず \(L^2(0,T;V)\) に属するとは限らない．
  • fractional kernelに同じfinite-mass state spaceをそのまま使えるわけではない．
  • kernel自体が変化・集中する極限は，式 (55) のvanishing-coercivity limitとは別問題である．
  • 任意の時間離散法がcross-term cancellationを保存するわけではない．

Conclusion

positive-type memoryが瞬時energyをcoerciveに支配できないという事実は， degenerate problemのill-posednessを意味しません． それは，物理変数 \(u\) だけを状態とするenergy spaceが不完全であることを示しています．

internal-variable familyを状態へ戻し， \[ \mathcal W = H\times\mathcal K \] で測ると， aggregationとconstant embeddingのadjoint relationが cross-term cancellationを生みます． その結果，augmented generatorはm-dissipativeとなり， contraction semigroupとHadamard well-posednessが得られます．

\[ \text{no instantaneous coercivity} \not\Longrightarrow \text{ill-posedness} \] \[ \text{correct extended state} + \text{exact energy cancellation} \Longrightarrow \text{graph-space well-posedness} \]
