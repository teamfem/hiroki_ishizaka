第6回：異方性三角形ではJacobianをどう作るか — standard positionとtwo-step affine mapping

ChatGPTで作る有限要素プログラム入門 第6回
29th August 2026

はじめに――Jacobianは一つでも，その「読み方」は一つではない

第3回では，三角形 \[ T=\operatorname{conv}\{p_0,p_1,p_2\} \] に対し，標準的なJacobian \[ J_T=[p_1-p_0,\ p_2-p_0] \] を作りました． この行列はreference triangleをphysical triangleへ写すためには十分です． P1有限要素のassemblyも，このJacobianから正しく構成できます．

しかし，異方性解析ではそれだけでは不十分です． 知りたいのは「写像が存在するか」ではなく， どの方向にどれだけ伸び，どの部分が角度の悪化を表しているかです． そのため，三角形の頂点を標準的にラベル付けし， Jacobianを方向別scale，shape deformation，rotation/reflectionへ分けて考えます．

今回の核心
異方性解析では \[ J_T = A_T\,\widetilde A\,\widehat A \] と分解する．ここで \[ \widehat A=\operatorname{diag}(h_1,h_2) \] が方向別scale， \[ \widetilde A= \begin{pmatrix} 1&s\\ 0&t \end{pmatrix} \] が残りのshape deformation， \(A_T\in O(2)\) がrotation/reflectionを表す．

この構成は，筆者らの異方性補間理論で用いているtwo-step affine mappingに基づきます．

1．最初に頂点を標準的にラベル付けする

任意の非退化三角形 \(T\) の頂点を，いったん \(p_1,p_2,p_3\) と付け直します． まず最長辺を \[ p_2p_3 \] とし， \[ h_T:=|p_2-p_3|. \tag{1} \] 残った頂点を \(p_1\) とします． さらに \[ h_1:=|p_1-p_2|, \qquad h_2:=|p_1-p_3|, \qquad h_2\le h_1 \tag{2} \] となるように \(p_2,p_3\) を入れ替えます．

このとき \[ \frac12 h_T<h_1\le h_T \] なので， \[ h_1\approx h_T. \tag{3} \]

重要
\(h_1,h_2\) は単に「長い辺と短い辺」を昇順・降順に並べたものではない． 最長辺の反対側の頂点 \(p_1\) を基準にして選ばれる方向別辺長である．

2．方向ベクトル \(r_1,r_2\)

標準ラベル付けから \[ r_1 := \frac{p_2-p_1}{h_1}, \qquad r_2 := \frac{p_3-p_1}{h_2} \tag{4} \] を定めます． \(r_1,r_2\) は単位ベクトルです．

二つの方向のなす角を \(\theta\) とすると \[ s:=r_1\cdot r_2=\cos\theta. \tag{5} \] さらに \[ t:=\sin\theta>0 \tag{6} \] とします． 頂点順序が反転している場合には，後でrotation/reflectionを表す直交行列側に符号を持たせます． したがってstandard positionでは \(t>0\) としてよいです．

式 (5)，(6) から \[ s^2+t^2=1. \tag{7} \]

3．第一段階：reference triangleからstandard positionへ

reference triangleを \[ \widehat T = \operatorname{conv} \left\{ (0,0)^{\top}, (1,0)^{\top}, (0,1)^{\top} \right\} \tag{8} \] とします．

まず方向別scaleだけを \[ \boxed{ \widehat A = \operatorname{diag}(h_1,h_2) } \tag{9} \] に分離します． 次に \[ \boxed{ \widetilde A = \begin{pmatrix} 1&s\\ 0&t \end{pmatrix}, \qquad s^2+t^2=1,\quad t>0 } \tag{10} \] とします．

二つを掛けると \[ A_{\widetilde T} = \widetilde A\,\widehat A = \begin{pmatrix} h_1&s h_2\\ 0&t h_2 \end{pmatrix}. \tag{11} \] 従って中間三角形 \(\widetilde T\) の頂点は \[ \widetilde p_1=(0,0)^{\top}, \qquad \widetilde p_2=(h_1,0)^{\top}, \qquad \widetilde p_3=(s h_2,t h_2)^{\top}. \tag{12} \]

ここで \[ |\widetilde p_1-\widetilde p_2|=h_1, \qquad |\widetilde p_1-\widetilde p_3|=h_2. \] つまり，実三角形の二本の標準辺長をそのまま保持しています．

4．第二段階：standard positionから実三角形へ

中間三角形 \(\widetilde T\) は，実三角形 \(T\) と同じ長さ・角度を持ちますが， まだ原点付近の標準位置に置かれています． そこで \[ \Phi_T(\widetilde x) = A_T\widetilde x+b_T, \tag{13} \] \[ A_T\in O(2) \tag{14} \] とし，rotationまたはmirror imagingとtranslationだけで \(\widetilde T\) を \(T\) へ移します．

従って全写像は \[ \Phi = \Phi_T\circ\Phi_{\widetilde T}, \tag{15} \] \[ \Phi(\widehat x) = A_T \widetilde A \widehat A\widehat x +b_T. \tag{16} \] そのJacobianは \[ \boxed{ J_T = A_T\widetilde A\widehat A } \tag{17} \] です．

5．直接作ったJacobianと同じになる

標準ラベル付けされた実三角形について，通常のJacobianは \[ J_T^{\mathrm{direct}} = [p_2-p_1,\ p_3-p_1]. \tag{18} \] 一方， \[ p_2-p_1=h_1r_1, \qquad p_3-p_1=h_2r_2. \] \(r_2\) を \[ r_2=sr_1+tq_2 \tag{19} \] と分解し， \[ A_T=[r_1,q_2]\in O(2) \tag{20} \] とすれば \[ A_T\widetilde A\widehat A = [h_1r_1,\ h_2(sr_1+tq_2)] = [p_2-p_1,\ p_3-p_1]. \] 従って \[ \boxed{ J_T^{\mathrm{direct}} = A_T\widetilde A\widehat A. } \tag{21} \]

つまりtwo-step affine mappingは，別の有限要素写像を作っているわけではありません． 同じJacobianを，異方性解析に意味のある三つの因子へ分解しているのです．

6．三つの因子は何を表しているか

factormeaninganisotropic analysis
\(\widehat A=\operatorname{diag}(h_1,h_2)\)方向別の伸縮\(h_i\partial/\partial r_i\) を残す
\(\widetilde A\)角度・flatnessを含むshape deformationmaximum-angle / semi-regularityに関係
\(A_T\in O(2)\)rotation / reflectionEuclidean normを変えない

ここが異方性解析の核心です． 単一の \(J_T\) をそのまま見ると，方向別scaleと角度の悪化が混ざっています． 分解すると，どの部分が何を引き起こしているかが見えるようになります．

7．semi-regularityは \(t\) に直接現れる

中間三角形の面積は \[ |T| = \frac12 h_1h_2t. \tag{22} \] 筆者らの幾何パラメータ \[ H_T := \frac{h_1h_2}{|T|}\,h_T \tag{23} \] を使うと， \[ \boxed{ \frac{H_T}{h_T} = \frac{h_1h_2}{|T|} = \frac{2}{t}. } \tag{24} \]

最長辺 \(p_2p_3\) の対角である \(\theta\) は三角形の最大角なので， \[ t=\sin\theta_{\max}. \] 従って \[ \frac{H_T}{h_T} = \frac{2}{\sin\theta_{\max}}. \tag{25} \]

つまり，方向別長さ \(h_1,h_2\) が極端に異なっても， \(t\) が0へ近づかなければsemi-regularityは壊れません．

8．「細長い」と「悪い扁平化」は同じではない

ここで二つの三角形族を比較します．

8.1 良い異方性：細長い直角三角形

\[ T_\varepsilon^{\mathrm{good}} = \operatorname{conv} \{(0,0)^{\top},(1,0)^{\top},(0,\varepsilon)^{\top}\}, \qquad 0<\varepsilon\ll1. \tag{26} \] 標準ラベルでは \[ h_1=1,\qquad h_2=\varepsilon, \qquad s=0,\qquad t=1. \] 従って \[ \frac{H_T}{h_T}=2. \tag{27} \] 一方， \[ J_T= \begin{pmatrix} 1&0\\ 0&\varepsilon \end{pmatrix} \] なので \[ \kappa_2(J_T)=\varepsilon^{-1}. \tag{28} \]

\(\varepsilon\to0\) ではcondition numberは発散しますが， semi-regularity parameterは一定です． これは「強い異方性」ですが，maximum angleは悪化していません．

8.2 悪い扁平化：最大角が \(\pi\) へ近づく三角形

\[ T_\delta^{\mathrm{bad}} = \operatorname{conv} \{(0,\delta)^{\top},(-1,0)^{\top},(1,0)^{\top}\}, \qquad 0<\delta\ll1. \tag{29} \] このとき \[ h_1=h_2=\sqrt{1+\delta^2}, \] \[ s=\frac{\delta^2-1}{\delta^2+1}, \qquad t=\frac{2\delta}{1+\delta^2}. \tag{30} \] 従って \[ \frac{H_T}{h_T} = \frac{1+\delta^2}{\delta} \longrightarrow\infty. \tag{31} \] また \[ \kappa_2(J_T)=\delta^{-1}. \tag{32} \]

こちらは方向別scaleそのものより， \[ t\to0 \] というshape deformationの退化が本質です．

9．raw condition numberだけでは区別できない

前節の二つの例を並べると重要なことが分かります．

element parameter \(\kappa_2(J_T)\) \(H_T/h_T\)
good anisotropy\(\varepsilon=10^{-3}\)\(10^3\)2
bad flattening\(\delta=10^{-3}\)\(10^3\)\(1.000001\times10^3\)

どちらも \[ \kappa_2(J_T)\approx10^3 \] です． しかし一方はsemi-regularで，もう一方はmaximum-angle conditionを失い始めています．

重要な結論
\(\kappa_2(J_T)\) が大きいという事実だけでは， 「良い異方性」と「悪い扁平化」を区別できない．
two-step affine mappingは，その二つを \[ \widehat A \quad\text{と}\quad \widetilde A \] へ分離して見るための道具である．

10．standard positionをPythonで構成する

実際の三角形から，標準ラベル付けとJacobian分解を自動的に作ります． 

import numpy as np


def anisotropic_triangle_decomposition(P):
    P = np.asarray(P, dtype=float)

    # all three edges
    edges = [(0, 1), (1, 2), (2, 0)]
    lengths = np.array([
        np.linalg.norm(P[i] - P[j])
        for i, j in edges
    ])

    # p2-p3 is the longest edge
    m = np.argmax(lengths)
    i2, i3 = edges[m]

    # p1 is the remaining vertex
    i1 = list(
        {0, 1, 2} - {i2, i3}
    )[0]

    p1 = P[i1]
    q2 = P[i2]
    q3 = P[i3]

    d12 = np.linalg.norm(q2 - p1)
    d13 = np.linalg.norm(q3 - p1)

    # enforce h2 <= h1
    if d12 >= d13:
        p2, p3 = q2, q3
        h1, h2 = d12, d13
    else:
        p2, p3 = q3, q2
        h1, h2 = d13, d12

    hT = np.linalg.norm(p2 - p3)

    r1 = (p2 - p1) / h1
    r2 = (p3 - p1) / h2

    s = np.dot(r1, r2)

    qperp = r2 - s * r1
    t = np.linalg.norm(qperp)

    if t <= 1.0e-14:
        raise ValueError(
            "Degenerate or nearly degenerate triangle"
        )

    qperp /= t

    # rotation / reflection
    AT = np.column_stack((r1, qperp))

    # anisotropic scaling
    Ahat = np.diag([h1, h2])

    # remaining shape deformation
    Atilde = np.array([
        [1.0, s],
        [0.0, t]
    ])

    J_factorised = AT @ Atilde @ Ahat

    J_direct = np.column_stack((
        p2 - p1,
        p3 - p1
    ))

    area = (
        0.5
        * abs(np.linalg.det(J_direct))
    )

    H_over_h = h1 * h2 / area

    return {
        "p1": p1,
        "p2": p2,
        "p3": p3,
        "h1": h1,
        "h2": h2,
        "hT": hT,
        "r1": r1,
        "r2": r2,
        "s": s,
        "t": t,
        "AT": AT,
        "Ahat": Ahat,
        "Atilde": Atilde,
        "J_direct": J_direct,
        "J_factorised": J_factorised,
        "H_over_h": H_over_h,
        "cond_J": np.linalg.cond(J_direct)
    }

11．分解そのものを監査する

コードを実行したら， \[ J_T^{\mathrm{direct}} = A_T\widetilde A\widehat A \tag{33} \] が数値的に成立するかを必ず確認します． 

data = anisotropic_triangle_decomposition(P)

factorisation_error = np.linalg.norm(
    data["J_direct"]
    - data["J_factorised"],
    ord=np.inf
)

orthogonality_error = np.linalg.norm(
    data["AT"].T @ data["AT"]
    - np.eye(2),
    ord=np.inf
)

print(factorisation_error)
print(orthogonality_error)
print(data["H_over_h"])

浮動小数点誤差を除けば \[ A_T^{\top}A_T=I, \qquad J_T^{\mathrm{direct}} = A_T\widetilde A\widehat A \] となるはずです．

12．方向別微分が見える

この分解を行う理由は，単にJacobianをfactorisationしたいからではありません． 方向ベクトル \[ r_i \] と方向別長さ \[ h_i \] を誤差評価に残すためです．

例えば，semi-regularityの下でP1 Lagrange interpolationには \[ |u-I_Tu|_{H^1(T)} \le C \sum_{i=1}^{2} h_i \left\| \frac{\partial u}{\partial r_i} \right\|_{H^1(T)} \tag{34} \] という方向別の評価が得られます．

等方的な \[ h_T|u|_{H^2(T)} \] だけでは， 解がどの方向に急激に変化しているかという情報が消えます． 異方性meshでは，この方向情報を保持することが重要です．

13．assembly用Jacobianを書き換える必要はない

ここは実装上，非常に大切な点です． P1有限要素の局所剛性行列を計算するだけなら，第3回で使った 

J = np.column_stack((
    P[1] - P[0],
    P[2] - P[0]
))

で正しいです．

第6回で行っているのは， 有限要素法そのものを別の方法へ変更することではありません． 同じphysical Jacobianを， 異方性を解析・監査できる形に分解しています．

したがって実装は \[ \text{standard FEM assembly} \] と \[ \text{anisotropic geometry audit} \] を分離して持つのが安全です．

14．ChatGPTにJacobianを書かせるときの監査項目

Audit prompt
この三角形について，異方性解析用のstandard positionを構成してください．
(1) 最長辺を \(p_2p_3\) とする，
(2) \(h_1=|p_1-p_2|\)，\(h_2=|p_1-p_3|\)，\(h_2\le h_1\) とする，
(3) \(r_1,r_2\) を構成する，
(4) \(s=r_1\cdot r_2\)，\(t>0\)，\(s^2+t^2=1\) を確認する，
(5) \(\widehat A=\operatorname{diag}(h_1,h_2)\)，\(\widetilde A=\begin{pmatrix}1&s\\0&t\end{pmatrix}\) を作る，
(6) \(A_T\in O(2)\) を作る，
(7) \(J_T=A_T\widetilde A\widehat A\) がdirect Jacobianと一致することを数値的に確認する，
(8) \(H_T/h_T=2/t\) を計算する，
という順に数式とPythonを対応させてください．

15．第6回の結論

異方性三角形でも，standard P1 finite elementのJacobianは \[ [p_2-p_1,\ p_3-p_1] \] で正しく作れます． しかし，異方性を理解するにはその行列を \[ \boxed{ J_T = A_T \widetilde A \widehat A } \] へ分けることが重要です．

\[ \widehat A \] は方向別scale， \[ \widetilde A \] はangle/flatness， \[ A_T \] はrotation/reflectionを表します． この分離によって，

\[ \text{large aspect ratio} \neq \text{bad element} \]

であることが数学的に見えるようになります．

次回はこの構成を実際のP1有限要素計算へ入れ， 異方性P1要素は本当に正しく動くかを linear patch test，相対誤差，condition numberを使って調べます．
