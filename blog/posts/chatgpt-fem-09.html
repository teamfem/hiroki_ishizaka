第9回：3次元異方性四面体 — Type (i), Type (ii), sliver

ChatGPTで作る有限要素プログラム入門 第9回
29th August 2026

はじめに――3次元では「辺長の順番」だけでは足りない

第8回では，2次元三角形についてshape regularityとsemi-regularityを分け， 細長くてもmaximum-angle conditionを保つ要素と， 最大角が \(\pi\) へ近づく要素を区別しました．

3次元へ進むと事情はさらに複雑です． 四面体には六本の辺があり， 「短い三本を \(h_1,h_2,h_3\) とする」 という単純な規則では，異方的な三方向を正しく取り出せない場合があります． どの辺がどの頂点で接続しているかが重要だからです．

今回の中心
3次元異方性四面体では， \[ \text{edge lengths} + \text{connectivity} + \text{volume} \] を同時に見る．
Type (i) / Type (ii) は，方向別scaleを正しく取り出すためのstandard-position classificationである．

本記事は，既存の 「正則性と準正則性を角度を使わずに表す」 および 「三次元layer-adapted meshを四面体分割すると何が起こるか」 で整理した内容を，ChatGPT生成FEMコードの3D mesh auditとして再構成します．

1．standard positionでは最初に二本の辺を選ぶ

四面体 \(T\) の六本の辺のうち，まず最短辺を \[ e_2 \tag{1} \] とします． 次に，\(e_2\) に接続する辺の中で最長のものを \[ e_1 \tag{2} \] とします．

\(e_1\) の端点を \(P_1,P_2\) とし， \(e_2\) が \[ F_4=\triangle P_1P_2P_3 \] の辺となるように \(P_3\) を選びます． 残った頂点が \(P_4\) です．

3次元で重要な点
\[ h_1,h_2,h_3 \] は，六本の辺を単に短い順に並べた最初の三本ではない． 体積を生み出す三方向と接続構造を同時に記録するために選ばれる．

2．Type (i) / Type (ii) は何を区別しているか

\(e_1=P_1P_2\) の中点を通り，\(e_1\) に垂直な平面を考えます． この平面によって空間は二つの半空間に分かれます．

既存の標準分類では，

  • \(P_3,P_4\) が同じ半空間にある場合を Type (i)，
  • \(P_3,P_4\) が異なる半空間にある場合を Type (ii)

とします．

この分類は，四面体の見た目を二種類に分けたいから導入するのではありません． どの辺を第二の方向尺度として使うかがTypeによって変わるためです．

3．方向別辺長 \(\alpha_1,\alpha_2,\alpha_3\)

standard positionから \[ \alpha_1:=|P_1P_2|, \qquad \alpha_3:=|P_1P_4| \tag{3} \] とします．

さらに \[ \alpha_2 = \begin{cases} |P_1P_3|, & \text{Type (i)},\\[4pt] |P_2P_3|, & \text{Type (ii)}. \end{cases} \tag{4} \]

この三本を使って \[ \boxed{ H_T = \frac{\alpha_1\alpha_2\alpha_3}{|T|}\,h_T } \tag{5} \] とし， \[ \boxed{ \frac{H_T}{h_T} = \frac{\alpha_1\alpha_2\alpha_3}{|T|} } \tag{6} \] をsemi-regularityの指標とします．

2次元と同様， \[ \sup_h\max_{T\in\mathcal T_h}\frac{H_T}{h_T}<\infty \tag{7} \] が3次元のsemi-regular conditionです．

4．maximum-angle conditionは3次元では面角と二面角を見る

三角形ではmaximum angleは一つのface angleだけで済みました． 四面体では，

  • 四つの三角形面に含まれるすべての内角，
  • 六本の辺に対応するすべての二面角

を考えます．

3次元maximum-angle conditionは，これらがある \[ \gamma_{\max}<\pi \] 以下に一様に抑えられることです． 既存の幾何理論では， \[ \boxed{ \text{semi-regularity} \quad\Longleftrightarrow\quad \text{3D maximum-angle condition} } \tag{8} \] が成り立ちます．

したがって \(H_T/h_T\) は， 多数のface angleとdihedral angleを一つずつ測らずに 同じ退化を検出する代数的certificateとして使えます．

5．実装ではType分類を省略できるcertificateも便利

理論上の方向別補間評価ではType (i)/(ii)に基づく \[ \alpha_1,\alpha_2,\alpha_3 \] が重要です． 一方，大量のtetrahedral meshを自動監査するときは， より簡単な量も便利です．

六本の辺長を \[ \ell_1\le\ell_2\le\cdots\le\ell_6=h_T \tag{9} \] と並べ， \[ \boxed{ C_T := \frac{\ell_1\ell_2h_T}{|T|} } \tag{10} \] とします． これは既存記事で \(R_T/h_T\) と書いている無次元量です．

対応する長さ量 \(R_T\) と \(H_T\) は固定定数倍で同値であり， 従って \[ C_T \asymp \frac{H_T}{h_T}. \tag{11} \] 特に， \[ C_T \] のmesh-uniform boundednessとsemi-regularityは同値です．

実装上の使い分け
Type (i)/(ii) standard position：方向別誤差評価・two-step mappingに使う．
\(C_T\)：mesh file全体からsliverやmaximum-angle degenerationを高速にscreeningする．

6．良い3次元異方性：Kuhn型四面体

辺長 \[ 0<a\le b\le c \] の直方体 \[ K=[0,a]\times[0,b]\times[0,c] \tag{12} \] を考えます． Kuhn型6四面体分割の一つは \[ T = \operatorname{conv} \left\{ (0,0,0)^{\top}, (a,0,0)^{\top}, (a,b,0)^{\top}, (a,b,c)^{\top} \right\}. \tag{13} \]

この四面体の体積は \[ |T| = \frac{abc}{6}, \tag{14} \] 直径は \[ h_T = \sqrt{a^2+b^2+c^2}. \tag{15} \] また二本の最短辺は \(a,b\) なので， \[ C_T = \frac{ab\sqrt{a^2+b^2+c^2}}{abc/6} = 6\frac{\sqrt{a^2+b^2+c^2}}{c}. \tag{16} \]

\(a\le b\le c\) から \[ 1 \le \frac{\sqrt{a^2+b^2+c^2}}{c} \le \sqrt3, \] 従って \[ \boxed{ 6\le C_T\le6\sqrt3. } \tag{17} \]

つまり \[ a:c\to0 \] のように極端な異方性を持っても， このKuhn型tetrahedronはsemi-regularityを失いません．

7．shape regularityは失ってもsemi-regularityは残る

3次元shape regularityの指標を \[ Q_T = \frac{h_T^3}{|T|} \tag{18} \] とすると，Kuhn型tetrahedronでは \[ Q_T = 6 \frac{(a^2+b^2+c^2)^{3/2}}{abc}. \tag{19} \]

例えばface layer型に \[ a=\varepsilon h, \qquad b\asymp c\asymp h \] とすると \[ Q_T\asymp\varepsilon^{-1} \to\infty. \tag{20} \] しかし \(C_T\) は式 (17) で一様有界です．

従って2次元と同じく，

\[ \boxed{ \text{strong anisotropy} \neq \text{maximum-angle degeneration}. } \tag{21} \]

8．sliver tetrahedronは辺長比だけでは見えない

3次元特有の厄介な要素としてsliverがあります． 次のfamilyを考えます． \[ S_\eta = \operatorname{conv} \left\{ (0,0,0)^{\top}, (1,0,0)^{\top}, (0,1,0)^{\top}, \left(\frac12,\frac12,\eta\right)^{\top} \right\}, \qquad 0<\eta\le\frac12. \tag{22} \]

体積は \[ |S_\eta| = \frac{\eta}{6}, \tag{23} \] 直径は \[ h_{S_\eta}=\sqrt2. \tag{24} \] 一方，二本の最短辺は \[ \ell_1=\ell_2 = \sqrt{\frac12+\eta^2}. \tag{25} \] 従って \[ Q_{S_\eta} = \frac{12\sqrt2}{\eta} \to\infty, \tag{26} \] さらに \[ \boxed{ C_{S_\eta} = \frac{6\sqrt2\left(\frac12+\eta^2\right)}{\eta} \to\infty. } \tag{27} \]

ところが辺長はすべて \(O(1)\) です． 最大辺長／最小辺長の比も \[ \frac{h_{S_\eta}}{\ell_1} \longrightarrow2 \tag{28} \] にしかなりません．

sliverの本質
辺が極端に短いのではなく， 四点がほぼ同一平面上に並び，体積だけが潰れる．
したがってedge aspect ratioだけでは検出できない．

10．Jacobian determinantだけでは不十分

四面体のstandard FEM implementationでは \[ J_T = [p_1-p_0,\ p_2-p_0,\ p_3-p_0] \] を作り， \[ |T|=\frac{|\det J_T|}{6} \] を計算します．

もちろん \[ \det J_T=0 \] なら退化要素です． しかし， \[ |\det J_T|>0 \] であることだけではmesh familyとして十分ではありません． sliverでは各levelでdeterminantは非零でも， refinement parameterとともにrelative volumeが急速に小さくなります．

したがって3D mesh auditでは，

\[ |\det J_T|, \qquad Q_T, \qquad C_T, \qquad \kappa_2(J_T) \]

を別々に見るべきです．

11．実装向けtetrahedron geometry certificate

Type (i)/(ii)の完全なstandard-position labellingは方向別補間解析に必要です． 一方，mesh全体のscreeningには \(C_T\) を先に使うと実装が簡潔です． 

import numpy as np
from itertools import combinations


def tetra_geometry_certificate(P):
    P = np.asarray(P, dtype=float)

    edges = list(combinations(range(4), 2))

    lengths = np.array([
        np.linalg.norm(P[i] - P[j])
        for i, j in edges
    ])

    hT = np.max(lengths)

    J = np.column_stack((
        P[1] - P[0],
        P[2] - P[0],
        P[3] - P[0]
    ))

    detJ = np.linalg.det(J)
    volume = abs(detJ) / 6.0

    if volume <= 0.0:
        raise ValueError("Degenerate tetrahedron")

    ell = np.sort(lengths)
    ell1 = ell[0]
    ell2 = ell[1]

    QT = hT**3 / volume

    Csemi = (
        ell1 * ell2 * hT
        / volume
    )

    return {
        "volume": volume,
        "hT": hT,
        "min_edge": ell1,
        "second_min_edge": ell2,
        "max_edge": hT,
        "edge_ratio": hT / ell1,
        "Q_T": QT,
        "semi_certificate": Csemi,
        "cond_J": np.linalg.cond(J),
        "detJ": detJ
    }

12．Type (i)/(ii)の分類はgeometry moduleに分離する

P1 stiffness assembly自体は第5回の 

J = np.column_stack((
    P[1] - P[0],
    P[2] - P[0],
    P[3] - P[0]
))

で正しく行えます． Type (i)/(ii)分類は，assemblyを変えるためではなく， 異方性解析用の方向尺度を抽出するために使います．

実装では，

\[ \texttt{fem\_assembly} \quad\text{and}\quad \texttt{anisotropic\_geometry} \]

を別moduleにしておく方が安全です．

注意
Type (i)/(ii)のstandard labellingにはtie処理も含めた一定の規則が必要です． production codeでは「短い三本の辺を選ぶ」といった簡略化で代用せず， 理論で用いる頂点ラベル規約と一致させる必要があります．

14．ChatGPTへの3D mesh audit prompt

Audit prompt
このtetrahedral meshを異方性P1有限要素解析の観点から監査してください．
(1) 各四面体の六本の辺長を計算する，
(2) \(h_T\)，体積，\(Q_T=h_T^3/|T|\) を計算する，
(3) 二本の最短辺から \(C_T=\ell_1\ell_2h_T/|T|\) を計算する，
(4) edge ratioだけでsliver判定をしない，
(5) Type (i)/(ii)が必要な場合は，最短辺とその接続辺からstandard positionを構成し， 理論の頂点ラベル規約に従って \(\alpha_1,\alpha_2,\alpha_3\) を決める，
(6) \(H_T/h_T\) と3D maximum-angle conditionの関係を確認する，
(7) FEM assembly用Jacobianとanisotropic-geometry classificationを混同しない，
という順で診断してください．

15．第9回の結論

3次元異方性では，

\[ \boxed{ \text{edge length information alone is not enough} } \]

です．

Type (i)/(ii)は，四面体の辺の接続関係を使って 異方的な方向尺度を正しく取り出すための分類です． 一方，mesh fileを大量に検査するときには \[ C_T = \frac{\ell_1\ell_2h_T}{|T|} \] が簡潔なsemi-regularity certificateになります．

Kuhn型四面体ではaspect ratioが発散してもこのcertificateは一様有界です． 対してsliverでは，辺長がすべて同程度でも体積だけが潰れ， \[ Q_T\to\infty, \qquad C_T\to\infty. \]

3D anisotropic FEMの監査原則
「短い辺があるか」ではなく， 方向尺度・接続関係・体積が整合しているかを調べる．

これで第6回から第9回までの異方性編が一度まとまりました． 次回は， ChatGPTが書いたFEMコードをどうデバッグするか を，1次元・2次元・3次元・異方性で得た監査項目を統合して扱います．
