代表的なlayer-adapted meshの幾何条件を比較する

異方性有限要素法の幾何学的基礎 第10回
1st August 2026 New

はじめに

第7回から第9回では，Shishkin mesh，Bakhvalov系mesh， Bakhvalov–Shishkin mesh，S-type meshを個別に調べました． 今回は，これらを一つの表にまとめます．

ただし，layer-adapted meshには多数の変種があり， 「Bakhvalov mesh」や「Bakhvalov-type mesh」という名称も文献によって 生成関数や接続方法が少し異なります．したがって本記事の表は， 第7回から第9回で採用した代表的構成を比較するものであり， 同じ名称を持つすべての変種を一つの公式で定義するものではありません [3]–[7]．

比較の核心は，layer-adapted meshには少なくとも次の三つの尺度があることです．

  1. 層を解像する尺度：遷移点，最小幅，生成関数，
  2. 要素形状の尺度： \(Q_T=h_T^2/|T|_2\) と \(H_T/h_T\)，
  3. 誤差解析の尺度：mesh-characterizing functionや対数因子．

これらは相互に関係しますが，同じ条件ではありません．

今回の結論
  • 境界層を解像するための強い異方性は，parameter-uniformなshape regularityと両立しないことがあります．
  • しかし，長方形セルを対角線で二分する標準構成では，すべての代表的layer-adapted meshで \(H_T/h_T=2\) です．
  • したがって，これらは層パラメータに一様には「準正則だが非正則」となる典型例です．
  • ShishkinとBakhvalov–Shishkinの精度差は，\(H_T/h_T\)ではなく生成関数とmesh factorに現れます．
  • 「最適なmesh」は一つではなく，実装の簡潔さ，局所幅の滑らかさ，対数因子，解析目的によって変わります．

1．比較の共通設定

単位正方形 \(\Omega=(0,1)^2\) を考え，\(x\) 方向に境界層があるとします． \(x\) 方向にはlayer-adaptedな格子点 \[ 0=x_0\lt x_1\lt\cdots\lt x_N=1 \] を置き，\(y\) 方向は \[ y_j=\frac{j}{N}, \qquad 0\le j\le N \] と一様に分割します．長方形セル \[ R_{ij} =[x_i,x_{i+1}]\times[y_j,y_{j+1}] \] の辺長を \[ h_{x,i}=x_{i+1}-x_i, \qquad h_y=\frac1N \] とします．各長方形をいずれかの対角線で二つの直角三角形に分割します．

局所的な異方性比を \[ r_i:=\frac{h_{x,i}}{h_y}=N h_{x,i} \] と置きます．第6回の計算により，各三角形で \[ \boxed{ Q_T=2\left(r_i+\frac1{r_i}\right) } \] および \[ \boxed{ \frac{H_T}{h_T}=2 } \] が成り立ちます．

比較を一変数へ還元できる

この構成では，すべてのmeshの幾何学的な違いは \(r_i=N h_{x,i}\) の分布へ集約されます． \(r_i\) が0または無限大へ近づけば \(Q_T\) は発散しますが， \(H_T/h_T\) は常に2です．

2．layer-adapted meshに共通する非正則性

指数境界層を解像するため，境界に最も近い要素幅が \[ h_{x,\min}\lesssim\frac{\varepsilon}{N} \] となるmeshを考えます．横方向は \(h_y=1/N\) なので，対応する三角形では \[ r_{\min} =\frac{h_{x,\min}}{h_y} \lesssim\varepsilon. \] したがって \[ Q_T =2\left(r_{\min}+\frac1{r_{\min}}\right) \gtrsim\frac1\varepsilon. \] よって \[ \sup_{0\lt\varepsilon\le1} \max_{T\in\mathcal T_{N,\varepsilon}}Q_T =\infty \] となり，\(\varepsilon\to0\) に一様なshape regularityは成立しません．

一方，直角三角形分割では \[ \frac{H_T}{h_T}=2 \] がすべての \(N\)，\(\varepsilon\)，局所幅に対して成立します．したがって， この構成で得られる代表的layer-adapted meshは

\[ \boxed{ \text{層パラメータに一様には準正則だが非正則} } \]

です．これはmeshの欠陥ではありません．むしろ，薄い層を少ない自由度で解像するために 意図的に導入した異方性が，\(Q_T\) の発散として表れています．

一次元のlayer方向では細幅と粗幅の比が発散しても，二次元三角形の直径は 横方向の \(1/N\) に支配され，互いに比較可能な場合があります．したがって， 「格子点列のquasi-uniformity」と「二次元単体の直径に基づくsize-quasi-uniformity」を 区別しなければなりません．

5．誤差解析上の比較

S-type meshでは，層領域のmesh-generating function \(\varphi\) に対して \[ \psi=e^{-\varphi} \] をmesh-characterizing functionと呼びます．多くのparameter-uniform誤差評価では， meshに由来する量として \[ N^{-1}\max|\psi'| \] が現れます [4]，[7]．

mesh 代表的なmesh factor 誤差解析上の典型的特徴 注意
Shishkin \(\max|\psi'|=O(\ln N)\) 評価に \(\ln N\) 因子が現れやすい 簡潔さと頑健性が大きな利点
Bakhvalov–Shishkin 代表例では \(\max|\psi'|=O(1)\) optimal S-type meshとして対数的mesh factorを避けられる 最終的な誤差率は問題・要素・ノルムに依存
一般のS-type \(\max|\psi'|\) による 生成関数の性質を一つの枠組みで比較できる optimal S-type性とshape regularityは別条件
Bakhvalov系 S-typeの量で直接記述しない場合がある 層に適合した滑らかなgradingにより最適評価が得られる場合がある 名称だけでは具体的な誤差評価を決められない

重要なのは，\(H_T/h_T=2\) がすべてのmeshで同じでも， \(\max|\psi'|\) は異なることです．したがって \[ \boxed{ \text{semi-regularityは共通でも，layer resolutionの効率は同じではない} } \] となります．

6．遷移点の係数 \(\sigma\) は比較表の外に置けない

ShishkinおよびS-type meshの遷移点は，典型的には \[ \lambda =\min\left\{ \frac12, \frac{\sigma\varepsilon}{\beta}\ln N \right\} \] です．ここで \(\sigma\) は飾りではありません． 多項式次数を \(k\) とすると，代表的な解析では \[ \sigma\ge k+1 \] のような条件が用いられ，一次要素なら \(\sigma=2\) が自然な選択の一つです．

\(\sigma\) を大きくすれば層領域は広がり，層外へ残る指数成分は小さくなります． 一方，層領域へ配分する要素数が同じなら局所幅は大きくなり， アスペクト比，接続部，計算量の配分も変わります．したがってmeshを比較するときは，

  • 同じ \(N\) だけでなく，同じ \(\sigma\)，\(k\)，\(\beta\) を使っているか，
  • 遷移点が \(1/2\) で飽和する場合をどう処理しているか，
  • \(\varepsilon\) と \(N\) に追加関係を仮定しているか，

を確認する必要があります．

比較表にmesh名だけを書いても不十分

同じ「Shishkin mesh」でも，遷移点の係数，層の位置，両端層か片側層か， 各部分への要素数配分によって具体的な局所幅は変わります．

7．目的別にどのmeshを選ぶか

主な目的 有力な選択 理由
まず頑健なlayer-adapted計算を実装する Shishkin 格子点生成が簡潔で，理論と実装を照合しやすい
層領域内の幅を滑らかに変化させる Bakhvalov系 指数層の減衰に合わせて自由度を配分できる
S-type解析で対数的mesh factorを避ける Bakhvalov–Shishkinなどのoptimal S-type \(\max|\psi'|\) を一様有界にできる代表例がある
複数の生成関数を統一的に解析する 一般のS-type枠組み meshの違いを \(\varphi\) と \(\psi\) の条件へ還元できる
筆者の異方性補間・semi-regularity理論へ接続する いずれも候補 標準的な直角三角形分割なら \(H_T/h_T=2\)

したがって，Bakhvalov–Shishkin meshが常にShishkin meshより優れている， という単純な序列ではありません．実装の透明性，係数行列，誤差ノルム， 高次要素，非線形問題，時間依存問題などを含めて選ぶ必要があります．

8．幾何条件から引き継げること

この比較から，筆者の異方性有限要素解析へ直接引き継げる情報は， 少なくとも次の通りです [1]，[2]．

  • 直角三角形分割ではsemi-regularity定数が層パラメータに依存しないこと，
  • shape-regularity定数に依存する古典評価は \(\varepsilon\to0\) で劣化し得ること，
  • 方向別の辺長を保持した異方性補間評価が自然であること，
  • mesh名ではなく，要素ごとの \(h_{x,i}\)，\(h_y\)，向きが解析入力になること．

一方，次の性質は \(Q_T\) と \(H_T/h_T\) だけでは決まりません．

  • parameter-uniformな誤差次数，
  • \(\ln N\) 因子の有無，
  • DMPやM-matrix性，
  • maximum-norm評価，
  • condition numberと反復法の性能，
  • 遷移点付近の数値振動．

したがって，layer-adapted meshの解析には \[ \boxed{ \text{要素幾何} + \text{生成関数} + \text{離散作用素の構造} } \] が必要です．

9．比較結果の要約

mesh 実装 grading mesh factor parameter-uniform shape regular 直角三角形分割のsemi-regularity

まとめ

Shishkin，Bakhvalov系，Bakhvalov–Shishkin，S-type meshは， 層領域への自由度配分という点では異なります．しかし，一方向をlayer-adaptedに分割し， 他方向を一様分割した長方形を直角三角形へ分けると，すべての要素で \[ \frac{H_T}{h_T}=2 \] となります．

境界付近に \(O(\varepsilon/N)\) の幅を置けば，横方向幅 \(1/N\) との比から \[ Q_T\gtrsim\frac1\varepsilon \] となります．したがって，層パラメータに一様には非正則ですが準正則です． この共通の幾何学的分類だけでは，mesh間の精度差は説明できません． Shishkinの対数因子やBakhvalov–Shishkinのoptimal S-type性を理解するには， 生成関数とmesh-characterizing functionが必要です．

次回は，この二次元の結論が三次元でも自動的に保たれるのかを検討します． 直方体型のlayer-adapted cellを四面体分割すると，分割パターン，頂点の並べ方， sliver型退化によって \(H_T/h_T\) が変わり得ます．
