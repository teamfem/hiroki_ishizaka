第16回：mixed Poisson問題を解く — RT0–P0と局所保存

ChatGPTで作る有限要素プログラム入門 Season 2 第4回（通算第16回）
29th August 2026

はじめに――今度はfluxを未知量として解く

Season 1のPoisson FEMではscalar solution \(u_h\) を直接求め， そのgradientを後から計算しました． 第14回ではRT0 interpolationを， 第15回ではCR–RTの離散部分積分を扱いました．

今回はRaviart–Thomas spaceを本当にtrial spaceとして使います． Poisson equationをfirst-order systemへ分解し，

\[ \boxed{ \text{flux-like variable} + \text{scalar variable} } \]

を同時に求めます．

この方法の大きな特徴は， elementごとのbalance lawがdiscrete equationそのものに組み込まれることです．

1．符号規約を最初に固定する

Poisson problem \[ -\Delta u=f \qquad\text{in }\Omega, \tag{1} \] \[ u=0 \qquad\text{on }\partial\Omega \tag{2} \] を考えます．

ここでは博士論文と同じく \[ \boxed{ \boldsymbol\sigma=\nabla u } \tag{3} \] と置きます． 従って \[ \boxed{ \boldsymbol\sigma-\nabla u=0, \qquad \nabla\cdot\boldsymbol\sigma=-f. } \tag{4} \]

物理的なdiffusive fluxを \[ -\nabla u \] と定義する流儀とは符号が逆です． 以下では式 (3) の規約を最後まで固定します．

2．dual mixed formulation

\[ V:=H(\operatorname{div};\Omega), \qquad Q:=L^2(\Omega) \] とします． 式 (3) を \(\boldsymbol v\in V\) でtestし，gradient termを部分積分すると， \(u=0\) on \(\partial\Omega\) から \[ (\boldsymbol\sigma,\boldsymbol v) + (u,\nabla\cdot\boldsymbol v) = 0. \tag{5} \]

従ってmixed problemは \[ \boxed{ (\boldsymbol\sigma,\boldsymbol v) + (\nabla\cdot\boldsymbol v,u) = 0 \qquad \forall\boldsymbol v\in V, } \tag{6} \] \[ \boxed{ (\nabla\cdot\boldsymbol\sigma,q) = -(f,q) \qquad \forall q\in Q. } \tag{7} \]

ここで \[ a(\boldsymbol\sigma,\boldsymbol v) = (\boldsymbol\sigma,\boldsymbol v), \qquad b(\boldsymbol v,q) = (\nabla\cdot\boldsymbol v,q). \tag{8} \]

3．Dirichlet条件をedge DoFへ直接課してはいけない

これは実装で非常に重要です． mixed formulationでは \[ u\in L^2(\Omega) \] なので，\(u_h\) はboundary traceを持つconforming \(H^1\) functionではありません．

homogeneous Dirichlet conditionは式 (5) を導く部分積分の中へ入っています． 従って

RT0–P0 mixed Poissonでしてはいけないこと
boundary RT flux DoFを0に固定しない．
boundary cellのP0 unknownを0に固定しない．

boundary normal fluxはsolutionの一部として未知です． ここをP1 PoissonのDirichlet eliminationと混同すると， 別のboundary-value problemを解くことになります．

4．RT0–P0離散空間

lowest-order pairを \[ V_h:=V_h^{RT0}\subset H(\operatorname{div};\Omega), \qquad Q_h:=P_0(\mathcal T_h)\subset L^2(\Omega) \tag{9} \] とします．

求めるのは \[ (\boldsymbol\sigma_h,u_h) \in V_h\times Q_h \] で， \[ \boxed{ (\boldsymbol\sigma_h,\boldsymbol v_h) + (\nabla\cdot\boldsymbol v_h,u_h) = 0 \qquad \forall\boldsymbol v_h\in V_h, } \tag{10} \] \[ \boxed{ (\nabla\cdot\boldsymbol\sigma_h,q_h) = -(f,q_h) \qquad \forall q_h\in Q_h. } \tag{11} \]

これは \[ V_h\times Q_h \subset H(\operatorname{div};\Omega)\times L^2(\Omega) \] なのでconforming mixed methodです．

5．unknownはglobal edge fluxとcell value

RT0のglobal DoFを \[ \Sigma_E = \int_E \boldsymbol\sigma_h\cdot\boldsymbol n_E\,ds \tag{12} \] とします．

P0 unknownは各triangle \(T\) 上のconstant \[ u_h|_T=U_T \tag{13} \] です．

従ってunknown vectorは \[ \boxed{ \mathbf x = \begin{pmatrix} \boldsymbol\Sigma\\ \boldsymbol U \end{pmatrix} } \tag{14} \] であり， 前半はglobal edges，後半はelementsに対応します．

6．block saddle-point system

global RT basisを \(\{\boldsymbol\phi_E\}\)， cell characteristic basisを \(\{\chi_T\}\) とします．

mass matrixとdivergence matrixを \[ M_{EE'} = (\boldsymbol\phi_{E'},\boldsymbol\phi_E), \tag{15} \] \[ B_{TE} = (\nabla\cdot\boldsymbol\phi_E,\chi_T) = \int_T\nabla\cdot\boldsymbol\phi_E\,dx \tag{16} \] と置けば， \[ \boxed{ \begin{pmatrix} M&B^{\top}\\ B&0 \end{pmatrix} \begin{pmatrix} \boldsymbol\Sigma\\ \boldsymbol U \end{pmatrix} = \begin{pmatrix} 0\\ -\boldsymbol F \end{pmatrix}, } \tag{17} \] ただし \[ F_T=\int_Tf\,dx. \tag{18} \]

matrixはsymmetricですがpositive definiteではなく， symmetric indefinite saddle-point matrixです．

7．RT0–P0では \(B\) がsigned incidence matrixになる

第14回でlocal RT basis \(\boldsymbol\theta_{T,i}\) を outward normal fluxが1になるように取りました． すると \[ \int_T \nabla\cdot\boldsymbol\theta_{T,i}\,dx = 1. \tag{19} \]

global edge normalとlocal outward normalのsignを \[ s_{T,E}\in\{-1,+1\} \] とすれば \[ \boxed{ B_{TE} = \begin{cases} s_{T,E},&E\subset\partial T,\\ 0,&\text{otherwise}. \end{cases} } \tag{20} \]

つまり \(B\) は幾何的なlengthを含むmatrixではなく， cell–edge connectivityとorientationを記録したsigned incidence matrixになります．

geometryは主にRT mass matrix \(M\) に入ります．

8．局所保存は第二式をcellごとに読むだけ

式 (11) で \[ q_h=\chi_T \] を選ぶと \[ \int_T \nabla\cdot\boldsymbol\sigma_h\,dx = -\int_Tf\,dx. \tag{21} \] Gaussの公式から \[ \boxed{ \int_{\partial T} \boldsymbol\sigma_h\cdot\boldsymbol n_T\,ds = -\int_Tf\,dx. } \tag{22} \]

これがmixed RT methodのelementwise local conservationです．

local conservationはpost-processingではない
solutionを得た後にfluxを調整して保存させるのではなく， discrete equationそのものが各cellのbalance lawになっている．

9．quadratureを使う場合の「exact conservation」

今回のsource \[ f(x,y) = 2\pi^2\sin(\pi x)\sin(\pi y) \tag{23} \] は多項式ではないので， finite-order Gauss quadratureで \[ F_T=\int_Tf\,dx \] を数学的にexactには積分できません．

実装でquadrature値を \(F_T^Q\) とすれば，linear systemは \[ \boxed{ \int_{\partial T} \boldsymbol\sigma_h\cdot\boldsymbol n_T\,ds = -F_T^Q } \tag{24} \] をsolver toleranceまでexactに満たします．

従って「局所保存がexact」というときは， assembled discrete loadに対してexactであることを明確にします． exact source integralとの違いはquadrature errorです．

10．assemblyの中心コード

from scipy.sparse import (
    bmat,
    csr_matrix,
    lil_matrix
)
from scipy.sparse.linalg import spsolve


M = lil_matrix(
    (n_edges, n_edges),
    dtype=float
)

B = lil_matrix(
    (n_cells, n_edges),
    dtype=float
)

F = np.zeros(n_cells)


for t, tri in enumerate(triangles):
    P = nodes[tri]

    J = np.column_stack((
        P[1] - P[0],
        P[2] - P[0]
    ))

    detJ = np.linalg.det(J)

    if detJ <= 0.0:
        raise ValueError(
            "Use positive triangle orientation"
        )

    area = 0.5 * detJ

    Mloc = np.zeros((3, 3))
    Floc = 0.0

    for xi, eta, w in quad:
        x = (
            P[0]
            + J @ np.array([xi, eta])
        )

        theta = np.array([
            (x - P[i]) / detJ
            for i in range(3)
        ])

        Mloc += (
            w * detJ
            * (theta @ theta.T)
        )

        Floc += (
            w * detJ
            * source(*x)
        )

    F[t] = Floc

    for i in range(3):
        ei = element_edges[t, i]
        si = element_signs[t, i]

        B[t, ei] += si

        for j in range(3):
            ej = element_edges[t, j]
            sj = element_signs[t, j]

            M[ei, ej] += (
                si * sj * Mloc[i, j]
            )


Z = csr_matrix(
    (n_cells, n_cells)
)

A = bmat(
    [
        [M.tocsr(), B.T.tocsr()],
        [B.tocsr(), Z]
    ],
    format="csr"
)

rhs = np.concatenate([
    np.zeros(n_edges),
    -F
])

solution = spsolve(A, rhs)

sigma_dof = solution[:n_edges]
u_cell = solution[n_edges:]

11．mass assemblyにもorientation signが二回入る

global RT basisのelement restrictionは \[ \boldsymbol\phi_E|_T = s_{T,E}\boldsymbol\theta_{T,E}. \tag{25} \]

従ってmass termでは \[ (\boldsymbol\phi_E,\boldsymbol\phi_{E'})_T = s_{T,E}s_{T,E'} (\boldsymbol\theta_{T,E},\boldsymbol\theta_{T,E'})_T. \tag{26} \]

\(B\) にsignを入れて，\(M\) では忘れるというbugもあり得ます． 第14回のorientation mapは全RT basis evaluationに適用しなければなりません．

12．discrete inf-supは「matrixが解けた」より強い

mixed methodのwell-posednessには， kernel上のcoercivityに加えて \[ \boxed{ \inf_{0\neq q_h\in Q_h} \sup_{0\neq\boldsymbol v_h\in V_h} \frac{ (\nabla\cdot\boldsymbol v_h,q_h) }{ \|\boldsymbol v_h\|_{H(\operatorname{div})} \|q_h\|_{L^2} } \ge \beta_h } \tag{27} \] が必要です．

重要なのは \[ \beta_h \] がmesh refinementで0へ落ちないことです． 一つの有限meshでsaddle matrixがnonsingularだっただけでは， uniform stabilityを証明したことにはなりません．

13．RT interpolationの注意がinf-sup proofにも現れる

博士論文のdiscrete inf-sup proofでは， \(q_h\in Q_h\) に対して \[ \nabla\cdot\boldsymbol v=q_h \] を満たす \[ \boldsymbol v\in H^1(\Omega)^d \] をまず構成し， その後 \[ I_h^{RT}\boldsymbol v \] を使います．

これは第14回の注意と完全に整合しています．

Fortin operatorとしてのRT interpolation
standard RT interpolationを \[ H(\operatorname{div};\Omega) \] 全体へ無条件に拡張したことにはしない．
proofでは\(H^1\)-regularなright inverse of divergence上でRT interpolationを使う．

さらにanisotropic meshでは， \(I_h^{RT}\) のstability constantをgeometryに一様に制御できるかが discrete inf-sup constantに関係します．

14．semi-regular meshでのstabilityとの関係

uniform shape-regular meshならstandard RT theoryを使えます． 一方，強いanisotropyを許す場合， 単に \[ \nabla\cdot RT_0=P_0 \] という代数的surjectivityだけでは十分ではありません．

博士論文 Chapter 12 ではsemi-regularity condition \[ \frac{H_T}{h_T}\le\gamma \tag{28} \] と \(h\le1\) の下でRT interpolation stabilityを使い， mesh-independentなdiscrete inf-sup boundを導いています．

したがってanisotropic mixed FEMでは，

\[ \boxed{ \text{commuting} + \text{RT stability} + \text{mesh geometry} } \]

を一組として監査する必要があります．

15．Galerkin orthogonalityとflux error

continuous / discrete equationsを引くと \[ (\boldsymbol\sigma-\boldsymbol\sigma_h,\boldsymbol v_h) + (\nabla\cdot\boldsymbol v_h,u-u_h) = 0 \tag{29} \] および \[ (\nabla\cdot( \boldsymbol\sigma-\boldsymbol\sigma_h),q_h) = 0. \tag{30} \]

十分なregularityの下ではRT commuting propertyを使って \[ \nabla\cdot( I_h^{RT}\boldsymbol\sigma-\boldsymbol\sigma_h) = 0 \] となるため， \[ \boxed{ \|\boldsymbol\sigma-\boldsymbol\sigma_h\|_{L^2} \le \|\boldsymbol\sigma-I_h^{RT}\boldsymbol\sigma\|_{L^2}. } \tag{31} \]

mixed RT flux errorがRT interpolation errorに直接支配される， 非常にきれいなbest-approximation型評価です．

16．scalar errorにはinf-sup stabilityが入る

\(L^2\)-projectionを \(\Pi_h^0\) とすると， discrete inf-sup conditionから \[ \boxed{ \|u-u_h\|_{L^2} \le \|u-\Pi_h^0u\|_{L^2} + \beta_h^{-1} \|\boldsymbol\sigma-\boldsymbol\sigma_h\|_{L^2}. } \tag{32} \]

つまりscalar approximationは

\[ \text{\(P_0\) projection error} + \text{flux error / inf-sup stability} \]

で制御されます．

第13回のCRでは \[ \text{interpolation} + \text{consistency} \] でしたが， conforming mixed methodでは別のerror structureになります．

17．manufactured solutionで実装を検証する

今回も \[ u(x,y) = \sin(\pi x)\sin(\pi y) \tag{33} \] を使います．

符号規約 \(\boldsymbol\sigma=\nabla u\) なので \[ \boldsymbol\sigma(x,y) = \begin{pmatrix} \pi\cos(\pi x)\sin(\pi y)\\ \pi\sin(\pi x)\cos(\pi y) \end{pmatrix}, \tag{34} \] \[ f(x,y) = 2\pi^2\sin(\pi x)\sin(\pi y). \tag{35} \]

unit squareのuniform triangulationを使い， RT mass matrixはdegree-2 polynomialをexactに積分できるquadratureで， source loadは7点triangle quadratureで評価しました． error integralにはさらに高次のquadratureを使っています．

20．solver residualとconservation residualは同じではない

global saddle-point residual \[ \left\| A\mathbf x-\mathbf b \right\| \] が小さいことは必要です． しかしlocal conservationを監査したいなら， 第二blockだけを取り出した \[ \boxed{ B\boldsymbol\Sigma+\boldsymbol F } \] も別に出力した方がよいです．

こうすると，

\[ \text{linear solver} \quad\text{と}\quad \text{physical cell balance} \]

を別々のtestとして読むことができます．

21．divergence errorには特別な構造がある

exact load integrationなら式 (11) から \[ \nabla\cdot\boldsymbol\sigma_h = -\Pi_h^0f. \tag{38} \] 一方 \[ \nabla\cdot\boldsymbol\sigma=-f. \] 従って \[ \boxed{ \nabla\cdot( \boldsymbol\sigma-\boldsymbol\sigma_h) = -(f-\Pi_h^0f). } \tag{39} \]

つまりRT0 mixed solutionのdivergence errorは， このPoisson settingではsourceのP0 projection errorそのものです．

quadratureを使った場合は， \(\Pi_h^0f\) をquadratureで定義されたcell averageに置き換えて読む必要があります．

23．ChatGPTへのmixed Poisson audit prompt

Audit prompt
このRT0–P0 mixed Poisson codeを数学的に監査してください．
(1) 符号規約が \(\boldsymbol\sigma=\nabla u\)，\(\operatorname{div}\boldsymbol\sigma=-f\) で一貫しているか，
(2) discrete spacesが \(RT_0\subset H(\operatorname{div})\) とcellwise \(P_0\) か，
(3) Dirichlet \(u=0\) をboundary RT fluxへ誤ってstrongly imposedしていないか，
(4) global RT orientation signがmass matrixとdivergence matrixの両方に入っているか，
(5) block systemが \(\begin{psmallmatrix}M&B^\top\\B&0\end{psmallmatrix}\) か，
(6) \(B_{TE}=s_{T,E}\) というRT0–P0 incidence structureを満たすか，
(7) saddle-point matrixをSPDと誤認していないか，
(8) discrete inf-sup stabilityを単なるmatrix nonsingularityと混同していないか，
(9) RT interpolationをFortin argumentに使うときdomain regularityを確認しているか，
(10) cellwise conservation residual \(B\Sigma+F\) とconvergence rateを別々に確認しているか
を順に検査してください．

24．第16回の結論

RT0–P0 mixed FEMでは， Poisson equationを

\[ \boldsymbol\sigma-\nabla u=0, \qquad \nabla\cdot\boldsymbol\sigma=-f \]

へ分解し，normal fluxとcell valueを同時に求めました．

実装構造は \[ \boxed{ \text{RT mass} + \text{signed incidence} + \text{inf-sup stability} + \text{cellwise balance} } \tag{40} \] です．

特に \[ B\boldsymbol\Sigma=-\boldsymbol F \] は単なるmatrix equationではなく， 各rowが一つのelementの \[ \int_{\partial T} \boldsymbol\sigma_h\cdot\boldsymbol n_T = -\int_Tf \] を表しています．

Season 2 第4回の原則
mixed FEMでは， 未知量・function space・block stability・保存則を同時に設計する．

次回はvector velocityとscalar pressureを未知量に持つ Stokes方程式へ進み， inf-sup conditionがelement choiceをどう決めるかを実装から見ます．
