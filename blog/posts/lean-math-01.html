第1回：数学的証明をLeanで確かめる — 二次元のCauchy–Schwarz不等式

線形代数 · 形式検証

1．計算することと証明すること

この連載では，線形代数と数値解析を題材に，定理証明支援系Leanの使い方を学びます．数学の定義や定理を理解することを出発点とし，紙と鉛筆で証明した後に，その論理をLeanで表現します．計算機に証明を任せるだけではなく，何を仮定し，何が保証されたのかを自分で説明できるようになることを目指します．

最初の問題は，二つのベクトルの内積の大きさを評価することです．数値解析では，このような不等式が誤差評価や安定性の証明の出発点になります．

2．数学的な証明

任意の実数 \(a,b,c,d\) に対して，\(x=(a,b)^{\top}\)，\(y=(c,d)^{\top}\) とおきます．ユークリッド内積を \((x,y)_{\mathbb R^2}=ac+bd\)，ノルムを \(\|x\|_{\mathbb R^2}=\sqrt{a^2+b^2}\) と定義します．

次の恒等式を展開によって確かめてください．

\[ (a^2+b^2)(c^2+d^2)-(ac+bd)^2=(ad-bc)^2. \tag{1} \]

右辺は非負なので，

\[ (ac+bd)^2\le (a^2+b^2)(c^2+d^2). \tag{2} \]

両辺は非負であり，平方根を取れば

\[ |(x,y)_{\mathbb R^2}|\le \|x\|_{\mathbb R^2}\|y\|_{\mathbb R^2} \tag{3} \]

を得ます．これがCauchy–Schwarzの不等式です．式(1)から，等号成立条件が \(ad-bc=0\) であることも分かります．これは二つのベクトルが線形従属であることと同値です（零ベクトルの場合を含みます）．

3．Leanで式(1)と式(2)を記述する

Lean Webを開けば，小さな例をブラウザから試せます．以下のコードではMathlibを読み込みます．環境によっては読み込みに時間がかかります．

import Mathlib

namespace LeanMathSeries

-- Lagrange's identity in dimension two.
theorem lagrange_identity (a b c d : ℝ) :
    (a^2 + b^2) * (c^2 + d^2) - (a*c + b*d)^2 =
      (a*d - b*c)^2 := by
  ring

-- The squared Cauchy–Schwarz inequality.
theorem dot_sq_le (a b c d : ℝ) :
    (a*c + b*d)^2 ≤ (a^2 + b^2) * (c^2 + d^2) := by
  apply sub_nonneg.mp
  rw [lagrange_identity]
  exact sq_nonneg (a*d - b*c)

-- A concrete counterexample to equality for every pair of vectors.
example : ((1 : ℝ)*0 + 0*1)^2 ≠ (1^2 + 0^2)*(0^2 + 1^2) := by
  norm_num

#print axioms lagrange_identity
#print axioms dot_sq_le

end LeanMathSeries

Leanソースファイル．この原稿では式(1)と式(2)を形式化の対象とし，式(3)および等号条件の形式化は次の課題とします．コードは公開前の実行確認が必要な下書きです．

theoremは証明する命題を宣言し，(a b c d : ℝ)は四つの変数が任意の実数であることを表します．ringは多項式恒等式の証明に使うタクティクです．sub_nonneg.mpで差の非負性に帰着し，rwで式(1)を書き換えに使い，sq_nonnegで実数の二乗が非負であることを適用します．

#print axiomsは定理が依存する公理を調べるためのコマンドです．証明を未完成のまま許すsorryは完成版には残しません．Leanが検査するのは記述した命題の証明であり，数学的な目的に合う命題を記述できているかは別に確かめる必要があります．

4．条件を変えてみる

不等式(2)を，任意のベクトルに対して成り立つ等式に変更することはできません．例えば \(x=(1,0)^\top\)，\(y=(0,1)^\top\) では左辺は0，右辺は1です．コードの最後のexampleはこの反例を記述しています．

  1. 式(1)の両辺を展開し，自分で証明してください．
  2. 等号が成立する具体例を二つ挙げ，零ベクトルの場合も調べてください．
  3. 三次元でも式(2)に相当する不等式を証明できるか考えてください．
  4. Leanで式(3)まで形式化するために必要な平方根の補題をMathlibで探してください．

5．数値解析への接続

線形方程式 \(Ax=b\) の近似解を \(\widehat{x}\) とすると，残差 \(r=b-A\widehat{x}\) と誤差 \(e=x-\widehat{x}\) は \(Ae=r\) で結ばれます．正則行列の場合，誘導作用素ノルムによって \(\|e\|_{\mathbb R^n}\le\|A^{-1}\|_{\mathrm{op}}\|r\|_{\mathbb R^n}\) を得ます．小さな残差だけでは誤差の小ささを保証できません．内積やノルムの理解が，このような誤差評価につながります．

ただし，実数上の定理の形式証明だけで浮動小数点演算の誤差が保証されるわけではありません．丸め誤差を含む保証には別のモデルと証明が必要です．この違いも数値解析編で扱います．
