第10回：model-reduction errorをどう分解するか

3rd August 2026

Introduction：細かいメッシュだけでは正しい答えにならない

有限要素メッシュを細かくし，時間刻みを小さくすれば， 選んだ方程式の離散解はその方程式の厳密解へ近づきます． しかし，その方程式自体が未解像状態を不適切に消去したモデルなら， 離散化誤差をどれだけ小さくしても元の現象には近づきません．

memory modelでは，少なくとも次の異なる近似が重なります．

  • full dynamicsからreduced memory equationを作る近似．
  • memory kernelまたはdelay lawを有限次元化する近似．
  • 空間を有限要素法で近似する誤差．
  • 時間をBDF・CQで近似する誤差．
  • CQ weightsと線形方程式を有限精度で計算する誤差．
今回の中心原理
model errorとstate-discretisation errorを一つの「数値誤差」にまとめない．
各近似段階の前後に中間問題を置き，同じtarget normでtelescoping decompositionを作る．

この分解によって，どの誤差が支配的かを判断でき， 不要なmesh refinementや過剰なlinear solveを避けられます．

1．full modelから計算結果までの階層

full stateを \[ X(t)=(u(t),z(t)) \] とし，観測・計算したいresolved componentを \[ PX(t)=u(t) \] とします． 計算までの階層を次のように書きます．

\[ \begin{aligned} \text{full dynamics }X &\longrightarrow \text{exact reduced trajectory }u^{\mathrm{red}} \\ &\longrightarrow \text{approximated-kernel solution }u^{K_N} \\ &\longrightarrow \text{spatially discrete solution }u_h^{K_N} \\ &\longrightarrow \text{fully discrete solution }U_{h,\Delta t,N} \\ &\longrightarrow \text{computed solution }\widetilde U_{h,\Delta t,N}. \end{aligned} \tag{1} \]

各矢印が一つの誤差源です． 重要なのは，すべての中間問題を明示することです． 中間問題を定義しなければ， 「kernel error」と「FEM error」を数学的に分離できません．

2．exact eliminationなら最初のmodel-reduction errorは零になり得る

第2回で扱った線形拡張系 \[ \begin{aligned} \partial_tu+Au+Bz&=f,\\ \partial_tz+Cz&=Du+g \end{aligned} \] から \(z\) をvariation of constantsで厳密に消去すると， \[ K(t)=Be^{-tC}D \] をもつmemory equationが得られます．

初期未解像状態に由来する \[ r_{z_0}(t)=Be^{-tC}z_0 \] と，未解像側のforcingを正しく残すなら，

\[ PX=u^{\mathrm{red}} \tag{2} \]

であり，この段階のreduction errorは零です．

一方，次の場合にはclosure errorが生じます．

  • 初期未解像状態 \(z_0\) の寄与を捨てる．
  • prehistoryを実際とは異なるzero historyへ置き換える．
  • nonlinear hidden dynamicsを線形kernelで近似する．
  • 一部のunresolved forcingを無視する．
  • 観測から同定したkernelが真のreduced operatorと一致しない．

従って，model reductionという語を 「kernelを有限個のmodeへ近似すること」だけに限定してはいけません． full modelからreduced equationを作る段階にも独立したerrorがあります．

3．exact telescoping decomposition

共通のnorm \(\|\cdot\|_{\mathfrak X}\) を選びます． 式 (1) の中間解を用いると，恒等的に \[ \begin{aligned} PX-\widetilde U_{h,\Delta t,N} ={}& \bigl(PX-u^{\mathrm{red}}\bigr) \\ &+ \bigl(u^{\mathrm{red}}-u^{K_N}\bigr) \\ &+ \bigl(u^{K_N}-u_h^{K_N}\bigr) \\ &+ \bigl(u_h^{K_N}-U_{h,\Delta t,N}\bigr) \\ &+ \bigl(U_{h,\Delta t,N} -\widetilde U_{h,\Delta t,N}\bigr). \end{aligned} \tag{3} \]

三角不等式から \[ \begin{aligned} \|PX-\widetilde U_{h,\Delta t,N}\|_{\mathfrak X} \le{}& E_{\mathrm{closure}} + E_{\mathrm{kernel}} \\ &+ E_{\mathrm{space}} + E_{\mathrm{time}} + E_{\mathrm{alg}}. \end{aligned} \tag{4} \]

error component 比較する二つの問題
\(E_{\mathrm{closure}}\) full resolved stateとexact reduced model
\(E_{\mathrm{kernel}}\) exact kernelと近似kernel
\(E_{\mathrm{space}}\) 近似kernelの連続問題とspace semidiscretisation
\(E_{\mathrm{time}}\) semidiscrete trajectoryとBDF・CQ solution
\(E_{\mathrm{alg}}\) exact discrete solutionとcomputer output

4．誤差を足す前にtarget normを固定する

異なるnormで得たboundをそのまま足すことはできません． 最初に最終的なtarget normを決める必要があります．

coercive instantaneous regime

第4回・第7回の理論では，例えば \[ \mathfrak X = L_\beta^2(0,T;V), \tag{5} \] または \[ \mathfrak X = W(0,T)\cap C([0,T];H) \tag{6} \] を使います．

degenerate instantaneous regime

第6回の問題では，物理変数だけの \(L^2(0,T;V)\)-normを一様に制御できないため， \[ \mathfrak X = C([0,T];\mathcal W) \tag{7} \] というmemory graph normを使います．

注意
coercive problemの \(L_\beta^2(0,T;V)\)-errorと， degenerate problemのgraph-energy errorを， 同じ数値として無条件に比較してはいけない．

5．raw residualではなくstability-amplified errorを見る

各errorは一般に \[ \text{error} \le \text{stability factor} \times \text{residual} \tag{8} \] という形になります．

measure-valued delayのkernel perturbationでは， \[ d_{\mu,\beta} := \alpha_0-\Lambda_1\kappa_\mu(\beta)>0 \] のとき \[ \|u_\mu-u_\nu\|_{L_\beta^2(0,T;V)} \le \frac{ \|K_{\mu-\nu}\widetilde u_\nu\|_{L_\beta^2(0,T;V^*)} }{ d_{\mu,\beta} }. \tag{9} \]

同じkernel residualでも， \(d_{\mu,\beta}\) が小さければsolution errorは大きく増幅されます． 従って，誤差指標はresidualの大きさだけでなく， stability marginを必ず含める必要があります．

6．lag-measure approximation errorは現在の理論で分離できる

delay law \(\mu\) を有限原子測度 \[ \mu_N = \sum_{j=1}^{N} m_j\delta_{\tau_j} \tag{10} \] へ置き換えます． 同じmassをもつ非負測度で，joined limit trajectoryが \(H^\theta(\mathbb R;V)\)-extensionをもつなら， 第7回のWasserstein estimateから \[ \|u_\mu-u_{\mu_N}\|_{\mathfrak X} \le C_{\mathrm{ker}} W_1(\mu_N,\mu)^\theta, \qquad 0<\theta\le1. \tag{11} \]

従って \[ E_{\mathrm{kernel}}^{\mathrm{lag}} := C_{\mathrm{ker}} W_1(\mu_N,\mu)^\theta \tag{12} \] を，lag-measure model-reduction errorとして独立に記録できます．

等分割mass lumpingでは \[ W_1(\mu_N,\mu) \le \frac{M\tau}{N}, \tag{13} \] なので \[ E_{\mathrm{kernel}}^{\mathrm{lag}} = O(N^{-\theta}) \tag{14} \] です． この項は空間mesh size \(h\) や時間刻み \(\Delta t\) とは独立に評価されます．

7．Paper IIで確立されている二項分解

有限原子kernel \(\mu_N\) に対するfully discrete approximationを \(U_{h,\Delta t,N}\) とすると， 現在のcontinuous kernel-stability theoryから \[ \begin{aligned} \|u_\mu-U_{h,\Delta t,N}\|_{\mathfrak X} \le{}& C W_1(\mu_N,\mu)^\theta \\ &+ \|u_{\mu_N}-U_{h,\Delta t,N}\|_{\mathfrak X} \end{aligned} \tag{15} \] という分解が得られます．

\[ \boxed{ \text{total error} \le \text{kernel-transport error} + \text{state-discretisation error} } \tag{16} \]

第一項は既にWasserstein distanceで制御されています． 第二項をspace errorとtime errorへさらに分解し， そのconstantをatomic kernel familyに対して一様に保つことが fully discrete sequelの中心課題です．

8．delay atomsとProny modesには別々のmodel errorがある

第7回で近似したのはdelay location \(s\) 上の測度 \[ \mu(ds) \] です．一方，第8回・第9回のProny approximationは， relaxation rate \(\lambda\) 上のBernstein measure \[ \nu(d\lambda) \] を \[ \nu_L = \sum_{\ell=1}^{L} c_\ell\delta_{\lambda_\ell} \tag{17} \] へ近似します．

従ってkernel model errorには \[ E_{\mathrm{kernel}} = E_{\mathrm{lag}} + E_{\mathrm{relax}} \tag{18} \] という二つの方向があり得ます．

approximation 原子を置く変数 縮約後の表現
finite delay quadrature lag \(s\) shifted states \(u(t-\tau_j)\)
finite Prony approximation relaxation rate \(\lambda\) local internal variables \(\zeta_\ell\)

両者を同じ \(N\) で表し，一つの「kernel discretisation」と呼ぶと， どの変数を改善すべきか分からなくなります．

9．Prony approximationでは何を残差として測るか

exact memory kernel \(k\) とProny approximation \(k_L\) を考えます． coercive regimeでは，reference solution \(u_{k_L}\) に沿った \[ R_{\mathrm{relax},L}(t) := A_1\bigl[(k-k_L)*u_{k_L}\bigr](t) \tag{19} \] をkernel residualとし， \[ \|u_k-u_{k_L}\|_{\mathfrak X} \le C_{\mathrm{stab}} \|R_{\mathrm{relax},L}\|_{\mathfrak Y} \tag{20} \] という形を目標にできます．

Laplace領域では \[ \widehat k(z)-\widehat k_L(z) = \int_{[0,\infty)} \frac{1}{z+\lambda} \,d(\nu-\nu_L)(\lambda) \tag{21} \] がtransfer-function errorです．

ただし，現在のlag-measure論文が直接確立しているのは delay variable上のWasserstein estimateです． 一般Bernstein measureに対するsharpなProny error bound， 特にdegenerate graph normでの一様estimateは， 別途構築すべき解析課題です． ここでは式 (19) をerror ledger上の独立項として置き， 未証明の普遍rateは仮定しません．

10．space errorはbest approximationだけではない

kernelを固定した連続解 \(u^{K_N}\) とspace semidiscrete solution \(u_h^{K_N}\) の差を考えます． conforming methodではbest approximationを中心に評価できますが， Crouzeix–Raviart法ではnonconforming consistencyも現れます． 概念的には \[ E_{\mathrm{space}} \le E_{\mathrm{approx}} + E_{\mathrm{cons}}. \tag{22} \]

異方性CR法では

  • 方向別補間誤差
  • semi-regular mesh parameter
  • broken gradient norm
  • face jumpまたはconsistency residual
  • 必要に応じたCR–RT reconstruction

がspace errorを構成します． memory termがあるから異方性補間理論が消えるわけではなく， 各time levelまたはtime integralの中で同じ空間誤差を評価します．

Paper IIで確立されているのは， kernel-transport constantがconforming・CR semidiscretisation後も mesh-independentに保たれることです． \(u_{\mu_N}-u_{h,\mu_N}\) の完全なspace consistency estimateは 独立した数値解析層です．

11．time errorをさらに分ける

BDF・CQによるtime errorは一項ではありません． 少なくとも \[ E_{\mathrm{time}} \le E_{\mathrm{BDF/CQ}} + E_{\mathrm{start}} + E_{\mathrm{delay\mbox{-}interp}} \tag{23} \] と分けます．

  • \(E_{\mathrm{BDF/CQ}}\)：smooth partに対するtime-stepping consistency error．
  • \(E_{\mathrm{start}}\)：初期層，non-smooth data，starting procedureによる誤差．
  • \(E_{\mathrm{delay\mbox{-}interp}}\)：delay atomがtime grid上にない場合のoff-grid history interpolation error．

Prony internal-variable methodではoff-grid delay interpolationは現れませんが， relaxation-spectrum approximation errorが別に現れます． delay-variable discretisationとrelaxation-variable discretisationで， time algorithmの誤差構造も異なります．

12．CQ weight computationとlinear solver error

理論上のfully discrete solution \(U_{h,\Delta t,N}\) と， 実際にcomputerが返す \(\widetilde U_{h,\Delta t,N}\) は同じではありません．

algebraic errorを \[ E_{\mathrm{alg}} \le E_{\mathrm{weight}} + E_{\mathrm{solve}} + E_{\mathrm{round}} \tag{24} \] と分けます．

  • \(E_{\mathrm{weight}}\)：contour integral・FFT・Prony fittingなどによるCQ weightの計算誤差．
  • \(E_{\mathrm{solve}}\)：各time stepのlinear systemを有限toleranceで止める誤差．
  • \(E_{\mathrm{round}}\)：長時間history accumulationとfloating-point roundingの影響．

第8回で定義したenergy residual \[ \mathfrak R_{\mathrm{en}}^n \] は，これらの実装誤差がcontinuous structureをどの程度壊したかを監査する指標になります．

13．誤差指標と厳密な上界を区別する

実際の計算では \[ \eta_{\mathrm{closure}}, \quad \eta_{\mathrm{kernel}}, \quad \eta_{\mathrm{space}}, \quad \eta_{\mathrm{time}}, \quad \eta_{\mathrm{alg}} \tag{25} \] というindicatorを作ります． しかし，すべてが自動的にrigorous upper boundになるわけではありません．

component 計算可能性
lag-kernel error \(\mu\) が既知なら \(W_1(\mu_N,\mu)\) から評価可能
space-time residual equilibrated reconstruction等によりcertificate化可能
algebraic residual solver residualとenergy balanceから直接計算可能
closure error full model・追加観測・validation dataがなければ一般に計算不能

closure errorが未知なのに， FEM residualだけを小さくして「全誤差が保証された」と主張してはいけません．

14．output errorも同じ階層で分ける

目的量 \[ \mathcal J(u) \] を評価したい場合も，同じ中間問題を使います． 線形functionalなら \[ \begin{aligned} |\mathcal J(PX)-\mathcal J(\widetilde U)| \le{}& |\mathcal J(PX-u^{\mathrm{red}})| \\ &+ |\mathcal J(u^{\mathrm{red}}-u^{K_N})| \\ &+ |\mathcal J(u^{K_N}-u_h^{K_N})| \\ &+ |\mathcal J(u_h^{K_N}-U)| \\ &+ |\mathcal J(U-\widetilde U)|. \end{aligned} \tag{26} \]

単純には \[ |\mathcal J(v)| \le \|\mathcal J\|_{\mathfrak X^*} \|v\|_{\mathfrak X} \] を使えます． よりsharpなoutput estimateには，DWRやdual problemを各層へ適用する必要があります．

特にkernel errorもgoal-orientedに評価すれば， 「解全体を近似するためのkernel」と 「特定のoutputを正確にするためのkernel」が異なる可能性があります．

15．error budgetを設定する

全許容誤差を \(\mathrm{TOL}\) とし， \[ \mathrm{TOL} = \mathrm{TOL}_{\mathrm{closure}} + \mathrm{TOL}_{\mathrm{kernel}} + \mathrm{TOL}_{\mathrm{space}} + \mathrm{TOL}_{\mathrm{time}} + \mathrm{TOL}_{\mathrm{alg}} \tag{27} \] と配分します．

目標は，各componentを同じ大きさへ機械的に揃えることではなく， costとreducibilityを考えて配分することです．例えば

  • kernel errorが支配的なら，mesh refinementを止めてatomまたはmodeを増やす．
  • space errorが支配的なら，\(N\) や \(L\) を固定してmeshを改善する．
  • time errorが支配的なら，\(\Delta t\) またはstarting treatmentを改善する．
  • algebraic errorが十分小さければ，solver toleranceをさらに厳しくしない．
  • closure errorが不明なら，追加観測またはfull-model comparisonを優先する．

16．一様なstability constantがなければ極限を交換できない

fully discrete programmeでは \[ N\to\infty, \qquad h\to0, \qquad \Delta t\to0 \] という複数の極限があります．

形式的に各誤差が0へ行っても，constantが他のparameterに依存して発散すれば， 極限順序を交換できません． 必要なのは \[ \|u_\mu-U_{h,\Delta t,N}\|_{\mathfrak X} \le C \left[ W_1(\mu_N,\mu)^\theta + \eta_h + \eta_{\Delta t} \right] \tag{28} \] を，\(C\) が \(h,\Delta t,N\) に依存しない形で示すことです．

Paper IIはkernel-transport estimateが conformingおよびCR spatial semidiscretisationへ mesh-uniformに移ることを示しています． しかし，space consistencyとtime steppingを含む 完全離散uniform estimateは今後の数値解析課題です．

17．zero-delay boundaryでは通常のerror budgetが壊れる

positive lagに集中するatomic familyでは，一つのweightと一つのstability marginを 一様に選べます． 一方，delay massが原点へ近づくと \[ \kappa_{M\delta_{\tau_d}}(\beta) = Me^{-\beta\tau_d} \tag{29} \] であり，subcritical thresholdを越えるfamilyでは 一様なmarginのための \(\beta\) が \(\tau_d^{-1}\)-scaleで発散します．

従って，\(W_1(M\delta_{\tau_d},M\delta_0)\) が小さいだけでは， uniform solution errorは保証されません． 原点では \(M\delta_0\) をinstantaneous operatorへ吸収し， 比較する中間問題自体をrenormaliseする必要があります．

教訓
model distanceが小さいことと，solution distanceが小さいことは同じではない．
両者を結ぶstability constantが一様であることを確認しなければならない．

18．実際のerror ledger

一回の計算について，次の表を保存します．

項目 使用parameter indicator / bound
closure hidden model，prehistory，identified parameters validation mismatchまたはfull-model residual
lag kernel atom数 \(N\)，位置 \(\tau_j\)，mass \(m_j\) \(C_{\mathrm{ker}}W_1(\mu_N,\mu)^\theta\)
relaxation spectrum mode数 \(L\)，\(\lambda_\ell,c_\ell\) transfer-functionまたはmemory residual
space mesh \(\mathcal T_h\) element residual，jump，CR–RT reconstruction
time \(\Delta t\)，BDF order，starting rule time reconstruction residual
algebraic solver tolerance，weight precision linear residual，energy residual

このledgerを比較すれば，計算costをどこへ追加すべきかが分かります．

19．現在確立されていることと今後の課題

現在の連続理論が与えるもの

  • weighted well-posednessとasymmetric residual principle．
  • total variation・narrow・Wassersteinによるlag-kernel stability．
  • finite-atomic delay approximationの \(W_1^\theta\)-error．
  • kernel errorとstate-discretisation errorの二項分離．
  • kernel estimateのmesh-uniform spatial Galerkin transfer．

数値論文で新たに必要なもの

  • CR spatial consistencyと異方性補間errorの完全評価．
  • BDF1・BDF2・CQ time errorのkernel-family一様評価．
  • off-grid delay interpolationとstarting errorの分離．
  • relaxation-spectrum Prony approximationの定量的residual bound．
  • graph normにおけるvanishing-coercivity robust error estimate．
  • 各componentを計算可能にするa posteriori certificate．

従って，式 (4) は研究programme全体の設計図です． すべての項に既に完成したsharp theoremがある，という主張ではありません．

Conclusion

model-reduction errorを正しく扱うには， full modelとcomputed solutionの間に中間問題を置き， 各近似段階を別々に比較する必要があります．

\[ \begin{aligned} \text{total error} \le{}& \text{closure error} + \text{kernel error} \\ &+ \text{space error} + \text{time error} + \text{algebraic error}. \end{aligned} \]

exact state eliminationならclosure errorは零になり得ますが， initial hidden stateやprehistoryを捨てれば再びmodel errorが生じます． lag-measure approximationについてはWasserstein stabilityが kernel errorを独立に制御します． 一方，Prony approximation，fully discrete CR–CQ error， graph-space certificateには追加の解析が必要です．

最も重要なのは，すべてのerrorを同じtarget normで測り， stability amplificationを含むindicatorとして管理することです． これによって，mesh，time step，delay atoms，relaxation modes， solver toleranceのどれを改善すべきか判断できます．
