3．定義から証明する

  1. 段階1：固有空間の条件を方程式にする

    固有値1の固有空間は、(A(t)−I)v = 0 を満たすベクトル全体です。v = (x,y)T とおくと、

    (A(t) − I)(x,y)T = (ty,0)T

    したがって、解くべき条件は ty = 0 です。

  2. 段階2：tが零かどうかで場合分けする

    t ≠ 0 の場合：ty = 0 から y = 0。xは自由なので、固有空間は span{(1,0)T}、つまり第1座標軸全体です。次元は1です。

    t = 0 の場合：ty = 0 は全てのx,yで成り立ちます。固有空間は ℝ²、つまり全平面で、次元は2です。

    この場合分けは、特定のスライダー値での数値実験ではなく、任意の実数tに対する議論です。

  3. 段階3：固有空間の次元から対角化を判断する

    2次元の空間で対角化するには、一次独立な固有ベクトルが2本必要です。この行列の固有値は1だけなので、t ≠ 0 では1本しか取れず、対角化できません。t = 0 なら A(0) = I で、e₁とe₂を固有ベクトルに取れます。

    結論：A(t)が対角化可能であることと、t = 0 は同値です。固有値の集合だけでは対角化可能性は決まりません。
